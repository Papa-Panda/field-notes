## 一句话总结

MTP 让模型在每个位置同时预测未来多个 token：训练时是信号更密的辅助任务，逼模型做长远规划；推理时同一组预测头直接当草稿器做投机解码，一鱼两吃。

## 核心

1. 问题/背景：标准 next-token 预测每步只学一个监督信号，生成也只能逐个往外蹦——训练信号稀、推理速度慢是同一个根源。
2. 机制/方法：MTP 在每个位置不只预测紧挨着的下一个 token，还同时预测再下、再下一个。要提前猜中更远的 token，模型不能只盯眼前，必须学着规划，同样数据的学习更充分。到了推理阶段，这些多预测头现成可用：先一口气草拟后续几个 token，再由主模型并行核对，猜对的部分直接采纳，一步跳好几格——即投机解码。实现上有两种流派：并排独立多头（简单，但头间互不知情）与 DeepSeek-V3 的串行模块链（后一模块吃前一模块输出，保留完整因果顺序，草稿更连贯）。
3. 关键证据或数字：实测第二个 token 的采纳率可达 85%–90% ，整体生成速度提升到约 1.8 倍。
4. 结论/判断：MTP 与「训练后外挂一个小草稿模型」的投机解码路线本质不同：它的草稿头在训练阶段就长在模型体内、与主干一起训、共享主干，天生一家人，这也是它采纳率高、能同时涨质量又涨速度的原因。

## 可迁移

- 理解推理加速选型：MTP 是「训练期内置草稿头」路线，和 Medusa 的多解码头同源、与外挂 draft 模型路线相对，面试或做 vLLM 选型时要能分清三者。
- 训练侧启示：辅助任务不只是防过拟合——预测更远的未来本身就是一种规划能力的塑造手段，与 RL 里的多步回报视角相通。
