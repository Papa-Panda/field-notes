2一句话总结

SFT 学不进新知识还会放大幻觉：未知样本学得慢，一旦被学会，模型学到的其实是「没根据也要编一个」的行为，幻觉随之线性上升；机理是新知识微调削弱了对问题关键实体的注意力，修法是训练后期回灌少量已知样本。

3核心

  1. 问题/背景：一条 SFT 问答样本对模型只有两种状态——已知（预训练见过、不用微调也能稳定答对）与未知（只有这条样本在教）。判法是对每个问题多次采样，能稳定答对算已知。受控实验固定总样本数、改变未知比例，看两条学习曲线。
  2. 机制/方法：未知样本拟合明显更慢（已知样本几个 epoch 就拟合，未知样本拖很久）；而当未知样本终于被学会，模型在其他问题上的幻觉倾向随之线性上升——因为训练在奖励「对没有依据的问题给出确定答案」，学到的是编这个行为本身。机理分析进一步定位：正常回答时注意力集中在问题里的关键实体（如人名）上，新知识微调后这份注意力被削弱、转而依赖周围上下文措辞，于是幻觉沿词面相似的上下文扩散，没训过的题型也开始编；且某一类知识的「不熟悉度」比总体新知识比例更关键。
  3. 关键证据或数字：幻觉倾向随未知样本被学会而线性上升（定性曲线，视频未给具体斜率）；修法是在训练后期重新混入少量已知知识样本——已知样本把注意力拉回关键实体，幻觉大幅缓解且性能不损失，注意是「少量、后期」，不是全程混、大比例混。
  4. 结论/判断：事实知识主要来自预训练，SFT 教的是怎么更高效地用。实操四步：SFT 前先多次采样划分已知/未知；控制未知比例，别指望 SFT 塞进知识；真正的知识注入走继续预训练（多样改写多遍）或检索增强（让模型查而不是背）；训练后期回灌已知样本顺手压幻觉。

4关键数字

现象 观察
未知样本拟合速度 明显慢于已知样本（后者几个 epoch 即拟合）
未知样本被学会后 其他问题上的幻觉倾向线性上升
修法 训练后期回灌少量已知样本，幻觉大幅缓解、性能不损失

5可迁移

  • post-training 数据 curation：SFT 数据配比先做已知/未知标定，未知知识类样本要么转成继续预训练语料、要么配检索，不要硬塞进 SFT。
  • 面试准备：一句「知识在预训练、SFT 只教用法」加上注意力机理，是回答「为什么微调后幻觉变多」的高质量答案骨架。

6疑问 / 下一步
