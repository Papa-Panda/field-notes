## 一句话总结

自洽性采样让模型对同一问题采样多条思维链，只对最终答案做多数投票——不换模型、不微调、不需要打分器，用 N 倍推理开销换准确率。

## 核心

1. **问题/背景**：单条思维链是一次性赌博：推理路径中途走偏一步，最终答案就错。模型本身有能力走对，只是单次采样不稳定。
2. **机制/方法**：对同一问题用温度采样（温度必须大于零，否则 N 条链完全相同、方法退化）采样出 $N$ 条不同推理链。关键观察是：通往正确答案的路径有很多条，而通往同一个错误答案的路径很少，因此各链的最终答案会向少数几个值汇聚，正确答案自然形成最大的一簇。投票只针对最终答案，不针对中间步骤——中间步骤几乎不会完全相同，没法投。
3. **关键证据或数字**：与 Best-of-N 的分工不同：Best-of-N 需要奖励模型或打分器从 N 条里挑最好的一条，自洽性不需要任何打分器，只数票数。代价是 N 倍推理开销，且 N 越大收益递减。实现上就是循环采样 N 次、抽取每条的最终答案、统计频次取最高。
4. **结论/判断**：自洽性是推理期最廉价的涨点手段之一，适合答案可归一化比对的任务（数学、选择题等）；它放大的是模型已有的正确倾向，模型对某类题完全不会时投票也救不回来。

## 可迁移

- 评估 RL 训练收益时要注意对照组：如果基线没开自洽性/多数投票，推理期采样技巧带来的涨点可能被误记为训练收益；反过来，rollout 阶段的多采样统计（通过率、答案分布）本身就是现成的难度与不确定性信号，可用于数据筛选。
- 投票「只投最终答案」的前提是答案可抽取可归一化；开放式生成任务要先解决答案等价判定，这一步往往比采样本身更难。

## 疑问 / 下一步

- N 取多大性价比最高取决于题难度分布；实际部署可按答案一致性做自适应停采（前几条已高度一致就提前停），视频未展开这一优化。
