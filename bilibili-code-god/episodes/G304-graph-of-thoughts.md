## 一句话总结
把推理结构从链（一条道）→树（可分叉回溯）→图（任意连边）逐级放开，图独有的「聚合」与「回环」让多个想法能合并取长补短、绕回自身反复精炼。

## 核心
1. **问题/背景**：思维链（CoT）把想法排成一条线，清晰但中间错了没法回头；思维树（ToT）允许每步分叉、走不通回溯重来，有了试错能力，但树的死规矩是每个节点只能有一个上游——能分叉，不能合并。
2. **机制/方法**：思维图（GoT）让任意两个想法之间都能连边，多出两样本事：一是聚合，多条分支汇聚到同一个新节点（如三份草稿各取亮点合成更好的一版），树上办不成、图上天经地义；二是回环，一个想法用一条自环边绕回自己反复打磨，像文章改二稿三稿。抽象成三种基本变换：生成（一个想法分出多个，负责探索）、聚合（多个合并成一个，负责取长补短）、精炼（想法绕回自己，负责打磨），自由组合即可拼出复杂推理流程。典型打法是排序任务的分而治之：先生成把长串拆段分别排好，再两两聚合归并成整条有序串。
3. **关键证据或数字**：排序任务上，GoT 相比 ToT 质量提升 62%，成本反而降低三成多——聚合复用了多条分支的信息，少走重复的冤枉路。
4. **结论/判断**：推理结构的表达力决定上限：链→树→图，每放开一层约束就多一类可表达的思考模式；结构对了，可以又准又省。

## 可迁移
- 设计 agent 的推理/搜索框架时，把「生成、聚合、精炼」当作三个正交算子来编排，比默认线性 CoT 多了合并多路候选与迭代修订两个抓手。
- 面试被问 CoT/ToT 的区别与局限时，答题骨架就是这条演进链：链不能回头、树不能合并、图两者皆可。

## 疑问 / 下一步
