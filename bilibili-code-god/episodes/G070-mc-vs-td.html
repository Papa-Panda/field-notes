2一句话总结

估计价值函数有两条路：蒙特卡洛等整局结束用真实回报更新（无偏但方差大），TD 只走一步用「即时奖励 + 下一步的估计」自举更新（方差小但价值估不准时有偏），两者是偏差–方差取舍的两端。

3核心

  1. 问题/背景：学习价值函数时，目标值从哪里来——等拿到真实总回报，还是用当前估计滚动更新，是所有后续算法（GAE、PPO、GRPO）都要面对的基本选择。
  2. 机制/方法：蒙特卡洛法跑完一整局，拿真实总回报回头更新每一步的价值，平均意义上准确，但单局之间波动大且必须等到结束；TD（时序差分）只走一步就更新，目标由马上得到的奖励加上折扣后的下一步价值估计构成，即用估计更新估计（自举），每步都掺入一点真实奖励，误差被逐步冲淡。
  3. 关键证据或数字：核心量是 TD 误差，即真实一步回报与当前估计之差：

$$\delta = R + \gamma V(s') - V(s)$$

它后面在 PPO/GRPO 的优势估计里无处不在；视频还预告：只走一步与走完整局之间的步数选择，后续会变成 GAE 里可调的旋钮。 4. 结论/判断：MC 与 TD 不是对错之分而是偏差–方差的取舍：TD 用「价值函数不准带来的偏差」换取低方差与在线更新能力。

4可迁移

  • 面试基础题的标准答法：先点明 MC 无偏高方差、TD 有偏低方差，再落到 TD 误差公式，并顺势引到 GAE 是在两者之间插值。
  • 理解 LLM RL 时同样适用：只用最终奖励（近 MC）信号稀疏但无偏，用 critic 逐步 bootstrap（TD 系）则引入 critic 误差的偏差。
