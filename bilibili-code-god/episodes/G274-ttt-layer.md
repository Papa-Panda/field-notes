## 一句话总结
TTT 层把序列记忆从"存一串状态向量"换成"维护一个小神经网络的权重"，每来一个 token 就用一道自监督题对它做一步梯度下降，从而同时拿到线性复杂度、恒定显存和远超 RNN 的记忆容量。

## 核心
1. 问题/背景：记住历史只有两条老路——注意力把全部历史原样存下、生成时逐个回看，记得全但计算量随长度平方增长、显存吃紧；RNN 把历史压进固定大小的状态向量，快而省，但容量有限，长序列早期信息被挤掉。一个太贵，一个健忘。
2. 机制/方法：把"记忆"本身换成一个小神经网络，其权重即记忆。每个 token 到来时，先把它压缩、再让小模型尝试还原，还原误差即损失；对小模型权重做一步梯度下降更新记忆，然后用更新后的小模型处理当前 token 输出。整条序列读完，等于把这个小模型逐词训练了一整轮。内层模型有两档：简单版是线性层，复杂版是两层小网络，骨架相同。
3. 关键证据或数字：每步只更新固定大小的小模型，不回看全部历史，故计算量随长度线性增长、显存恒定；且喂入的上文越多表现还能持续变好，而固定记忆的传统 RNN 很早就到顶、再喂也不涨。
4. 结论/判断：TTT 的本质是"测试时仍在训练"——处理一条序列就等于在线训练一个小模型；用权重当记忆，表达力远强于单个状态向量，是长文本场景下兼顾成本与记忆的结构路线。

## 可迁移
- 面试被问"注意力 vs RNN 的取舍"时，可把 TTT 作为第三条路线补充：状态即权重、更新即梯度下降，与 Titans 的神经记忆（G276）同属"记忆参数化"思路。
- RL infra 视角：内层一步梯度下降的开销必须足够小才划算，评估这类结构时先看内层模型规模与每步更新成本。
