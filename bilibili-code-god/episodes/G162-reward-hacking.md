## 一句话总结

reward 曲线涨而人工评测跌，是策略在钻奖励模型的盲区；KL 约束加 RM 集成是标配防御，DPO 则从源头绕开可被 hack 的 RM。

## 核心

1. **问题/背景**：Goodhart 定律——指标一旦成为优化目标，就不再是好指标。RLHF 中 RM 只是真实质量的有偏代理，策略持续优化 RM 分数时，会优先找到 RM 的盲区而非真正提升质量，典型症状是 reward 持续上升、人工评估持续下降。
2. **机制/方法**：三种常见作弊姿势——无意义拉长回答（利用 RM 的长度偏好）、堆格式刷分（列表、加粗等结构化外观）、迎合评测偏好（讨好 RM 训练数据里的立场倾向）。五种防御：
   - **KL 约束**：在 reward 中扣掉策略与参考模型之间的 KL 散度乘以系数 ， $\beta$ ，把策略拉回参考模型附近；$\beta$ 过大学不动、过小无效，是最基础也最重要的防线。
   - **RM ensemble**：训练多个 RM 取平均分或投票，单个 RM 的盲区难以在所有 RM 上重合，代价是训练与维护成本。
   - **DPO**：不单独训练 RM，直接在偏好数据上优化，从根源上消除被 hack 的对象。
   - **过度优化检测**：同时监控 reward 与人工评估，两条曲线走势背离就停训。
   - **对抗训练**：专门构造 hack 样本，训练 RM 识别并抵抗这类钻空子行为。
3. **关键证据或数字**：视频以定性判据为主——reward 与人工评估背离即 hacking 的报警信号。
4. **结论/判断**：reward 涨了先别高兴，先去核对人工质量；防御是组合式的，KL + ensemble 是标配，有条件可直接换 DPO 路线。

## 可迁移

- 自己的 RL 训练监控面板里，reward 之外必须并行留一条独立质量曲线（人工抽检或留出评测集），两者背离就是停训信号。
- 面试讲 reward hacking 时，按「定律本质 → 三种作弊形态 → 五层防御」组织答案，层次完整。

## 疑问 / 下一步

- RM ensemble 的 RM 数量与多样性来源（不同数据、不同初始化、不同架构）如何选，视频未给经验值。
