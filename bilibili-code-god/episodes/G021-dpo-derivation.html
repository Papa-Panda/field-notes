2一句话总结

DPO 的全部魔法在于：带 KL 约束的奖励最大化问题有闭式最优策略，把它反解出奖励再代入 Bradley-Terry，配分函数在成对相减时恰好消掉，于是偏好学习不再需要显式 reward model。

3核心

  1. 问题/背景：PPO 路线要训四个模型还要在线采样，DPO 问的是：能不能跳过 reward model，直接从偏好数据学策略？
  2. 机制/方法：起点仍是熟悉的目标——奖励尽量高、同时用 $\beta$ 控制的 KL 把策略拴在 reference model 附近。该问题有解析解：最优策略正比于 reference model 乘上奖励除以 $\beta$ 的指数，即奖励高的回答被指数放大。把式子倒过来，奖励就能用策略表示： $\beta$ 乘对数比率，再加一项 $\beta \log Z$ ，其中 $Z$ 是配分函数。麻烦在于 $Z$ 要对所有可能回答求和，算不出来。
  3. 关键证据或数字：关键一步是 Bradley-Terry 只看同一提问下两个回答的奖励差；两项里的 $Z$ 相同，一减就没了。剩下的就是 DPO 损失：好回答的对数比率减坏回答的对数比率，过 sigmoid 后取负对数； $\beta$ 默认 0.1。由此得到论文标题的结论—— $\beta$ 乘对数比率本身就是隐式奖励，语言模型内部已经藏着一个 reward model。
  4. 结论/判断：DPO 的代价也很明确：离线、不采样、无探索，学不到偏好数据覆盖之外的行为。

4关键数字

量 取值/形式
$\beta$ 默认值 0.1
隐式奖励 $\beta$ ×（策略与 reference 的对数比率）

5可迁移

  • 面试讲 DPO 不要只背损失函数：从「KL 约束目标有闭式解 → 反解奖励 → BT 相减消掉配分函数」三步推下来，才算讲透。
  • 理解隐式奖励后，DPO 的诸多变体（改 $\beta$ 、改参考策略、加长度惩罚）都能放回同一个框架里看。
