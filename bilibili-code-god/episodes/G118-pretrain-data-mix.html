2一句话总结

数据配比是预训练的隐藏超参，直接决定模型往哪个方向「偏科」；没有通用最优解，实操路线是先抄主流配比起步，再用 DoReMi 或单变量消融在自己的评测集上小规模搜出来。

3核心

  1. 问题/背景：预训练语料来自网页、百科、代码、书籍、对话等多种来源，质量与能力贡献各异，配比不同模型擅长的东西就不同，因此配比本身就是需要调的超参，而不是抄一份就完事。
  2. 机制/方法：三类数据源分工——网页量最大、负责广度与常识但需重度清洗；代码练结构与长逻辑链、对推理提升明显；书籍长文提供连贯长上下文、是长程依赖的主要来源；数学与学术数据量小但密度高、专补严谨推理。调配比三法：经验法（从主流模型配比起步）、DoReMi（用小模型自动搜索最优配比再迁移到大模型，思路是哪个域 loss 高就多喂哪个）、消融实验（只改一种来源的比例看效果）。
  3. 关键证据或数字：主流配方彼此差别巨大——GPT-3 网页约占 60%，LLaMA 网页约 67%，DeepSeek 则显著提高代码比例并观察到代码越多推理越强；差异本身就说明不存在唯一最优配比。
  4. 结论/判断：配比不是抄来的，是在自己的评测集上搜出来的：先统计各来源数据量与质量，从主流配比开始，小规模用 DoReMi/消融试不同配比，再按目标能力调整，全程监控各能力验证集表现。

4可迁移

  • 做继续预训练或领域微调的数据配比时可复用同一路线：主流配比起步 → 小模型/小规模搜配比 → 按目标能力的验证集消融定锤；尤其记住「加代码比例拉推理」这条已被多家验证的方向性结论。
