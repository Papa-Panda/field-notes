## 一句话总结

损失随参数、数据、算力呈幂律下降，在双对数坐标里是一条可外推的直线——先用小模型拟合直线，就能预知大模型的最终损失；Chinchilla 进一步给出每参数约 20 个 token 的黄金配比。

## 核心

1. **问题/背景**：动辄几亿美金的训练没人敢盲赌，需要在开跑前预知结果。经验事实是：损失随规模呈幂律下降（收益递减但永远在降、且降得极有规律）。
2. **机制/方法**：幂律写成 $L = A \cdot X^{-\alpha}$ ，在双对数坐标下变成直线，于是可以拿小模型的几个点拟合、再用尺子往外延长预知未来。损失还能拆成三项：不可约底线 + 参数不足的惩罚 + 数据不足的惩罚，两边都要喂饱才能降损失。预算固定时，参数与数据应等比例同涨，而不是一味堆参数。
3. **关键证据或数字**：见下表。Kaplan 2020 的解读偏向「模型越大越好」，GPT-3 的 175B 参数、300B token 正是产物（每参数仅约 1.7 个 token，按 Chinchilla 配比它只该做约 15B）；Chinchilla 用 70B 参数 + 1.4T token 反而全面击败约 4 倍大的 Gopher。GPT-4 则用不到最终算力万分之一的小模型实验，提前锁定最终 loss。
4. **结论/判断**：训练最优 ≠ 推理最优——Chinchilla 只算了训练账；部署时推理要被跑几十亿次，所以 LLaMA-3 8B 喂 15T token（黄金配比只需约 160B，超配约 94 倍）是替所有用户省推理钱。2026 年预训练放缓，但定律没死，只是换了维度：test-time scaling 与 RL 后训练沿新曲线继续爬。另外记住 loss 是平滑下降的，能力却常常跳变涌现，直线之外总有惊喜。

## 可迁移

- 规划自有训练/微调实验时，先用小规模跑 3–4 个点在 log-log 图上拟合，再决定大跑的配比与预算，这是 scaling law 最直接的工程用法。
- 面试聊「为什么现在小模型喂远超 Chinchilla 的数据」时，用训练一次付费、推理终身付费的账本回答，能把话题从背结论拉到成本结构。
