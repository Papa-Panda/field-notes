2一句话总结

冷启动 SFT 的职责只是给后续 RL「点火」——教格式、教基本推理模式、稳住语言，让 RL 初期采样组内有对有错；几百到几千条足矣，堆量或追求 SFT 分数反而会压窄探索空间、限制 RL 上限。

3核心

  1. 问题 / 背景：R1-Zero 证明了纯 RL（基座 + GRPO + 规则奖励）也能长出推理能力，但副产物是思维链中英混杂、格式不稳定、可读性差，而这些问题靠规则奖励本身修不干净。R1 正式版因此在 RL 之前插入冷启动 SFT，随之而来的实操问题是：冷启动到底该用多少条？
  2. 机制 / 方法：R1 的四阶段流水线是 ①冷启动 SFT（几千条高质量长思维链，源自 few-shot 提示 R1-Zero 生成再经人工整理，统一格式与可读性）→ ②推理 RL（GRPO + 语言一致性奖励，惩罚中英混杂，略牺牲分数换可读性）→ ③拒绝采样 SFT（用 RL 模型采样筛选正确轨迹造数据再 SFT）→ ④全场景 RL（兼顾有用与无害）。冷启动在其中的作用是三件事：给出 think / 答案标签让规则奖励可解析；教会反思、验证等基本推理模式，使 RL 初期采样组内有对有错（全错则 GRPO 零梯度）；稳定语言分布。
  3. 关键证据 / 数字：R1-Zero 在 AIME 2024 上从 15.6% 涨到 71%，并出现自我反思的「顿悟」现象，说明 RL 的能力增益真实存在、缺的只是格式与可读性。数据量上要区分两个量级：第三阶段拒绝采样造了约 80 万条（60 万推理 + 20 万通用），而冷启动只有几千条。反面约束是：SFT 数据过多、训得太久会把输出分布拉窄，RL 采样只剩 SFT 教过的模式，探索空间变小、上限受限；2026 年多项研究反复验证「SFT 分数越高，模型可塑性越差」。更底层的视角来自 OctoThinker：基座在中期训练阶段是否见过数学语料、问答格式与长思维链，决定了它对 RL 是否友好，这一点冷启动替代不了。
  4. 结论 / 判断：冷启动的停止标准不是 SFT 分数，而是功能性的——RL 前 100 步内格式合规率过 90%、组内奖励方差不为零，即可停手转入 RL。小模型与 base 模型起步尤其依赖冷启动（直接 RL 初期连格式都学不会、一组采样全错、根本点不着火），instruct 模型起步差别则小得多。

5可迁移

  • 做推理 RL 流水线时，把冷启动当「点火器」而非「预训练」来调：数据选强模型蒸馏或自采样筛选、格式统一、答案正确、长度适中，并用组内方差与格式合规率做监控指标，而不是盯 SFT 评测分。
  • 面试答这道题的骨架：纯 RL 的能力与缺陷 → 四阶段流水线中冷启动的三项功能 → 「太多反而限制上限」的分布拉窄机制 → 基座中期训练决定 RL 友好度，冷启动不可替代。

6疑问 / 下一步
