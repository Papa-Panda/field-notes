## 一句话总结
训短推长会崩是因为位置编码在未见过的长位置上失控、困惑度悬崖式暴涨；解法归为四类——改注意力偏置、给位置编码做缩放、只看局部窗口、或用长文本继续训练。

## 核心
1. 问题/背景：训练窗口固定在几千 token，推理却想塞入 32K 甚至 128K；训练长度之外的位置模型从未见过，注意力分数随之乱套，困惑度在越过训练长度的一刻悬崖式上升。
2. 机制/方法：四条路线各有取舍。① 改偏置：ALiBi 不给位置编号，直接按词间距离对注意力加线性惩罚，惩罚只依赖距离这条直线，可自然向外延伸，天生能外推；② 位置缩放：PI 把超长位置编号按比例压回训练范围，NTK 与 YaRN 在此基础上高频少压、低频多压，压得更聪明也更省微调；③ 局部窗口注意力：每个词只看固定窗口内的邻居，距离永远不超过窗口，外推问题被绕开；④ 长文本继续训练：不做翻译，直接让模型见过长位置。
3. 关键证据或数字：核心判据是困惑度曲线——未处理时在训练长度处直接起飞；工程落地通常只需设缩放类型与倍数，再补一轮长文本微调几千步窗口即可稳撑到十几万 token。
4. 结论/判断：一句话直觉——要么让模型见过长位置，要么把长位置「翻译」回它见过的范围；四类方法是这一直觉的不同实现。

## 可迁移
- 这是 RoPE 之后的面试必问链：先讲清崩的机理（未见位置 → 注意力失控 → 困惑度爆炸），再按四类报菜名，比只背 YaRN 完整得多。
- 实际选型时，窗口注意力与缩放法可叠加长文本续训，组合拳通常比单一招数更稳。
