2一句话总结

单个神经元多义不是模型在捣乱，而是特征数远超维度、被叠加塞进同一空间的结果；SAE 用一个过完备的稀疏编码层加 L1 约束，把中间层激活拆成少数只对单一概念响应的方向，让内部表示第一次可读。

3核心

  1. 问题/背景：逐个看神经元会发现同一个神经元对法语、代码 bug、DNA 等毫不相关的输入都会激活，无法判断它到底编码什么概念。
  2. 机制/方法：根源是 superposition——模型要表示的特征数远多于可用维度，只能把多个特征以近似正交的方向叠加进同一空间，每个神经元被迫复用。SAE 的做法是把中间层激活向量送进一个维度远大于原空间（可达数万到上百万）的编码层，再解码重建原激活；损失由重建误差加 L1 稀疏项组成，L1 逼迫绝大多数特征激活归零，只留下少数真正相关的，从而每个保留下来的方向只对一个概念响应。
  3. 关键证据或数字： $f = \mathrm{ReLU}(W h + b)$ 编码、再线性解码重建；Anthropic 在 Claude Sonnet 上实际解出了上百万个可读特征，覆盖具体城市、安全相关、谄媚、不诚实等概念，每个都能对应到一个具体方向。
  4. 结论/判断： $\lambda$ 是可读性与重建质量之间的旋钮——调大更稀疏更可读但重建变差，调小则特征重新混杂。SAE 是事后外挂的探测工具，不改变原模型权重；找到特征后还可通过钳制其激活高低来 steer 模型行为，与 activation steering 衔接。

4关键数字

项 值
编码层维度 远大于原激活维度，可达数万至上百万
Anthropic 解出的可读特征量级 上百万个

5可迁移

  • 面试被问「神经元多义」时，标准答法是 superposition 假说 + SAE 用 overcomplete dictionary 加 L1 做稀疏分解，而不是把多义当 bug。
  • 做可解释性或行为干预时，SAE 特征钳制是 activation steering 的一条现成路径，可用于抑制谄媚、欺骗类行为方向。

6疑问 / 下一步

  • SAE 拆出的特征在多大程度上是模型真实使用的计算单元、而非重建视角下的伪影，仍需用因果干预实验逐个验证。
