## 一句话总结
不靠大模型蒸馏，用代码验证的思维链、MCTS 搜索和过程偏好模型三件套滚动自我进化四轮，7B 模型在 MATH 上从约 58.8 分刷到 90 分、反超 o1-preview。

## 核心
1. **问题/背景**：小模型学数学推理通常靠蒸馏强教师的解题过程，但学生的能力上限被教师锁死，教师不会的题学生永远学不会。
2. **机制/方法**：三件套互相咬合——① 代码增强的思维链：每一步推理都配一段可运行的 Python 并实际执行，跑通且结果对才保留这一步，从源头过滤「看着顺、中间算错」的步骤；② 蒙特卡洛树搜索：以题目为树根逐层展开候选步骤，按能走通到正确答案的频率给节点打 $Q$ 值，连起高分节点得到优质轨迹当训练数据；③ 过程偏好模型：给每步打精确绝对分太难标注，于是从 $Q$ 值里取最高分与最低分步骤凑成偏好对，只学「这一步比那一步好」，训练出能给后续搜索当向导的裁判。
3. **关键证据或数字**：三件套串成自举循环——搜索生成轨迹 → 训练更强的模型与更准的裁判 → 更强的模型再搜索出更好的轨迹，如此滚动四轮；在 MATH 上从 58.8 分提升到 90 分，反超 o1-preview 约 4.5 个百分点；在美国数学邀请赛（AIME）难题上平均做对 8 题，约达顶尖高中生前 20% 的水平。
4. **结论/判断**：可验证的过程信号（代码执行 + 搜索 $Q$ 值）能替代人工标注和强教师，小模型的推理上限远高于蒸馏范式给的预期，但前提是任务本身可验证、搜索算力足够。

## 可迁移
- post-training 数据合成：能自动验证的任务（代码执行、形式化检查、终局答案）可以让搜索 $Q$ 值充当免费的过程级标注，偏好对构造比绝对打分更便宜、更稳。
- RL infra：MCTS 轨迹生成 + 多轮自举是一个典型的「生成—筛选—训练」闭环，轨迹质量（而非数量）决定每轮增益，infra 上要把验证器吞吐和搜索并发当一等公民。
