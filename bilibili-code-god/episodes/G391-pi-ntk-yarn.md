## 一句话总结
长度扩展的演进主线是「按频率区别对待」：PI 把位置均匀压回训练范围，NTK 高频少压、低频多压，YaRN 再分段处理并加注意力温度补偿，几乎不训练就能把 32K 稳扩到 128K。

## 核心
1. 问题/背景：RoPE 像一排转速不同的表盘——高频分量区分相邻词、低频分量刻画远程关系；只在 32K 内训练的模型面对十几万位置时，表盘转到从未见过的角度组合，输出随即崩坏。
2. 机制/方法：PI 直接把超长的位置索引按比例线性压缩回训练区间（如 128K ÷ 4 落回 32K），简单但均匀压缩挤坏了高频的近处分辨率，需少量微调校准；NTK-aware 改为非均匀缩放——高频少压甚至不压、低频多压，只动 RoPE 底数一处，免训练即可外推一部分；YaRN 把频率维度分三段（高频不动、低频全压、中间平滑过渡曲线衔接），并额外缩放注意力温度，补偿长上下文下注意力被稀释的副作用。
3. 关键证据或数字：直接硬外推时困惑度一过 32K 就急剧飙升；用 YaRN 扩展后从 32K 到 128K 困惑度保持平稳。工程开启成本极低：配置缩放类型、缩放系数（示例为 4）、原始长度 32K，再以极少量长文本微调。
4. 结论/判断：三种方法画在「频率—压缩量」图上分别是平线、斜升曲线、分段曲线；频率维度分工不同，扩长度就必须区别对待，YaRN 是当前主流方案。

## 可迁移
- 面试答长度扩展时，用「高频管分辨率、低频管远程」这条主线串 PI → NTK → YaRN，比罗列方法名更有说服力。
