2一句话总结

激活导向（activation steering）发现「诚实、拒绝、情绪」这类行为在模型内部近似对应残差流中的一个方向向量：用正反样本的激活差把这个向量求出来，推理时按系数加回去，就能在不训练、不改权重的前提下调节模型行为——但系数过大必然伤能力。

3核心

  1. 问题/背景：微调改行为成本高且不可逆；prompt 控制又不可靠。线性表示假设（linear representation hypothesis）认为高层概念在激活空间中近似线性编码，于是有了第三条路：直接在推理时干预中间激活。

  2. 机制/方法：三步。①求方向：构造对比样本对（如诚实回答 vs 欺骗回答、目标行为的正/负例），分别跑模型收集某层残差流激活，取两组激活均值之差并归一化，得到方向向量 $v$（CAA 的做法；ActAdd 更简单，用一对对比 prompt 即可）。②注入：推理时在选定层的残差流上做 $h \leftarrow h + \alpha v$ ，其中 $h$ 为该层隐藏状态， $\alpha$ 为 steering 系数，正负号决定推向行为的哪一端，干预可作用于每个 token 位置或部分层。③调参：在验证集上扫 $\alpha$ 与注入层，在行为强度与通用能力之间找平衡点。ITI 则更细粒度：先用探针找出与真值性最相关的注意力头，只对这些头做干预。

  3. 关键证据或数字：ITI 在 LLaMA 上报告将 TruthfulQA 的真实回答率显著提升（论文口径从约 32.5% 提升到约 65.1%）；CAA 表明在多个行为维度（谄媚、拒答倾向等）上，较大的 $\alpha$ 能单调改变行为发生率，同时在 MMLU 等能力基准上开始出现可测的下降——即「强度—能力」权衡曲线是这类方法的统一图景，具体数值依模型与任务而变。

  4. 结论/判断：激活导向是低成本、可撤销的行为控制手段，适合做对齐探针、快速原型与安全兜底；但它调的是线性近似的方向，不是删除或新增能力，不能替代训练， $\alpha$ 过强会普遍损害流畅度与能力，使用前必须扫权衡曲线。

4可迁移

  • RL 训练出现 reward hacking 或拒答率漂移时，可先用 steering 做快速归因实验：若某个行为方向能被线性向量显著调动，说明问题更多在表示/数据而非能力缺失，再决定是否回炉训练。
  • 面试可迁移点：能讲清 CAA 求向量的流程（对比样本 → 激活均值差 → 归一化）、注入公式与 $\alpha$ 的权衡，是 representation engineering 方向的标志性问答。

5疑问 / 下一步

  • steering 向量的跨模型、跨语言可迁移性与「多行为向量互相干扰」问题尚无定论；且方向往往只在分布内有效，OOD 输入下效果衰减需实测。
