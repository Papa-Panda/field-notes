## 一句话总结

标准 SFT 对每个 token 等权，单参考答案下模型会去背措辞而非学逻辑；Rho-1 与 ProFit 选 token 的方向相反、目标一致——loss 应算在信息上，不算在措辞上。

## 核心

1. 问题/背景：一条参考答案里一半是逻辑、一半是措辞（如「我们可以看到」「显然」可任意替换而不改意）。SFT 对回答每个 token 算交叉熵取平均、权重相同，全学等于给某一种说法加分，loss 降了能力没涨，即表面过拟合。
2. 机制/方法：两条路线。Rho-1：先用在高质量数据上训过的参考模型给每个 token 算超额损失（训练模型 loss 减参考模型 loss）；超额大说明「参考模型会、你还不会」，是有信息增量的 token，只在排名靠前的 token 上算 loss。ProFit：方向相反，其观察是 token 概率与语义重要性相关——模型给高概率的往往是核心逻辑框架，低概率的往往是可替换表达；SFT 前用当前模型前向一遍，把低概率 token 从 loss 里 mask 掉，只学高概率核心部分。
3. 关键证据或数字：Rho-1 在数学继续预训练上少样本最高涨 30 个点，MATH 上 1B 达 40.67%、8B 达 51.8%，只用 3% 的预训练 token 追平 DeepSeekMath，15 个通用基准平均 +6.8。ProFit 不用多条参考答案，在通用推理与数学基准上稳定优于标准 SFT（摘要未给保留比例，实操 60%–70% 是常见起点，需自调）。
4. 结论/判断：看似打架，实为两个阶段的两个目标：Rho-1 面向预训练/继续预训练，找有信息增量的 token、把算力花在没学会的东西上；ProFit 面向 SFT，去措辞噪声、防单一答案的表面过拟合。两者与 prompt 是否算 loss、think 段是否 mask、多轮只算最后一轮等同属一个「loss 配置家族」，都在回答哪些 token 该学。

## 关键数字

| 方法 | 设置 | 结果 |
|---|---|---|
| Rho-1 | 仅 3% 预训练 token | 追平 DeepSeekMath；MATH 1B 40.67% / 8B 51.8% |
| Rho-1 | 15 个通用基准 | 平均 +6.8 |
| ProFit | mask 低概率 token | 通用推理/数学稳定优于标准 SFT |

## 可迁移

- 实操三条：两个方法都要多一次前向拿 token 概率或损失（成本是训练前一次离线打分）；阈值/保留比例要调，短回答、格式、代码这类每个 token 都关键的任务谨慎 mask；面试被问「SFT 过拟合怎么办」，除加数据外可答选 token。
- 与本人数据 curation 主线衔接：token 级选择是样本级筛选的下一层粒度，可与难度筛选叠加。
