## 一句话总结

三兄弟的分野就一条主线：用什么标准选划分特征——ID3 看信息增益、C4.5 看信息增益率、CART 看基尼指数，一代比一代更工程化，最终 CART 成了工业界默认。

## 核心

1. **问题/背景**：决策树就是一棵 if-else 规则树，训练的核心问题只有一个：每个节点选哪个特征来划分，才能让子节点尽快变「纯」。这需要一个纯度量化的工具，起点是信息熵——熵越大越混乱，熵为零表示完全纯净。
2. **机制/方法**：ID3 用信息增益（父节点熵减去子节点熵的加权平均）选特征，但它系统性偏爱取值多的特征：极端地拿样本 ID 当特征，每个子节点都纯净、增益拉满，树却毫无泛化。C4.5 把增益换成增益率——增益除以特征自身的固有熵（衡量取值分散程度），取值越多惩罚越大，正好抵消这种偏好；同时补上了连续特征二分、缺失值加权等工程能力。CART 换用基尼指数（1 减去各类概率平方和，越小越纯）选划分后加权基尼最小的特征，并且是严格二叉树，每个节点只做是/否判断；同一框架换上平方误差就能做回归。
3. **关键证据或数字**：视频用 14 天打球数据的例子对照：按天气划分信息增益约 0.246、按湿度约 0.151，ID3 选天气；而 ID 特征增益虽最大，其固有熵也最大，增益率被压到很低，C4.5 仍选天气——一个小例子同时演示了缺陷与修复。
4. **结论/判断**：结构上 ID3/C4.5 是多叉树、CART 是二叉树；任务上只有 CART 分类回归通吃；连续与缺失值上 ID3 都不支持、后两者都支持。所以 sklearn 的决策树、随机森林、XGBoost、LightGBM 的基学习器清一色是 CART：结构简单、计算高效、任务统一。

## 关键数字

| 划分标准对照 | 熵/纯度工具 | 偏好问题 |
|---|---|---|
| ID3 信息增益 | 信息熵 | 偏爱多取值特征 |
| C4.5 信息增益率 | 信息熵 + 固有熵 | 用固有熵惩罚多取值 |
| CART 基尼指数 | 基尼不纯度 | 无此类偏好，计算更省 |

## 可迁移

- 面试问「决策树怎么选特征」，默认答基尼指数并带出三兄弟演进史，是最稳妥的答法；被追问 ID3 缺陷时，用「ID 特征」这个极端反例一击说清。
- 对 post-training 的视角：梯度提升树至今仍是表格数据与打分排序（如 RM 评估、数据质量打分）的强基线，理解 CART 是读懂 XGBoost/LightGBM 的前置知识。
