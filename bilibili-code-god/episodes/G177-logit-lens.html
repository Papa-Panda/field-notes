2一句话总结

Logit Lens 把每一层的 hidden state 直接过 LM head 映射回词表，像 X 光一样逐层看模型「在哪一层想出答案」，借此判断训练到底改善了中间表示还是只动了输出映射。

3核心

  1. 问题/背景：模型给出正确答案时，我们不知道它是在哪一层算出来的，也不知道一轮 SFT/RL 之后变好的究竟是内部表示还是最后的读出。
  2. 机制/方法：对每层的 hidden state 乘 LM head 权重矩阵、做 softmax 得到该层的预测分布，看 top-1 预测随层数的演化，并画「层号 × 预测 token」图。通常浅层偏语法与噪声、中层形成语义、深层落到具体答案。
  3. 关键证据或数字：经验观察是大模型的推理往往在前 $70\%$ 的层就已完成，后面的层主要做精化与验证；正确答案首次出现的那一层，就是该任务的推理实际发生位置。
  4. 结论/判断：训练诊断的用法是对比训练前后各层的预测分布：如果训练后中间层预测也变准，说明表示被真正改善；如果只有最后一层变了，训练只是微调了输出映射、没压实能力。推论是某些任务上可考虑冻结「答案已出现层」之后的参数来省训练成本。

4关键数字

项目 数值
推理大致完成位置 前 $70\%$ 层
诊断对比维度 训练前 vs 训练后，逐层 top-1 预测

5可迁移

  • 这是可解释性工具落到训练诊断的典型例子：RL/SFT 后能力没涨时，用 logit lens 定位到底是表示没动还是读出没对齐，能区分「没学到」和「学了但没表达出来」两类问题。
  • 与按层冻结、逐层学习率等 infra 手段相连：先知道能力在哪几层形成，再决定冻哪几层、哪几层给大学习率。

6疑问 / 下一步

  • 中间层 hidden state 与最终层的分布并不对齐，直接套同一个 LM head 会有系统性偏差；Tuned Lens 用逐层仿射探针对齐，这个修正对结论影响多大，值得实测。
