## 一句话总结
Chameleon 把图片也切成离散 token、与文字共用同一词表和同一个 Transformer 从头训练（早融合），代价是训练极易发散，靠 QK-Norm 等稳定化手段才跑通；主流 LLaVA 式则是视觉编码器外接现成语言模型的后融合。

## 核心
1. **问题/背景**：多模态模型怎么把图和文合起来有两条路线。后融合（LLaVA 一类）不动训好的语言模型：图片经独立视觉编码器（如 CLIP）压成向量，再由投影层翻译成语言模型能读的形式塞进输入——两套系统只在接口处对接，工程简单、可复用现成模型，但融合只发生在浅层接口。
2. **机制/方法**：早融合分三步——先用类似 VQ-VAE 的图像分词器把图切块、每块匹配码本中最近的视觉基元编号，一张约 512 像素见方的图变成 1024 个离散视觉 token；再把视觉 token 与文本 token 并入同一张大词表（文本词表加 8000 多个图像码），图文混排内容被拉平成一条交错序列；最后用同一个 Transformer 从头训练，目标就是预测下一个 token、不分图文，生成时也能任意交错地写字与出图。
3. **关键证据或数字**：两种 token 分布脾气完全不同——文本规整、图像变化剧烈——混训时注意力数值容易失控、损失发散。Chameleon 的解法是给注意力的 query、key 各加归一化（QK-Norm），并调整归一化层位置把数值摁住，才让从头共训真正跑通。
4. **结论/判断**：后融合是后期拼装、早融合是从头共生；早融合的融合深度和交错生成能力更强，但把训练稳定性成本前置到了自己身上。

## 关键数字
| 项目 | 数值 |
|---|---|
| 一张 ~512px 图的视觉 token 数 | 1024 |
| 统一词表中的图像码数量 | 8000+ |
| 稳定化关键手段 | QK-Norm + 归一化层位置调整 |

## 可迁移
- 面试问「早融合 vs 后融合」：按融合发生的位置（输入层 vs 接口层）、是否共用参数、能否交错生成三条线对比，再补一句早融合的训练稳定性代价。
- QK-Norm 是跨主题的通用稳定化技巧：任何注意力数值易爆的场景（长上下文、混合模态）都可以优先想到它。
