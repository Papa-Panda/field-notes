## 一句话总结

防灾难性遗忘的三条路线按侵入性递增排：先上经验回放兜底，不够叠 EWC 锁重要参数，要彻底隔离就每任务一个 LoRA adapter、主干冻结。

## 核心

1. 问题/背景：模型要持续学新数据新能力，但直接在新数据上微调会灾难性遗忘——旧能力断崖式下跌。持续学习的目标是学新不忘旧。
2. 机制/方法：经验回放是在新数据里混入 10%–20% 旧数据边学边复习，最简单也最稳，代价是旧数据存储；EWC 用 Fisher 信息矩阵找出对旧任务最重要的参数，训新任务时约束这些参数别动太多；渐进式网络给每个新任务分配新模块、旧模块冻结，零遗忘但网络无限膨胀，大模型上借其思路改为每任务训一个独立 LoRA adapter。
3. 关键证据或数字：回放比例经验值 10%–20% 就能顶住大半遗忘；三条路线分别对应数据层、参数层、结构层三种隔离粒度。
4. 结论/判断：落地按台阶走——默认起点是 replay；回放后旧任务准确率还在跌就叠 EWC；多任务且要求互不干扰就走 adapter 路线。全程定期在旧任务验证集上评估遗忘程度，别只看新任务分数。

## 可迁移

- 后训练里的「学新能力掉旧能力」就是同一问题：继续 SFT/RL 时混入旧分布回放数据是最便宜的防退化手段，adapter 隔离则适合多客户/多域并行迭代的场景。
- 面试答持续学习按「数据回放 → 参数约束 → 结构隔离」的谱系讲，并点明各自代价（存储、Fisher 计算、参数膨胀），比单列方法名完整。
