2一句话总结

随机初始化的大网络里藏着一张稀疏「中奖彩票」子网：只要把保留连接重置回最初的初始化值再单独训练，它就能用相近步数追平大网络精度——结构与初始化缺一不可。

3核心

  1. 问题/背景：剪枝通常被当作训后压缩手段，被剪剩的小网络若随机初始化单独训，往往达不到大网络精度；但有一类特殊小子网可以做到，差别不在结构本身。
  2. 机制/方法：四步找彩票——正常训练大网络 → 按权重绝对值剪掉最弱连接 → 把保留连接的权重重置回训练前的原始随机初始化 → 只训子网。实践中用迭代剪枝：每轮只剪一小部分、重置、再训练，反复挖出更稀疏的子网。
  3. 关键证据或数字：可只保留约 10% 量级的参数而精度不降反升；同一稀疏结构换一套新的随机初始化则收敛更慢、精度明显差一截，证明「中奖」靠的是结构 + 那套初始值，而非结构单独成立。
  4. 结论/判断：一个网络能否训好，在初始化那一刻就已被很大程度决定；训练的过程某种意义上是在把中奖彩票从大网络里挑出来。

4可迁移

  • 面试答彩票假设按「剪枝 → 重置回初始化（不是重随机）→ 单独训练达标」这条链讲，并点明迭代剪枝挖更稀疏彩票。
  • 对 post-training 的启发：稀疏子网视角可迁移到 LoRA / 剪枝后微调的初始化选择——起点权重本身就是信息，不只是待优化的变量。

5疑问 / 下一步

彩票假设在 LLM 规模上是否仍成立、以及能否不训大网络就直接定位中奖子网（early-bird 类方法），值得查最新证据。
