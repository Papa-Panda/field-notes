## 一句话总结

把多个同源 checkpoint 的权重逐参数平均，免训练就能得到比任何单个模型更好的模型，前提是它们来自同一个预训练权重、落在同一个损失盆地里。

## 核心

1. 问题/背景：手里有多个 checkpoint（不同种子训出的模型，或同一过程的不同阶段），能否不花训练成本把它们合成一个更好的模型？
2. 机制/方法：Model Soup 直接对权重做逐参数平均。原理是 loss landscape 在最优解附近较平坦，不同模型收敛到平坦区的不同点，取平均相当于取中心点，更稳定、泛化更好。三种炖法：uniform soup（不同种子训完直接全平均）、不同数据微调后的平均、greedy soup（按验证分数排序，逐个加入，只保留让分数提升的成员）。
3. 关键证据或数字：落地流程是训多个/存多个 checkpoint → 逐个在验证集评估 → 选高分者平均 → 再评估 soup，不行就换 greedy soup。
4. 结论/判断：唯一硬性前提是所有模型同源（同一预训练权重）；不同底座的权重对不齐，平均出来是废的。首选 greedy soup，通常最优且性价比极高。

## 可迁移

- 多次 SFT/RL 实验的 checkpoint 别急着删，先试 greedy soup，零训练成本换一波免费的分数。
- 面试被问模型合并时，关键句是「同盆地才能平均」——权重平均有效的前提是线性模式连通性，不同初始化的模型不在同一盆地。

## 疑问 / 下一步

- RL 训出的多个 checkpoint 做 soup 时，行为风格（如回答长度）会不会也被平均掉，值得实测。
