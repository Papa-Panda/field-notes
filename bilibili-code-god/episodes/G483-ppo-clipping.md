## 一句话总结

朴素策略梯度步子一大就会练崩，PPO 的 clip 把新旧策略概率比夹在 $1 \pm \varepsilon$ （常取 0.2 ）之间、超出部分梯度归零，相当于给每次更新装一条涨跌幅 ±20% 的安全带。

## 核心

1. **问题/背景**：SFT 是逐字模仿标准答案，但「哪个回答更好」根本没有标准答案；RL 换思路：模型自己写、评委打分、朝高分方向改。可朴素策略梯度有个大坑——一步更新过猛，模型输出直接变乱码且再也救不回来。
2. **机制/方法**：定义概率比 $r$ 为新策略概率除以旧策略概率（ $r = 1.3$ 即该词概率涨了 30%）。PPO 把 $r$ 夹在 $1 - \varepsilon$ 到 $1 + \varepsilon$ 之间：好动作的奖励封顶（涨到上限不再给梯度，防贪心），坏动作的惩罚封底（防改过头）。公式里的优势 $A$ 由专门的 Critic 价值网络估「平时水平」，实际减预期就是这一步的真实贡献，再配合 GAE 把功劳摊到每个 token。
3. **关键证据或数字**： $\varepsilon$ 通常取 0.2 ，即单步概率涨跌幅限制在 ±20%；对比曲线里大步更新冲高后一头栽下悬崖，小步更新稳稳上升。完整 RLHF 是四步循环：Actor 生成 → Reward Model 打分并扣 KL 罚分（防偏离原版太远刷分说胡话）→ Critic + GAE 算优势 → 带 clip 小步更新。
4. **结论/判断**：PPO 名字里的 Proximal（近端）就是这条安全带的含义——大胆试错、小步改进；InstructGPT/ChatGPT 正是这套四模型循环练出来的。

## 关键数字

| 项 | 取值/说明 |
|---|---|
| clip 范围 $\varepsilon$ | 通常 0.2（概率比限制在 0.8–1.2） |
| 超出 clip 的部分 | 梯度归零，不再推动更新 |
| RLHF 循环 | Actor 生成 → RM 打分 + KL 罚 → Critic/GAE 算优势 → clip 更新 |

## 可迁移

- 面试讲 PPO 别只背公式：先讲「步子大了练崩」的失败模式，再讲 clip 是对概率比的涨跌幅限制、封顶与封底分别防什么，机制感立刻出来。
- 自己调 GRPO/PPO 时，clip 范围是第一批要看的超参之一：训练早期 loss 或熵异常跳变，优先怀疑步子过大、clip 太松。

## 疑问 / 下一步

- GRPO 砍掉 Critic 后优势改用组内相对值，clip 机制原样保留——组内优势的高方差与 clip 的相互作用（比如 DAPO 的 clip-higher）值得接着看进化史那期（G485）。
