## 一句话总结
WSD 把学习率拆成预热、稳定、衰减三段：中间稳定段是一条不指向任何终点的高位直线，可任意延长、随时收尾，从根本上解开了 cosine 必须预设总步数的枷锁。

## 核心
1. **问题/背景**：cosine 退火的曲线形状被终点死死绑定，开训前必须算死总步数；中途想加数据续训，整条曲线推倒重画；想要多个不同规模的模型，每个都要从头设曲线从头训，算力白白烧掉。
2. **机制/方法**：三段式——预热段从 0 线性爬到峰值（与普通 warmup 相同）；稳定段顶在最高位平推，不奔向任何终点，想走多长走多长；衰减段在决定收尾时才启动，短时间内把学习率快速压下去。稳定段的 checkpoint 是「现成的好料」，可分叉出多条衰减分支：早衰减得小模型，晚衰减得大模型，一条主线喂出多个规模。
3. **关键证据或数字**：稳定段看似 loss 降得慢，真正的性能跃升压在衰减段的「临门一脚」——衰减一拉，loss 急剧下降、性能窜升一截；分叉复用省去每个规模从头重训的算力。
4. **结论/判断**：WSD 与 warmup 不是一回事——warmup 只是开场升温的一小段，WSD 是从开场到收尾的完整三段式调度。适合训练计划不确定、需要多规模产出或边训边决策的场景。

## 可迁移
- 自己跑 post-training 实验时，若总步数未定或想从同一 checkpoint 分叉不同配方，优先 WSD：稳定段存档 + 短衰减收尾，比每个实验各设一条 cosine 便宜得多。
- 面试高频问法「WSD 为什么能随时停」：答稳定段不依赖终点、衰减段独立且短促，收尾时机由人决定而非曲线决定。
