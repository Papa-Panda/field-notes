## 一句话总结

进化策略（ES）放弃逐 token 梯度，改为对全参数加扰动、按整条轨迹奖励加权平均来更新：梯度估计方差不随轨迹长度增长、显存只需推理量级，并且涨 pass@1 的同时不掉 pass@k。

## 核心

1. **问题/背景**：策略梯度（PPO/GRPO）要存激活、要旧策略的 log-prob、多轮 Agent 还要做重分词和逐轮信用分配，长程任务尤其难训。2025 年 8 月两篇论文把进化策略这个老方法重新请回大模型 Agent 训练。
2. **机制/方法**：ES 以当前参数为中心撒出若干随机扰动，每个扰动是一个「分身」，各自把任务完整跑一遍拿到标量总分；分数标准化后，按分数加权平均扰动方向即得更新方向。全程只有前向，噪声只存随机种子。方差账是关键：策略梯度把每步动作的分数累加，方差大致随步数 $H$ 线性增长；ES 对整条轨迹只用一个标量打分，方差与 $H$ 基本无关。附带好处是不用重分词、不用给工具返回打 mask、不用逐轮分功劳。
3. **关键证据或数字**：Qwen3.5-27B 在 WebArena Lite 上从 29.47% 涨到 36.16% ；长程数独任务在 $H = 15$ 时 ES 以 53.13% 反超 GRPO 的 40.63% ，且耗时 9.4 小时对 19 小时；4B 模型显存从 58.9G 降到 8.4G（省约 86%）。公平对比（算力对齐）下 GRPO 把 pass@1 拉高却让 pass@32 从 96.4 掉到 95.3 ，ES 两项都涨；且 ES 的参数漂移是 GRPO 的约 40 倍却不遗忘——因为绝大部分更新幅度极小，真正的大更新集中在 LayerNorm 权重和注意力投影上。两者还能接力：先 GRPO 后 ES 可兼得 pass@1 与 held-out 上的 pass@k。
4. **结论/判断**：ES 不是「省显存版 GRPO」，而是另一种优化器：pass@1 涨幅通常不如 GRPO，但在长程、只看 pass@k、显存受限的场景下有结构性优势；种群规模是关键超参（小模型上翻倍收益大、大模型上不敏感）。

## 可迁移

- Agent RL 选型：轨迹越长、奖励越稀疏（只有终局分），ES 的方差优势越明显；反之短程密集反馈仍是策略梯度的主场。
- 「GRPO 涨 pass@1 掉 pass@k」是可迁移的诊断框架：任何 RL 配方都应同时报 pass@1 与 pass@k，警惕分布收窄。
