## 一句话总结

DPO 的成败在训练之前就由偏好数据决定：三元组的质量差距必须明显，三种生产方式各有取舍，四个质量陷阱必须逐项过滤。

## 核心

1. **问题/背景**：DPO 需要 (prompt, chosen, rejected) 三元组，模型靠好坏回答的对比学方向；若两者质量接近，梯度里没有可学的信号，这也是很多人做不下去 DPO 的第一道关卡。
2. **机制/方法**：三种生产方式——人工标注质量最高但贵且慢，只适合做小规模金标准；用 GPT-4 给同 prompt 的多个采样回答打分排名、最高分作 chosen、最低分作 rejected，是当前主流（UltraFeedback 即此路线）；on-policy 采样用当前模型自己的输出再标注，分布与模型完全一致、修正最有针对性，但要反复采样标注、工程最复杂。
3. **关键证据或数字**：四个致命陷阱——对比度不足（差距太小学不到信号）、错误标注（chosen 实际更差，直接把模型教反）、长度偏差（chosen 总是更长，模型学到的是变长不是变好）、位置偏差（chosen 总在前面，模型学位置不学质量）。
4. **结论/判断**：推荐五步实操流程：先跑一轮 on-policy 采样拿真实输出 → GPT-4 批量打分排名构造对子 → 过滤对比度不足的对 → 检查长度偏差 → 留 10% 做人工抽检守住质量底线。偏好数据宁可少不可差。

## 可迁移

- 做 DPO/偏好数据时先建质检清单：对比度过滤 + 长度偏差检查 + 抽检，比堆数据量重要得多。
- 面试被问偏好数据构造时，按「人工金标准 / 强模型合成 / on-policy 采样」三档成本-质量谱系回答，再补四个陷阱。
