2一句话总结

扩散模型就是一个层数极多的分层 VAE：前向加噪是写死的固定编码器、反向去噪是学出来的解码器、训练目标是证据下界；而预测原图、预测噪声、预测分数只是同个去噪方向的三种坐标，彼此线性换算、数学等价，差别只在损失权重与数值稳定性。

3核心

  1. 问题/背景：扩散、VAE、分数匹配三套理论各写各的公式，看似毫不相干；扩散内部又有预测原图、预测噪声、预测分数三种练法，初学者很容易当成三件不同的事。
  2. 机制/方法：换个角度看前向加噪链——它把原图编码成一串越来越模糊的中间产物（隐变量），且每步加噪量由固定配方决定、没有任何可学参数，就是一个不用训练的编码器；反向过程则是配套的、需要训练的解码器。固定编码器 + 学习解码器 + 一长串隐变量，正是分层 VAE 的结构，训练目标随之统一为该分层模型的证据下界（ELBO）。
  3. 关键证据或数字：网络每步真正要学的是一个去噪方向，而这个方向有三种等价描述：指向终点（原图 $x_0$ ）、指向过程（加入的噪声 $\epsilon$ ）、指向概率密度上升最快的梯度（分数）。给定当前噪声图与步数，三者之间是确定的线性换算：知噪声可反推原图，分数不过是噪声乘上一个负系数，没有信息损失，学任何一个都是在学同一件事。
  4. 结论/判断：三种预测目标的取舍是工程问题而非对错问题：对应损失的加权不同、数值稳定性不同——噪声大时预测噪声更稳，噪声小时预测原图更准，后来预测速度（v-prediction）是折中。面试和读论文时先把它们放回同一张图，再讨论各自的加权细节。

4关键数字

视角 对应物
前向加噪 固定（无参数）编码器
反向去噪 可训练解码器，层数 = 扩散步数 $T$
三种预测目标 $x_0$ / $\epsilon$ / 分数，线性互换、无信息损失

5可迁移

  • 面试被问「扩散和 VAE 什么关系」「为什么 DDPM 预测噪声」时，用「分层 VAE + 三种坐标等价」一张图回答，比背公式更有说服力。
  • 读扩散类论文时先定位它选了哪种参数化与加权，能快速判断其贡献是新机制还是数值稳定性的工程改进。
