## 一句话总结

RL 训练早期的熵坍塌源于策略梯度中的协方差项：高概率又高奖励的 token 被持续正强化、分布迅速变尖，解法是 Clip-Higher 与 KL 约束这类「别让模型太早太狠自我强化」的手段。

## 核心

1. **问题/背景**：RLVR 训练刚开始没多久，策略熵就断崖式下跌，模型早早变得过度自信、不再探索，之后再练也难有进步；实验统计显示绝大部分熵消耗和性能提升都挤在训练最早期，模型极早期就基本定型。
2. **机制/方法**：推导后策略梯度的方向与大小本质上由动作对数概率梯度与优势函数之间的协方差决定。对单个 token：概率高、奖励高时协方差为正，概率被推得更高、其余 token 被挤压，熵下降（这是坍塌主因）；概率低奖励高、或概率高奖励低时协方差为负，反而增熵促探索。训练初期强预训练模型的先验让「随手给出的高概率答案往往就是对的」，高概率与高优势强烈正相关，协方差持续为正，模型只是在反复确认自己已经会的东西。
3. **关键证据或数字**：见下表。解法一是 DAPO 的 Clip-Higher：把 PPO 对称的裁剪拆成两个参数，高概率 token 用较小上界限制其继续被推高，低概率 token 用较大上界留出上涨空间（例如概率 $1\%$ 的 token 放宽后最多涨到 $1.28\%$ ，即 $+28\%$ ）。解法二是 KL 散度约束，不让当前策略偏离太快太远，同样能保住一部分熵。
4. **结论/判断**：熵坍塌是自我强化太猛的结果，解药是保住探索；面试或排障时先看熵曲线掉的速度，再回头查是不是高概率高优势的正相关在驱动。

## 关键数字

| 到 800 步 | 约 $94\%$ | — |

## 可迁移

- 训练监控里熵应和 reward 一起看：reward 在涨但熵已掉完，往往意味着后续步数只是在空转，Clip-Higher（非对称裁剪上下界）是 GRPO/DAPO 排障的第一梯队手段。
- 「梯度 ≈ 对数概率梯度与优势的协方差」这个视角可以迁移到很多 RL 现象的解释：凡是高概率与高优势正相关的场景，都会自发走向分布变尖。
