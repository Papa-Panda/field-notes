## 一句话总结

LSTM 是门控驱动的串行链，BERT 是自注意力搭的全连接图：并行、双向、预训练范式三点差异，决定了 BERT 主攻理解任务、LSTM 留在时序生成的老位置。

## 核心

1. **问题/背景**：两者都是经典 NLP 模型，但底层思路几乎是两个世界，需要一套能快速对比的框架。
2. **机制/方法**：结构上，LSTM 靠遗忘门、输入门、输出门三个门控一格一格传递记忆，是链式接力；BERT 基于 Transformer 编码器，每个词用自己的 Q 与全文的 K、V 算注意力，多头从不同维度捕捉语义，是全连接结构。方向上，LSTM 可单向（生成式，从左往右）也可双向，但信息仍要顺序传递；BERT 是原生双向——预训练用掩码语言模型随机盖住词、同时看左右两侧来猜。
3. **关键证据或数字**：并行性是最硬的分界：LSTM 前后严格依赖、无法并行，序列越长越慢且容易梯度消失；BERT 整段文本一次性并行处理，任意两词直接建立联系，长距离依赖不衰减。范式上 LSTM 没有预训练，往往针对单个任务从头训练、泛化差；BERT 是「海量文本无监督预训练 + 下游微调」的代表，擅长文本分类、命名实体识别、语义相似度等理解任务，代价是自注意力算力需求比 LSTM 大得多。
4. **结论/判断**：选型口诀——需要按时序生成、算力受限用 LSTM 这类顺序模型；做语义理解且能吃下注意力成本，用 BERT 式预训练编码器。这也是 Transformer 取代 RNN 的核心原因：并行 + 任意两词直连。
