2一句话总结

RLHF 三阶段是一条一脉相承的链：1.3 万条人工示范做 SFT 教按指令答，3.3 万条人工排序训出 reward model，3.1 万条提问上用 PPO 往高分优化；靠这三步，13 亿参数的小模型在人类评委那里赢了 1750 亿的 GPT-3，代价是公共任务掉分的「对齐税」。

3核心

  1. 问题/背景：为什么 1.3B 的 InstructGPT 能比 175B 的 GPT-3 更受人类欢迎？因为它多做了三步对齐，而原始大模型只会续写、不会按指令回答。
  2. 机制/方法：三个阶段串联：第一步 SFT，约 1.3 万条提问由人写示范答案，教模型按指令答；第二步训 reward model，约 3.3 万条提问由人对模型输出做排序（细节见 G030）；第三步 PPO，约 3.1 万条提问让模型自己答、RM 打分、往高分方向优化。三个模型同源：reward model 从 SFT 模型改出来，critic 从 reward model 初始化（均为 6B 量级）。
  3. 关键证据或数字：记住三个数即可：SFT 1.3 万、RM 3.3 万、PPO 3.1 万条提问。结论性的对比是：13 亿参数的对齐模型在人类偏好上打赢 1750 亿的未对齐 GPT-3——对齐的杠杆远大于单纯扩参数。
  4. 结论/判断：为什么不能跳过 SFT 直接 RL：原始模型不会按指令答，采样出的回答分不出好坏，PPO 拿不到有效信号。副作用是对齐税——RL 之后公共任务掉分，InstructGPT 的补法是 PPO-ptx：把预训练梯度混进来一起算，混合系数 27.8。

4关键数字

阶段 数据量 做什么
SFT 约 1.3 万条提问 人写示范，教按指令答
Reward Model 约 3.3 万条提问 人排序，训打分模型
PPO 约 3.1 万条提问 模型自答、RM 打分、往高分优化
对齐税补法 PPO-ptx 系数 27.8 混入预训练梯度

5可迁移

  • 面试讲 RLHF 流水线时用「1.3 万 / 3.3 万 / 3.1 万」三个数加「13 亿打赢 1750 亿」一个结论，比泛泛而谈三阶段更有说服力。
  • 理解后续所有简化（DPO 去掉 RM 与 PPO、GRPO 去掉 critic）时，都可以回到这条原始链上问：它砍的是哪一步、省了什么、丢了什么。
