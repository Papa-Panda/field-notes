## 一句话总结

在 SDPA 输出后、输出映射前加一个每头独立、逐元素、由当前 token 算出的 sigmoid 门（仅 +1% 参数），一举破低秩瓶颈、强稀疏过滤无关历史、干掉 attention sink，长文本外推随之大涨。

## 核心

1. **问题/背景**：注意力有三个老大难——输出路径上 V 投影与输出投影两层线性叠乘本质低秩、表达被卡死；首 token 被塞进近半注意力并伴随巨量激活（attention sink），低精度训练不稳；靠固定注意力数值调节 softmax 分母的静态机制在长度外推时跟不上。
2. **机制/方法**：论文系统比较了五个加门位置，结论是在缩放点积注意力的输出之后、最终输出映射之前，加头专属、逐元素的 sigmoid 乘性门效果最好：

$$\mathrm{out} = \mathrm{SDPA}(x) \odot \sigma(x W_g)$$

门由当前 token 计算、逐头独立，本质是给注意力输出配上非线性，像给注意力装了一个激活函数。
3. **关键证据或数字**：门均值仅 0.116 ——约 88% 的注意力输出被直接抑制，只放行极少数关键信息，实现输入相关的动态过滤；困惑度下降 0.2 以上、评测提升 1–2 个点。首 token 注意力占比 46.7% → 4.8% ，最大激活值 1053 → 94 ，sink 被主动过滤取代被动稀释。长度外推实验：上下文 32K → 128K 无需重训，Ruler 基线 31.7 分 vs 门控 58.8 分，领先近 27 分。
4. **结论/判断**：使用配方明确：位置在输出后、映射前；每头独立逐元素 sigmoid ；训练可适当调高学习率吃稳定性红利；兼容 dense/MoE/GQA ；且最好在预训练阶段就加上，后期继续训练补不回训练动态的收益。已成为 Qwen3-Next 性能与鲁棒性的关键支撑。

## 可迁移

- 「在两个线性层之间插非线性破低秩」是可复用的结构诊断套路：凡是投影-投影直连处（如某些 adapter/融合层）都值得检查秩瓶颈。
- attention sink 是长上下文与量化部署的常见坑：部署/评测时若见首 token 吸走近半注意力，先想到这是被动稀释机制在工作，而非模型「偏好」首 token 。

## 疑问 / 下一步
