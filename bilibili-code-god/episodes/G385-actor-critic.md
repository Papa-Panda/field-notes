## 一句话总结

策略梯度不稳定的病根是拿整局回报给每个动作打分、噪声太大；Actor-Critic 用评委的价值估计扣掉基准线得到优势，再叠加多 worker 并行采样去相关，从 REINFORCE 一路演化到 A2C/A3C 与 PPO 共用的骨架。

## 核心

### 1. 问题/背景

策略梯度的朴素目标是让好动作概率变大、坏动作变小，关键在于怎么给动作打分。REINFORCE 的答案是把一整局玩完、用总回报给这局里每个动作统一打分。问题是单局输赢里运气成分太大，信号忽高忽低、方差吓人，训练抖动剧烈甚至崩掉，几乎没人敢直接用。

### 2. 机制/方法

拆成两条腿：演员（actor）是策略网络，只负责根据当前状态选动作；评委（critic）是价值网络，只负责估计当前状态大概值多少分，记作 $V$ 。某个具体动作的价值记作 $Q$ ，真正有用的信号是动作比平均水平好多少，即优势 $A = Q - V$ 。演员每走一步，评委当场反馈，不必等整局结束。更新规则随之变得干净：优势为正就加大该动作概率，为负就压低。再往上加一档并行：一批 worker 各自在独立环境副本里采样、算梯度，汇总更新中央网络；异步更新是 A3C，改成同步整齐更新是 A2C。

### 3. 关键判断（为什么这套有效）

- 优势把动辄成百上千的原始回报，变成围绕零浮动的小数字，信号量级和方差一起降下来。
- 数学上可证明，减去只依赖状态的基准线不改变策略梯度的期望方向——无偏，但抖动小一大截。
- 并行 worker 打破了单轨迹采样前后步高度相关的问题，数据更杂，训练又快又稳。

### 4. 结论/判断

从 A2C、A3C 到今天对齐大模型用的 PPO，骨架都是同一套：演员出动作、评委给优势、用优势加权更新策略，采样—算优势—更新演员—更新评委四步循环。理解这条回路，就理解了大半个现代强化学习。

## 可迁移

- 面试答 PPO/GRPO 时先落回这个骨架：谁是 actor、谁给 baseline、优势怎么算，再谈各算法的改动点，不容易被追问打散。
- 训 RL 时方差治理优先于调学习率：先看 baseline/优势估计是否到位，再怀疑其他环节。
