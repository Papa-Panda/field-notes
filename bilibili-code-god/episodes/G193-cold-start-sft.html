2一句话总结

纯 RL 训出的 R1-Zero 推理能力强但输出不可读，DeepSeek-R1 的解法是在 RL 之前先用数千条高质量长思维链数据做一轮冷启动 SFT——数据量只需千级，关键作用是把输出格式与语言先扶正，让后续 RL 在一个可读、稳定的起点上优化。

3核心

  1. 问题/背景：DeepSeek-R1-Zero 直接在基座模型上用 GRPO 做大规模 RL，跳过了 SFT 阶段，证明了纯 RL 也能自发涌现长思维链和自我反思行为。但其输出存在明显缺陷：可读性差、语言混杂（中英文夹杂）、格式不受控，不适合直接交付用户。

  2. 机制/方法：DeepSeek-R1 改为四阶段流程：①冷启动——收集数千条长 CoT 示例（来源包括用 R1-Zero 生成后由人工标注者后编辑、few-shot 提示生成并经拒绝采样筛选等），先对基座做一小轮 SFT；②推理导向 RL——在冷启动模型上做大规模 RL，并加入语言一致性奖励抑制语言混杂；③拒绝采样 + SFT——用 RL 后的模型生成数据，经拒绝采样构造新的 SFT 集（含推理与非推理数据）再训练；④面向全场景的 RL 对齐。冷启动数据规模刻意保持在千级：足够教会格式与可读性，又不至于用 SFT 锁死 RL 的探索空间。

  3. 关键证据或数字：R1 论文报告，四阶段后的 DeepSeek-R1 在 AIME 2024 上 pass@1 达 79.8%，与 OpenAI o1-1217 相当；作为对照，R1-Zero 经多数投票后在 AIME 2024 可达 86.7%，说明纯 RL 的能力上限并不低，短板主要在输出形态。论文亦明确将「可读性差、语言混杂」列为 R1-Zero 的主要问题，冷启动正是针对这两点。

  4. 结论/判断：冷启动 SFT 的价值不在教知识，而在定形态：少量精选数据决定的是输出的语言、格式与结构，能力增益仍主要来自后续 RL。「先 SFT 定形、再 RL 提能」已成为推理模型训练的事实标准流程。

4可迁移

  • 做推理模型 post-training 时，先评估基座/中间模型的输出可读性与语言一致性；若形态不合格，不必堆大规模 SFT，千级高质量长 CoT 冷启动 + 语言一致性奖励通常就够。
  • 面试高频：能说清 R1 与 R1-Zero 的差别（有无冷启动与后续两阶段）、冷启动数据为何只要千级（定形而非教知识），是理解现代 reasoning 训练管线的标志题。

5疑问 / 下一步

  • 冷启动数据的质量筛选标准（拒绝采样的判据、人工后编辑的比例）对后续 RL 上限的影响有多大，公开材料披露有限，值得结合自有小规模实验验证。
