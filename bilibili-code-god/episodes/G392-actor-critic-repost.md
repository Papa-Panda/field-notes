## 一句话总结

Actor-Critic 给策略梯度加一个价值网络当评委：用优势 $A = Q - V$ 扣掉状态基线只留「比平均好多少」，梯度无偏而方差大降；再靠多 worker 并行采样去相关，A3C/A2C 由此比 REINFORCE 稳得多，这套骨架 PPO 至今沿用。

## 核心

1. **问题/背景**：REINFORCE 判断动作好坏靠整局结束后的总回报，可一局输赢运气成分太大，同一动作这次得高分下次得低分，信号方差吓人，训练抖动甚至崩溃，几乎没人敢直接用。
2. **机制/方法**：拆成两条腿——演员（策略网络）负责在当前状态选动作，评委（价值网络）不选动作、只估计当前状态的平均价值 $V$ 。演员每走一步评委当场反馈，不必等整局结束；更新时不用动作的绝对价值 $Q$ ，而用优势 $A = Q - V$ ：为正就提高该动作概率，为负就压低。数学上减去只依赖状态的基线不改变梯度期望（无偏），却把成百上千的大数值变成绕零浮动的小数值，方差刷地降下来。再加一档马力：多 worker 各自在环境副本里独立采样、计算梯度后汇总更新中央网络——异步版是 A3C，同步整齐更新是 A2C——样本去相关，训练又快又稳。
3. **关键证据或数字**：视频用训练曲线对比直观呈现：REINFORCE 上蹿下跳，Actor-Critic 平稳爬升。训练循环可压缩成四步：采样 → 算优势 → 更新演员 → 更新评委。
4. **结论/判断**：从 A2C/A3C 到对齐大模型天天用的 PPO，骨架都是同一套：演员出动作、评委给优势、优势加权更新策略。理解这条回路，就理解了半壁江山的策略梯度算法。

## 关键数字

| 组件 | 作用 |
|---|---|
| 优势 $A = Q - V$ | 扣基线、无偏、方差大幅下降 |
| 多 worker 并行 | 样本去相关，替代经验回放 |
| A3C vs A2C | 异步更新 vs 同步更新 |

## 可迁移

- 讲 GRPO/PPO 时能一句话交代谱系：GRPO 是把评委换成组内相对统计量的 Actor-Critic 变体，优势估计的方差-偏差权衡仍是同一道题。
- 面试被问「为什么减 baseline 不改变梯度期望」时，要能现场推：基线只依赖状态，对动作求期望后与策略梯度项正交。
