## 一句话总结

标题虽叫职场斗争，内容其实是一个半开玩笑的开源项目：把同事的技能、性格、说话方式乃至甩锅习惯「蒸馏」成一个可调用的 AI skill。

## 核心

1. **问题/背景**：能否把一个具体同事的工作方式与人格特质结构化地沉淀下来，让 AI 按他的方式干活、用他的语气说话。
2. **机制/方法**：这是一个元技能（用来创造其他技能的技能）。输入飞书消息、钉钉文档、邮件、PDF 或主观描述，走五步流水线：基本信息采集 → 导入原始素材 → 双轨分析（工作能力与人格特质并行提取）→ 生成预览 → 写入文件；输出 work.md（工作能力）、persona.md（人格特质）与完整 Skill.md。人格侧用 L0–L5 分层架构保证行为一致性：L0 是标签翻译成的硬性行为规则（优先级最高）、L1 身份认同、L2 表达风格、L3 决策方式、L4 人际行为，修正层按反馈实时纠偏。
3. **关键证据或数字**：标签翻译是亮点——「甩锅高手」会被译成第一反应找外部原因、主动模糊责任边界；「PUA 大师」译成把杂活包装成成长机会。素材侧可自动采集上千条飞书消息与数十篇钉钉文档；技能支持增量追加素材、对话修正即时生效、版本回滚（保留最近十个版本）。
4. **结论/判断**：本质是把「人设一致性」拆成可分层覆盖的规则系统，再用真实沟通素材做双轨提炼；UP 在结尾也声明这是玩笑，别真拿去让同事失业。

## 可迁移

- 分层人设（硬规则覆盖 > 身份 > 风格 > 决策 > 人际）的思路可迁移到 Agent 角色设定：把不可违反的约束放最高层、风格放低层，避免 prompt 内部打架。
- 「工作能力」与「人格/表达」双轨独立生成再组合，是做角色型 Agent 时值得借鉴的解耦方式。
