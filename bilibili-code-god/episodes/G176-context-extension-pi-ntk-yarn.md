## 一句话总结

直接拉长上下文会因 RoPE 从未见过远距离位置而崩；主流解法是按频率缩放位置编码（YaRN 为当前最优）再配合分阶段渐进扩展训练。

## 核心

1. 问题/背景：模型训练时只见过 0–4K 范围内的位置，直接喂 128K 序列时相对位置远超训练分布，注意力分布紊乱、困惑度暴涨、输出变乱码——瓶颈在位置编码外推，不在窗口参数本身。
2. 机制/方法：三种缩放思路递进。PI（位置插值）把 0–128K 的位置线性压缩回 0–4K 范围，让模型看到的相对位置仍在训练分布内，简单但相邻 token 的位置差异被压小、区分度下降，且需要少量微调适应。NTK-aware 不再均匀压缩：按频率分治，高频部分不缩放以保住近距离精度，低频部分大幅缩放以容纳远距离，很多情况下免微调即可外推。YaRN 在 NTK 基础上发现外推后注意力温度分布会偏移，某些层过集中或过分散，于是再加一个温度缩放因子校正，效果最好。
3. 关键证据或数字：分阶段训练是配套的工程 pipeline——先在 4K 上正常预训练，再改位置编码在 32K 上续训一小段，最后扩到 128K 再训一段；每个扩展阶段只用约 5% 的预训练算力。
4. 结论/判断：YaRN + 分阶段渐进扩展是当前主流组合（Llama 3 等长上下文模型采用类似路线）：渐进扩展既避免一步到位的灾难性遗忘，也保住了短文本性能；长上下文扩展的本质是把位置编码重新安排一遍，而不是把窗口调大。

## 关键数字

| 项 | 取值 |
|---|---|
| 扩展路径 | 4K → 32K → 128K |
| 每扩展阶段算力 | 约为预训练的 5% |
| PI 是否需微调 | 需要少量微调 |
| NTK-aware 是否需微调 | 多数情况不需要 |

## 可迁移

- 面试高频：RoPE 外推三方法的取舍（PI 的均匀压缩 vs NTK 的分频缩放 vs YaRN 的温度校正）是长上下文题的标准答法，注意每种方法各自修的是哪个失效模式。
- 工程实践：做上下文扩展时把「位置编码改造」和「分阶段续训」当成一个整体设计，不要指望改一个配置参数一步到位。

## 疑问 / 下一步

视频只讲到 128K 量级；扩到 1M 时 YaRN 类缩放是否仍够用、是否需要配合注意力机制本身的改造（如稀疏注意力），值得另找材料对照。
