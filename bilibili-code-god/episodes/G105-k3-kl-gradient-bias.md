## 一句话总结

k1/k2/k3 的「无偏」说的是估计值：把 k3 估计值当 loss 直接反向传播会漏掉采样分布随参数变化的 score function 项，梯度仍是有偏的；KL 放进奖励梯度无偏但方差大，放进 loss 方差小但有偏，detach 的位置决定偏不偏。

## 核心

1. **问题/背景**：RL 目标是最大化奖励减去 $\beta$ 乘策略与参考模型的 KL 散度。KL 要对整个词表求期望、序列上算不动，只能用采样 token 估计：k1 是 log 概率比（无偏但方差大、可正可负），k2 是 log 概率比平方的一半（非负但有偏），k3 是概率比的倒数减其 log 再减一（无偏、低方差、非负），GRPO 与 DeepSeek-R1 用的就是 k3。主流开源库习惯把 k3 往 loss 里一加就完事。
2. **机制/方法**：问题在求梯度这一步。KL 是一个期望，而采样分布本身依赖参数 $\theta$ ，对这种期望求梯度有两项：被积函数对 $\theta$ 的导数，加上采样概率变化带来的 score function 项。把 k3 当 loss 用自动微分，只算出第一项，第二项被丢掉——估计值在期望上等于 KL，梯度在期望上却不等于 KL 的梯度。还有第二个陷阱：逐 token 估计有序列依赖，只对当前 token 求导只拿到部分梯度。两种放法的梯度结构因此不同：放进奖励（每个 token 奖励减 $\beta$ 乘 log 概率比，再走策略梯度），KL 经 REINFORCE 的 score function 传梯度、天然含分布项，梯度对但方差大；放进 loss 把 k3 当正则项直接求导，方差小但漏项有偏。各种 detach 技巧（把某些项摘出计算图）也会改变偏不偏。Benjo 团队系统列举了这些配置并逐一判定有偏/无偏。
3. **关键证据或数字**：在 Qwen2.5-7B、Llama-3-8B Instruct、Qwen3-4B 上做 on-policy RL：梯度有偏的配置更容易训练不稳定，无偏配置在域内与域外任务上都更好。另一个发现是异步 off-policy 训练里 KL 仍有稳定作用，但具体配置的差异变小，因为 off-policy 的重要性采样本身已改变梯度结构。
4. **结论/判断**：判断 KL 实现对不对，不能只看 KL 数值曲线对不对，要看梯度对不对；面试被问 KL，先答梯度是否有偏，再答 $\beta$ 多大。

## 可迁移

- 用 verl 等框架时先查 KL loss 的实现选项（如 low_var_kl 等）：是对 log ratio 直接求导，还是用了带修正的形式，两者梯度性质不同。
- 要严格无偏就把 KL 放奖励里或用 score function 形式的估计器；要低方差就用 loss 形式，但接受有偏并配更小的 $\beta$ 。
