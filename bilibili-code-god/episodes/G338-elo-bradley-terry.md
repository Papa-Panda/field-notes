## 一句话总结
Elo 用「分数差 → 胜率」的 logistic 曲线和在线更新给选手排名；Bradley-Terry 把标量分数推广成任意可微函数——当这个函数是神经网络时，它就是 RLHF 的奖励模型。

## 核心
1. **问题/背景**：Chatbot Arena 上 GPT、Claude、Gemini 的排名怎么算？答案是六十多年前国际象棋的评分系统：每个选手一个分数，分数差决定胜率。
2. **机制/方法**：Elo 的期望胜率只看分数差 $\Delta R$，是一条 logistic 曲线：差 0 时胜率 50%，差 400 时约 91%（赢十次输一次量级），差 800 时约 99%。赛后在线更新：新分数 = 旧分数 + $K$ ×（实际结果 − 期望胜率）；期望越低、爆冷赢一场涨得越多。$K$ 因子控制步长——FIDE 规则下新选手 $K$ 取 40 快速校准、普通选手 20、2400 分以上大师 10，本质是学习率退火：前期大步探索，后期小步微调。
3. **关键证据或数字**：Bradley-Terry 是 Elo 的统计学推广：把胜率写成 sigmoid 作用在分数差上，数学等价、只换了对数底数；关键推广是分数 $R$ 不必是标量，可以是任意可微函数。在大模型时代令 $R$ 为神经网络、输入两个回答输出标量奖励，就是 RLHF 里用人类偏好数据训练的奖励模型。
4. **结论/判断**：Arena 实战是匿名双模型盲测投票（平手各半），累积几十万次投票成榜；但裸 Elo 有两大局限——假设传递性（A 强于 B、B 强于 C 则 A 强于 C，而模型各有专长不存在全序）、采样偏差（对手强弱分布影响分数），实际用的是带 bootstrapping 置信区间的变种。

## 关键数字
| 项 | 值 |
|---|---|
| 分数差 400 | 胜率约 91% |
| 分数差 800 | 胜率约 99% |
| $K$ 因子 | 新手 40 / 普通 20 / 大师 10 |

核心公式如下：

$$P(A \text{ 胜 } B) = \frac{1}{1 + 10^{(R_B - R_A)/400}}$$

## 可迁移
- 理解 Arena 排名先看置信区间与对局分布，再看名次差——小分差 + 宽区间时排名基本是噪声。
- 面试主线：Elo → Bradley-Terry → 奖励模型是一条完整的数学血统，能讲清「BT 把标量换成神经网络」就打通了评估与 RLHF 两章。
