## 一句话总结

策略梯度里减去任何只依赖状态、不依赖动作的量（baseline）都不会改变期望梯度、只降方差：减状态价值 $V$ 得到优势函数，GRPO 则用同题一组的平均分当 baseline。

## 核心

1. 问题/背景：一道题四个回答分别得 8、9、7、10 分，全是正分。没有 baseline 时策略梯度会把四个回答的概率一起往上推，只能靠彼此挤压区分好坏，学得又慢又抖；可分数本是相对的，这组里得 7 分的其实是差的那个。
2. 机制/方法：关键恒等式只有一行：对数概率的梯度按策略取期望恰好为零。因此减掉任何只跟状态有关的数，期望梯度一分不变，变的只有方差。减什么最好？减这个状态平常能拿多少分，也就是价值函数 $V$ ；回报减 $V$ 正是优势函数——拿到预期之内的分不动，超出或低于预期才更新。
3. 关键证据或数字：GRPO 把这件事做得更直接：同一道题采样一组回答，直接减组内平均分当 baseline，不需要单独训一个 critic 网络。
4. 结论/判断：从三十年前的 REINFORCE 到今天的 GRPO 用的是同一招——减一个与动作无关的量，不偏，还更稳。

## 可迁移

- 面试高频：被问「减 baseline 为什么无偏」时，答对数概率梯度期望为零这一行恒等式，再接优势函数与 GRPO 组平均两种 baseline 选法即可。
- 实现 GRPO/PPO 变体时，baseline 的选择只影响方差不影响无偏性，调参时应优先盯方差（组大小、归一化方式）而非担心引入偏差。

## 疑问 / 下一步

- 组平均作 baseline 时，组内样本相关性带来的方差估计偏差在小 group size 下有多大，视频未量化，后续可查 GRPO 相关分析。
