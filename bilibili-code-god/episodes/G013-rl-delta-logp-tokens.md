## 一句话总结

RL 对模型的改动是稀疏且有方向的：逐 token 的带符号对数概率差 $Δlog p$ 呈双峰长尾分布，只替换其中最大的约 10% 的 token 就能复现 RL 的表现；沿这个方向还能在测试时零训练外推、或在训练时给低概率 token 的优势加权。

## 核心

1. **问题/背景**：想知道 RL 训完模型到底哪里变了，习惯看的熵和 KL 是幅度指标——只说变了多少、不说往哪变，在 base 模型与 RL 模型的输出上画直方图几乎重合，什么都看不出来。换成带符号的 token 级对数概率差：对同一段文本，RL 模型与 base 模型各给每个 token 一个对数概率，相减即得 $Δlog p$ ，正值表示 RL 把这个 token 推高、负值表示压低。
2. **机制/方法**： $Δlog p$ 的直方图是双峰加两条长尾：绝大多数 token 在 0 附近没动，少数 token 被大幅推高或压低——RL 的改动集中在一小撮位置。替换实验验证因果：让 base 模型生成，按某指标挑出部分位置、把 base 的 token 换成 RL 模型在同样上下文下的选择再继续生成；按 $Δlog p$ 挑、只换约 10% 的 token，分数就追平 RL 模型；按 divergence 挑需要换多得多，按熵挑最差。原因看梯度：每个 token 的梯度范数正比于 $1 - π$ ，概率本来就高的 token 梯度几乎为零，低概率 token 梯度大，所以 RL 天然把「本来不太可能、但推理上关键」的 token 推高——RL 不是在重写整个分布，是在少数关键分叉口改变选择。
3. **关键证据或数字**：两个可直接用的工具。① 测试时外推：构造新分布沿 $Δlog p$ 方向再走一步，只在 $Δlog p$ 大幅为负（RL 明显压低）的位置施加，系数 $γ$ 取 0.05–0.1，不训练在 AIME24 上多 1–3 分（视频口径：32B 模型 46.15 → 约 47.5，14B 模型 54.58 → 约 55.8，均为 avg@32）；代价是推理时要同时跑 base 与 RL 两个模型，外加 $γ$ 与阈值两个超参。② 训练时加权：给低概率 token 的优势乘上与概率负相关的放大因子（视频口径：优势乘 $1 + α(1 - π)$ 一类形式， $α$ 取 0.1 或 0.2），在 Qwen2.5-Math-7B 上 AIME24 的 avg@32 从 35.73 涨到 39.06、pass@16 从 54.09 涨到 60.58；但该加权未在全部规模上验证， $α$ 不是通用常数。
4. **结论/判断**：分析 RL 改了什么要看方向、不看幅度：画 $Δlog p$ 直方图看双峰与长尾。实操上，手里有 base 与 RL 两个 checkpoint 就能先零成本试外推（ $γ$ 从 0.05 起、只作用于负得多的位置、盯 avg@32）；训练想加速再试优势加权（ $α$ 从 0.1 起步，看 pass@k 是否一起涨）。

## 关键数字

| 指标 | 基线 | 结果 |
|---|---|---|
| 替换 token 比例（复现 RL 表现） | 全量 | 约 10%（按 $Δlog p$ 挑选） |
| 测试时外推 AIME24 avg@32（32B） | 46.15 | 约 47.5 |
| 测试时外推 AIME24 avg@32（14B） | 54.58 | 约 55.8 |
| 优势加权 AIME24 avg@32（Qwen2.5-Math-7B） | 35.73 | 39.06 |
| 优势加权 AIME24 pass@16（Qwen2.5-Math-7B） | 54.09 | 60.58 |

## 可迁移

- 诊断 RL run 时把 $Δlog p$ 直方图加进常规面板（与 trainer/inference logprob 差互补：一个看一致性、一个看改动的方向与稀疏度）。
- 面试答「RL 学到了什么」：一个可定位（少数关键 token）、可外推（测试时沿方向放大）、可加权（训练时给低概率 token 更大优势）的方向，而非整个分布的重写。
