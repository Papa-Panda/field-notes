## 一句话总结

多任务训练失衡的根源是各任务 loss 尺度不同而非重要性不同，解法从手动调权到在梯度层面自动拉平共三档。

## 核心

1. **问题/背景**：数学、代码、对话多任务同训时，各任务 loss 尺度天然不同（例如数学约 2.0、对话约 0.5），直接相加求和会被大尺度任务主导梯度，结果是模型只学好数学、对话学不到。
2. **机制/方法**：三法递进。其一手动调权：给每任务乘一个人工权重（如数学 0.3、代码 0.3、对话 0.2、翻译 0.2），简单可控但经验性强，换数据分布就要重调。其二不确定性加权：为每任务引入可学习的不确定性参数，不确定性越大的任务自动获得越小的权重，模型自己找平衡，省去人工试凑。其三 GradNorm：在梯度层面平衡，计算各任务的梯度范数并动态调整权重，使各任务梯度范数大致相等，保证每个任务对参数更新的贡献相当。
3. **关键证据或数字**：实操起点是等权（每任务权重取 $1$ 除以任务数），再按验证表现迭代：某任务落后就增大其权重，某任务过好而其他退步就减小。验收标准是逐任务看验证集表现，确保没有任务被牺牲。
4. **结论/判断**：手动调权适合任务少的场景；任务一多就调不动，应升级到不确定性加权或 GradNorm。视频的落点是：失衡的根源是尺度，所以最终要在梯度层面解决。

## 可迁移

- 多任务/多领域混训时把「各任务梯度范数」列入监控面板，失衡先看尺度再谈权重。
- 面试可迁移的表述：手动权重 → 不确定性加权 → GradNorm 是一条从经验到自适应的完整谱系，能讲清三者代价与适用规模即是加分项。

## 疑问 / 下一步

- GradNorm 本身引入额外超参（不对称系数），在 RL 后训练的多奖励场景里是否稳定，值得找实践报告对照。
