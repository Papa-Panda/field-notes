## 一句话总结

$\gamma$ 决定回报计算时「眼光有多远」：未来第 $k$ 步奖励乘 $\gamma^k$ 再求和，有效视野约为 $\frac{1}{1-\gamma}$ 步；它改的是优化目标本身，而 LLM 的一段回答就是一局、奖励只在句尾给，所以直接取 $\gamma = 1$ 不打折。

## 核心

1. **问题/背景**：同样是 100 块，今天给和一年后给价值不同——未来的奖励要打折。回报定义为未来奖励的折扣和， $\gamma$ 在 0 到 1 之间，越小越只看眼前。
2. **机制/方法**：粗略换算：$\gamma = 0.9$ 大约看 10 步，$\gamma = 0.99$ 大约看 100 步，即有效视野约 $\frac{1}{1-\gamma}$ 。按 GAE 论文的口径， $\gamma$ 改的是目标本身——改了它，「正确答案」就变了，不是单纯的估计技巧。
3. **关键证据或数字**：InstructGPT 附录里估计 GAE 时取 $\gamma = 1$ 不打折。理由是 LLM 场景中一段回答就是一局、分数只在最后一个 token 给；若打折，越靠前的 token 分到的信号越少，可开头几个 token 往往最关键。
4. **结论/判断**：记住两点即可—— $\gamma$ 决定看多远；大模型一局到底、句尾给分，干脆不打折。

## 可迁移

- 面试被问「LLM 的 RL 为什么 $\gamma = 1$」时，用「回合边界 = 一条回答、奖励末端稀疏、打折会系统性削弱开头关键 token 的信号」三句答清，并与传统控制任务（长时域、稠密奖励、需要 $\gamma < 1$ 保证回报收敛）做对比。
