## 一句话总结

Warmup 就是训练开头几百到几千步把学习率从 0 线性抬到目标值再接衰减，用近乎零成本躲开「损失面最乱 + Adam 步长最不准」的开局脆弱期。

## 核心

1. **问题/背景**：同样的模型和数据，两次训练一次平稳收敛、一次开局损失剧烈震荡甚至发散，差别只在最开始几百步的学习率处理。不做 warmup 等于一开局就把学习率顶格。
2. **机制/方法**：
- 做法：warmup 阶段学习率从 0 线性升至目标值，之后再按计划衰减，整条曲线呈「先爬坡、再下坡」的小山形。
- 原因一（损失面）：参数随机初始化时损失曲面又陡又乱，大步更新容易一步迈过头直接发散；先用小学习率探路、挪到平缓区域，再逐步放大步子。
- 原因二（优化器）：Adam 靠历史梯度平方估计每个参数的步长，但训练初期样本太少、二阶矩估计极不稳定，算出的步长忽大忽小；warmup 把早期学习率压小，等估计准了再放开。
- 结构差异：老式 Post-LN 结构早期靠近输出的梯度特别大、特别容易炸，对 warmup 依赖极重；Pre-LN 把归一化前置后早期梯度温和得多，敏感性明显下降。Warmup、小初始化、Pre-LN 做的是同一件事：稳住最脆弱的开局。
3. **关键证据或数字**：视频给的工程配置示例是前 2000 步线性升温，之后接余弦衰减或按步数平方根反比衰减；主流框架都内置现成调度器，接入成本约一行配置。
4. **结论/判断**：Warmup 不是玄学调参，而是针对两个可解释的失效模式（初始损失面陡峭、Adam 二阶矩未收敛）的稳定器；不加时早期损失剧烈震荡，运气差直接发散且拉不回来。

## 可迁移

- 训练排障：RL/SFT 训练开局 loss 尖峰或发散时，先查 warmup 步数与峰值学习率的配比，再怀疑数据和模型结构。
- 面试：答 warmup 要同时给出「损失面」和「Adam 估计」两条机制，并补一句 Post-LN vs Pre-LN 的敏感性差异，这是常考的加分点。

## 疑问 / 下一步

- Warmup 步数占总步数的比例如何随模型规模/batch size 缩放，视频未给经验公式，大模型训练中通常需结合实际 loss 曲线试。
