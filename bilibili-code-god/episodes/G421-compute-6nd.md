## 一句话总结

一次乘加 = 2 次浮点运算，由此推出每 token 前向约 $2N$ 、反向约 $4N$ ，训练总算力约 $6ND$ ；MoE 要用激活参数代入 $N$ ，且固定算力下数据量约取参数量的 20 倍最划算。

## 核心

1. **问题/背景**：训练一个大模型要烧多少算力、花多少钱，不必翻财报——圈内靠一个乘法估算，前提是先把计数单位定死：一次浮点加或乘算一次运算，神经网络的核心动作是乘加。
2. **机制/方法**：一次乘加先乘后加，正好 2 次浮点运算。前向时每个 token 流过模型要与每个权重各做一次乘加，所以参数量为 $N$ 的模型每 token 前向约 $2N$ ；反向要同时算两笔账——误差对输入的梯度（把信号继续往前传）和误差对权重的梯度（更新参数），每笔开销都与前向相当，故反向约 $4N$ 。一来一回合每 token 共 $6N$ ，再乘上总 token 数 $D$ ，得到训练总算力公式：

$$C \approx 6ND$$

3. **关键证据或数字**：代入 GPT-3（1750 亿参数、约 3000 亿 token）：$6 \times 1.75 \times 10^{11} \times 3 \times 10^{11} \approx 3 \times 10^{23}$ 次浮点运算，单张顶级训练卡要连轴转几十年，堆 1000 张卡也要大半个月，电费加卡费轻松冲到百万美元级。
4. **结论/判断**：两个进阶口径面试常追问——MoE 的 $N$ 必须用每 token 激活参数而非总参数，否则严重高估；Chinchilla 的结论是算力固定时参数与数据要平衡，数据量约为参数量的 20 倍最划算，配比失衡就是又贵又亏。

## 关键数字

| 项 | 基线/口径 | 结果 |
|---|---|---|
| 每 token 前向 | 1 次乘加 = 2 FLOPs/参数 | 约 $2N$ |
| 每 token 反向 | 输入梯度 + 权重梯度两笔账 | 约 $4N$ |
| GPT-3 训练总算力 | $N = 1.75 \times 10^{11}$ ， $D = 3 \times 10^{11}$ | 约 $3 \times 10^{23}$ FLOPs |
| Chinchilla 配比 | 算力固定 | $D \approx 20N$ 最优 |

## 可迁移

- 做 RL 训练的算力预算时，rollout 是纯前向（约 $2N$ /token）、训练步是前向+反向（约 $6N$ /token），用同一公式就能快速估出两段的成本占比和瓶颈在哪。
- 面试被问「训一个 X B 模型要多少卡时」，按 $6ND$ → 除以单卡有效 FLOPs（记得乘 MFU）→ 换算卡时，是标准答题链路。

## 疑问 / 下一步
