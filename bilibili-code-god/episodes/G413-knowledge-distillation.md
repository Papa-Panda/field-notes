## 一句话总结
知识蒸馏让大模型当老师、小模型当学生：学生学的不是非黑即白的硬标签，而是老师软标签里携带的暗知识——类别之间的远近关系，再用温度放大、KL 蒸馏损失与真实标签的交叉熵双损失一起训。

## 核心
1. 问题/背景：我们想要小模型（跑得快、省显存、能进端侧），但小模型自己拿标准答案硬学，成绩总差大模型一截。蒸馏的想法是先训好一个大而准的老师，让它手把手教学生，把能力「压」进小模型。
2. 机制/方法：关键在教什么。一张猫图，硬标签只有「是猫」一个 bit；而老师输出的是一整套概率，除「最可能是猫」之外，还给出「和狗比较像、和车差得远」这类次级信息，即软标签里的暗知识：类别间的相似结构。学生正是靠这张关系网学得又快又好。训练目标是两份损失的加权和——对齐师生软分布的 KL（相对熵）蒸馏损失，加上学生对真实标签的常规交叉熵损失，前者传暗知识、后者守正确答案。
3. 关键证据或数字：老师太自信时次优类别概率被压到看不见，用温度 $T$ 把 logits 除以 $T$ 再归一化，分布变平、暗知识被放大到可学（温度的梯度补偿细节见 G411）。视频的定性结论：几十 MB 的小模型经蒸馏后性能可逼近数 GB 的大模型。
4. 结论/判断：一条软标签的信息量远大于一个硬答案；学生学的从来不只是答案，而是老师看世界的结构，这就是蒸馏能以小博大的原因。

## 可迁移
- 这套「软标签 + 温度 + 双损失」是 LLM 时代 on-policy distillation、logits 蒸馏的原型，理解它有助于看懂现在把强模型输出分布当训练信号的一系列后训练做法。
- 面试速记四词：软标签、暗知识、温度、双损失；展开时先讲硬标签丢了什么信息，再讲温度怎么把它放大。
