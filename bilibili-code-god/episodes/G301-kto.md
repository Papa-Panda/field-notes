## 一句话总结
KTO 砍掉对齐所需的成对偏好数据，每条回答只带一个好/坏的二元标签，再把前景理论的损失厌恶写进目标函数——坏样本压得比好样本抬得更重——效果可追平甚至超过 DPO。

## 核心
1. **问题/背景**：RLHF、DPO 等主流对齐方法吃成对偏好数据：同一问题要生成两个回答、由人两两比较分高下。标注成本高、规模难放大，数据贵直接拖累对齐质量。
2. **机制/方法**：KTO 只要求每条回答独立领一个二元标签（好/坏，类似点赞/点踩，现实中随手可得）。训练时不再两两互比，而是给每条回答算一个相对参考模型的隐含分数，与一个代表平均水平的参考点比较：好回答往参考点上方推、坏回答往下方压。关键的不对称来自损失厌恶——人对等额损失的痛感约为收益快乐的两倍——所以下压坏样本的力度显著大于上抬好样本。
3. **关键证据或数字**：前景理论的价值曲线在收益侧平缓、损失侧陡峭，视频以此解释惩罚权重为何更重；KTO 在好坏样本比例悬殊的数据上依然训得稳，并在多种模型规模上验证可追平或反超吃成对数据的方法。
4. **结论/判断**：数据格式从「问题 + 成对回答 + 排序」简化为「问题 + 回答 + 真/假标签」，采集门槛骤降；因为每条样本独立与参考点比较，天然不需要配对，也天然抗类别不平衡。

## 可迁移
- 面试被问「没有成对偏好数据怎么做对齐」：KTO 这条链（数据形态 → 参考点 → 损失厌恶加权）可以完整答上，并能与 DPO 的数据成本做对照。
- 对自有数据管线：点赞/点踩、accept/reject 这类单条二元反馈在真实产品里几乎零成本，KTO 说明这类信号不必先攒成对就能直接用于对齐训练。
