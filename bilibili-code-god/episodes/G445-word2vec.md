## 一句话总结

Word2Vec 用 CBOW/Skip-gram 两个填空游戏把词压成稠密向量，让语义变成距离和方向，还能算「国王−男人+女人≈女王」；今天每个大模型第一层的 embedding 就源于它。

## 核心

### 1. 问题/背景

最土的词表示是独热编码：词表几万个词就给几万维向量、只有一位是 1。问题是又长又空，且任意两词互相垂直——猫和狗在计算机眼里毫无关系，语义全丢了。

### 2. 机制/方法

依据分布假设：看一个词常和哪些词做邻居，就知道它的意思。Word2Vec 把每个词压成约 300 维的稠密向量，靠两个方向相反的填空游戏训练：CBOW 用上下文猜中心词，Skip-gram 用中心词猜周围词（一般 Skip-gram 在生僻词上更强，CBOW 训练更快）。模型为把空填对，被迫把语义编进向量。全词表 softmax 太慢，两个加速招：负采样只抽几个错词当反面教材，把几十万选一变成几道判断题；层次 Softmax 把词摆成哈夫曼树，常用词离根近，预测只需顺树走几步，计算量从几十万砍到几十。

### 3. 关键证据或数字

训完后向量里藏着语义方向：「男人→女人」的箭头与「国王→女王」的箭头方向几乎一致，于是有封神等式：国王 − 男人 + 女人 ≈ 女王；同理巴黎 − 法国 + 意大利 ≈ 罗马。词义的加减法第一次被真正算了出来。

### 4. 结论/判断

Word2Vec 与现代大模型的区别只在向量是「死的」（一个词永远同一串数字）还是会随上下文变；把离散符号变成连续向量、让相似者靠拢的内核一脉相承，所以它是 embedding 的祖师爷。

## 关键数字

| 量 | 值 |
| --- | --- |
| 独热维度 | 等于词表大小（数万维） |
| Word2Vec 典型维度 | 约 300 维 |
| 层次 Softmax 计算量 | 从数十万降到数十量级 |

## 可迁移

- 理解 embedding 层训练目标（查表+梯度更新哪些行）时，Word2Vec 是最干净的原型，面试聊 embedding 来历按这条线讲即可。
- 负采样的「正样本+抽样负样本」套路在推荐系统、对比学习里反复出现，是可复用的训练加速范式。
