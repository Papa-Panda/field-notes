## 一句话总结

SFT 第二个 epoch 的 loss 断崖暴跌通常不是学得更好，而是模型从「学规律」切换到「背答案」；用验证集 loss 判断真假过拟合，并靠少 epoch、shuffle、学习率衰减与早停避免。

## 核心

1. **问题/背景**：第一个 epoch 里 loss 平稳下降，模型在学数据的规律；进入第二个 epoch，同一批数据第二次出现，模型发现直接记住每条数据的答案比学规律更省力，训练 loss 随之急剧下降，但泛化并没有变好。
2. **机制/方法**：三大根因——其一，记忆替代泛化：交叉熵损失有下界（约为 token 的信息熵），训练 loss 逼近这一下界就说明模型几乎在逐字背诵训练集。其二，数据没 shuffle 的假象：每个 epoch 按固定顺序喂入时，epoch 边界处的分布切换会造成数值跳变，看起来像暴跌，其实不是过拟合（LLaMA-Factory 的 issue 里有大量此类报告）。其三，学习率没衰减：第二个 epoch 还用大步长，模型在最优点附近剧烈震荡，一旦碰到某个能让 loss 骤降的记忆方向就沿它一路背下去。
3. **关键证据或数字**：判断真过拟合最可靠的方法是同时看验证集 loss：训练 loss 暴降而验证 loss 上升或停滞，就是过拟合；经验上 SFT loss 低于 0.5 就需要警惕；也可以人工抽检，输出变得模板化、千篇一律同样是过拟合信号。
4. **结论/判断**：五个避免手段——SFT 默认只跑 1–2 个 epoch，数据量够时 1 个 epoch 就够；每个 epoch 前 shuffle；第二个 epoch 学习率减半或用 cosine 自然衰减；留验证集做早停（连续三个 checkpoint 不降就停）；质量优先，呼应 LIMA 的教训：1000 条高质量数据跑 1 个 epoch 胜过 5 万条低质量数据跑 5 个 epoch。

## 关键数字

| 项 | 经验值 |
|---|---|
| SFT epoch 数 | 1–2（默认不贪多） |
| 过拟合警惕线 | 训练 loss < 0.5 |
| 早停耐心 | 验证 loss 连续 3 个 checkpoint 不降 |

## 可迁移

- RL 训练里对同一批 rollout 做多个 epoch（PPO 式复用）有同样的记忆化风险：监控的重点应放在 held-out 指标与输出多样性，而不是训练 reward 的涨幅。
- 排障口诀可复用：loss 曲线在 epoch 边界出现台阶时，先查 shuffle 与学习率日程，再下过拟合结论。

## 疑问 / 下一步

- 对小数据集必须多 epoch 的场景，除学习率衰减外，数据增强或混入通用数据能把「背答案」的转折点推迟多少？值得做一组对照实验。
