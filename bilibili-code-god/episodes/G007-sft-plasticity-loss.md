## 一句话总结

SFT 分数解释不了 RL 结果（ $R^2$ 只有 0.43 ）：过度 SFT 把 token 熵压没、模型掉进又深又窄的坑，RL 没了探索空间；该盯的是验证集 loss 拐点与 pass@k，两者合用能把预测相关性拉到 0.94。

## 核心

1. **问题/背景**：业界默认假设是 SFT 分数越高、交给 RL 的底子越好。Meta 与弗吉尼亚理工用 Llama-3-8B、Mistral-12B、Qwen-34B（字幕口径）跑了几十组不同 SFT 再各接一遍 GRPO，总计超过 100 万 GPU 小时，把每组 SFT 分数与 RL 后分数画散点——没有漂亮直线， $R^2$ 只有 0.43 ，即 SFT 分数只能解释 RL 结果的 43%。
2. **机制/方法**：港科大论文把机理命名为可塑性丧失。RL 靠采样进步：同一道题多写几遍、写出不一样的答案才能比出好坏；SFT 训满后模型每次输出几乎一模一样，采样无差异、奖励无差别，RL 无东西可学。更诡异的是过训模型在 RL 里梯度反而更大、参数却几乎不动——掉进又深又窄的坑，怎么推都推不出来。
3. **关键证据或数字**：Qwen 换一种数据配方，SFT 涨 8.7 点、RL 后反而掉 1.43 点；只挑短样本训 SFT 学得快又好、RL 后明显更差，随机采样 SFT 低 5 点、RL 后反高近 6 点。同份数据训 1–4 遍：SFT 分数逐遍涨，但各 epoch 交给 RL 后第二遍即到顶，之后往下掉。熵的账：SFT 2 轮 token 熵 0.184，32 轮掉到 0.024（只剩 1/8），训练 loss 从 0.11 压到 0.002，RL 收益从 9.9 分砍到 4.9 分，跨域泛化收益从 6.7 砍到 2.4。预测指标：验证集 loss 的拐点（训练分还在涨时它先拐头向上，就是 RL 潜力开始流失的时刻）与 pass@k（采样 64 次有一次对就算对，量的是剩余探索能力）对 RL 结果的相关性可达 0.94 以上，远高于训练分的 0.75；两指标合用把 $R^2$ 从 0.43 拉到 0.94。
4. **结论/判断**：已经训过头还有救——复苏：过训模型参数与原始基座各取一半平均，再把最激进的 1% 神经元重置回基座，只需一次前向归因、不用重训；过训模型 RL 综合分 14.9，复苏后 17.5，甚至超过正常 SFT 的 17.0。

## 关键数字

| 指标 | 数值 |
|---|---|
| SFT 分数对 RL 结果的 $R^2$ | 0.43（验证 loss + pass@k 合用：0.94） |
| token 熵（SFT 2 轮 → 32 轮） | 0.184 → 0.024 |
| RL 收益（2 轮 → 32 轮 SFT） | 9.9 分 → 4.9 分 |
| 复苏后 RL 综合分 | 14.9 → 17.5（正常 SFT 为 17.0） |

## 可迁移

- 日常训练四条：同样算力宁可一个 epoch 看更多数据、别把少量数据反复刷；长短样本混着来、别只挑短的；盯验证集 loss 与 pass@k、别盯训练分；token 熵低于 0.05、训练 loss 低于 0.01 是过训警报。
- 面试被问 SFT 训多久：别答「三个 epoch」，答看验证集 loss 的拐点与 pass@k。
