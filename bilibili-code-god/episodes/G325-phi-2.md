## 一句话总结

Phi-2 用 2.7B 参数在推理、代码、数学上打平甚至超过 70B 模型，靠的不是规模，而是把训练数据换成 GPT-4 生成的「教科书级」合成数据——质量胜过规模。

## 核心

1. **问题/背景**：Scaling law 的惯性路线是堆算力、堆数据、堆参数，但互联网数据混杂广告、灌水、错误答案等噪声，模型要浪费大量参数去记忆杂音。Phi 系列反着来：如果小模型只读结构清晰、逻辑连贯的教科书式内容，它能学得更专注高效。
2. **机制/方法**：Phi-2 的训练数据共约 1.4T token，其中约 250B 是 GPT-4 按教科书风格生成的合成数据（定义、定理、例题、习题环环相扣），其余是筛选后的高质量网络数据。合成教科书的三大特点是「清、联、净」：结构清晰、逻辑连贯（从浅入深而非东一段西一段）、无噪声（无广告、无拼写错误、不跑题）。
3. **关键证据或数字**：2.7B 的 Phi-2 对比 Llama-2 70B（25 倍参数差距）：BigBench Hard 推理打平甚至超过 70B；HumanEval 代码约 59 分，远超同量级；GSM8K 数学约 61 分，比 Llama-2 70B 还高。它并非全面碾压，而是在需要逻辑链条的 reasoning / coding / math 上以少胜多。
4. **结论/判断**：Phi-1（1.3B 专攻代码，HumanEval 超过 50 分）→ Phi-1.5 → Phi-2 → Phi-3/4 把「小模型 + 高质量数据」走成了方法论。与 Magpie 式合成指令数据（教模型怎么说话）对照，Phi 是合成教科书数据（教模型怎么思考），同为数据合成的胜利。

## 可迁移

- 做 post-training 数据 curation 时可直接借用「清、联、净」三字标准评估合成数据质量，而不是只看 token 量。
- 面试聊数据 scaling 时，Phi 是「quality over quantity」最有力的反例：同样的 token 预算，信息密度决定上限。
