2一句话总结

RL 训练的熵会在前 200 步内对数线性地急速坍塌、锁死探索；解法是 DAPO 的不对称裁剪放宽概率上界，或用协方差正则惩罚高协方差 token，其中 KL-Cov 更稳、更被推荐。

3核心

  1. 问题/背景：策略熵衡量每步生成的随机性，熵高偏探索、熵低偏利用。SFT 有标签直接引导，熵降了训练也不会失败；RL 依赖策略自己采样出的轨迹，一旦熵过低，轨迹过于确定、探索空间急缩，优化卡进局部最优。
  2. 机制/方法：解法一是 DAPO 的 Clip-Higher：GRPO 的 clip 上下界对称，DAPO 改为不对称（ $\epsilon_{high} > \epsilon_{low}$ ）——对概率下降严格限制保稳定，对概率上升放宽上限，让低概率 token 有更大的提升空间、鼓励探索。解法二是协方差正则：论文发现熵的变化量正比于 log 概率与优势函数的协方差，高概率又高优势的 token 正是熵骤降的元凶；Clip-Cov 随机裁掉这类 token 的梯度，KL-Cov 则对协方差最高的若干 token 施加 KL 惩罚。
  3. 关键证据或数字：见下表。熵随步数对数线性下降，可用 $H = A - B \log(\text{step})$ 拟合；更大的模型（如 32B）系数 $A$ 、 $B$ 都更大，熵转化效率更高，但也更快摸到性能上限。实验上 KL-Cov 的熵曲线比 Clip-Cov 更稳定。
  4. 结论/判断：熵坍塌不是玄学而是有经验公式的动力学现象；所有解法的共同思想只有一个——控制熵的下降速度，给探索留足空间。调 GRPO 时熵曲线应是和 reward 并列盯的第一批指标。

5可迁移

  • 自己跑 GRPO/RLVR 时先把熵曲线画出来：若前几百步就掉光，后面再调 reward 也救不回来，优先上 Clip-Higher 或 KL-Cov。
  • 面试讲 GRPO 改进时，DAPO 四件套里 Clip-Higher 专治熵坍塌，能说清「放宽上界 = 给低概率 token 留上升通道」的机制，比只背名字强。
