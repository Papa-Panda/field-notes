## 一句话总结

不收敛没有单一原因，按「学习率 → 数据 → 初始化 → 精度」的顺序逐项排除、每次只改一个变量，比盲目试参数有效得多。

## 核心

1. **问题/背景**：不收敛有三种表现：loss 停在初始值附近不降、上下震荡无趋势、先降后升（典型过拟合或学习率过大信号）。
2. **机制/方法**：四步排查——① 学习率最常见：先用当前值的 10 倍与 1/10 做方向测试，更系统的做法是 LR range test，从极小值线性增大画 loss 曲线，取下降最陡区间；② 数据：检查是否 shuffle（顺序固定会让模型学顺序而非内容）、抽查 batch 输入输出、统计标签分布与错标；③ 初始化：方差不对会让信号逐层放大或衰减，打印每层激活范数看是否稳定，大模型常用截断正态、标准差约 0.02，改结构后忘了调初始化是常见坑；④ 精度：临时关混合精度用 FP32 跑几步验证，检查 LayerNorm 的 epsilon 与各层梯度范数。
3. **关键证据或数字**：视频强调的排查优先级本身就是经验结论——学习率第一、数据第二、初始化第三、精度最后。
4. **结论/判断**：纪律比技巧重要：单变量修改 + 实验日志记录改动与效果，否则无法归因、无法回溯。

## 可迁移

- 这份清单可直接迁移到 RL 训练排障：reward 不涨时同样先查学习率与数据（rollout 分布），再查初始化与数值精度。
- LR range test 是低成本定学习率区间的标准动作，做 pilot run 前先跑一遍能省大量无效 step。

## 疑问 / 下一步

- RL 场景下 loss 曲线本身噪声大，「先降后升」等形态判据需要换成 reward/KL 等指标的组合信号。
