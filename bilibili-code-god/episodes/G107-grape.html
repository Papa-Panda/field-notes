2一句话总结

对要训的模型来说，最好的 SFT 答案不是最强模型写的那条，而是它自己最「顺口」的那条：GRAPE 用目标模型的长度归一化概率从多源候选里挑概率最高的一条，只用 1/3 数据、一半轮数就超过 Tulu3-SFT。

3核心

  1. 问题/背景：SFT 数据是「指令 + 回答」，回答通常由更强的模型写。但每个模型有自己的措辞、结构与推理习惯，即它自己的分布；强模型写的回答对你的模型可能是分布之外的，每个 token 概率都很低，学起来要大幅改参数，规模一大收益递减，甚至伤原有性能与鲁棒性。所以数据的问题不只是「对不对」，还有「像不像你」。
  2. 机制/方法：GRAPE 三步：先对每条指令从多个来源收集回答（来源越多样越好）；再用目标模型对每条候选做一次前向，算长度归一化的对数概率（平均每个 token 的 log p，避免偏向短回答）；最后选概率最高的那条正常 SFT。注意打分用的是要训的那个模型本身，不是老师。成本只是对候选各做一次前向，比训练便宜得多。
  3. 关键证据或数字：与「从最强模型蒸馏」的数据相比平均绝对提升最多 13.8%；与用三倍数据的基线相比最多高 17.3%；只用 1/3 数据、一半 epoch，Llama-3-8B 超过 Tulu3-SFT 约 3.5%。原因在于概率高等于贴近预训练分布，学习成本低、对已有能力扰动小——这与 on-policy / 自蒸馏数据「学得快、忘得少」是同一条逻辑。
  4. 结论/判断：贴分布不等于最正确。若目标是引入新能力（如长推理模式），模型自己概率最高的恰恰可能是老套路的回答；正确用法是先过正确性筛选，再在正确的候选里按概率排序。

5可迁移

  • SFT 数据管线可加一步低成本的「目标模型概率重排」：候选先多样采样、再过正确性过滤、最后按长度归一化 log p 选一；长度归一化必须做，否则永远选最短的。
  • 数据 curation 面试里可把 GRAPE 与 TailSFT、拒绝采样并列：共同点都是按「与当前策略的距离」而不是只按来源强弱选数据。
