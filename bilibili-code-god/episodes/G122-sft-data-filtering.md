## 一句话总结

SFT 数据几万到几十万条无法人工逐检，自动筛选按「PPL 粗筛 → 强模型打分精筛 → embedding 聚类去冗余」的成本递增顺序，只留高分、PPL 正常、且覆盖多样的子集。

## 核心

1. **问题/背景**：低质量数据会直接教坏模型，而数据量一大人工审查就不现实，必须用算法或模型给每条数据打分、只留高分。
2. **机制/方法**：三层方法各司其职——强模型（如 GPT-4）按准确性、完整性等维度打分做质量裁判；困惑度（PPL）检测异常，异常高多半是乱码或劣质文本，异常低则可能有数据泄漏，保留中间正常区间；embedding 聚类去重，删掉过于相似的重复样本与各簇里的低质离群点，同时用簇结构保住类型覆盖。
3. **关键证据或数字**：视频引 AlpaGasus 的结论——经强模型筛选后只保留约 9% 的数据，效果反而比全量训练更好，说明数据价值曲线先陡后平、筛比堆划算。
4. **结论/判断**：落地顺序按成本排：先用近乎零成本的 PPL 把乱码和重复大批量干掉，再用强模型打分精筛提质，最后 embedding 聚类去冗余、每簇留代表样本压数量保多样性，并对比筛选前后的效果验证。

## 可迁移

- 数据 curation 流水线设计可直接套这个三段式：便宜的统计信号（PPL）做粗筛、贵的模型裁判做精筛、聚类做多样性兜底，成本结构最合理。
- 面试谈数据质量时可用「价值曲线先陡后平」解释为什么少而精胜过多而杂，并用泄漏检测（PPL 异常低）补上评测污染这一环。
