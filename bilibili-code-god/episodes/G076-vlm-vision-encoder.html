2一句话总结

VLM 微调要不要解冻 ViT 没有统一答案：受控消融显示只训 ViT 就有实打实的感知收益、ViT+LLM 联合最好，但知识推理类基准（MMMU）会因视觉特征被任务数据拉偏而下降——感知任务解冻并给小学习率，推理任务或小数据时冻结。

3核心

  1. 问题/背景：VLM 由三段组成——ViT 视觉编码器把图片切 patch 编成向量，projector 把视觉向量对齐到 LLM 的词向量空间，LLM 读图文生成。微调时每段可冻可训，「动不动 ViT」是第一个决定，各家做法不一：LLaVA 只训 projector 和 LLM（认为 ViT 预训练已足够好、动了容易坏），InternVL 2.5 在 SFT 阶段让 ViT 可训，Falcon-UI 在 Qwen2-VL 上试过解冻、没拿到稳定收益又冻了回去。
  2. 机制/方法：2025 年的受控消融在 Qwen2-VL-7B 与 Qwen2.5-VL-7B 上对比三组：不微调、只训 ViT、只训 LLM、ViT+LLM 联合。感知类指标对 ViT 是否可训非常敏感；反面证据是 Open Qwen2-VL 发现 SFT 解冻 ViT 平均分更好、但 MMMU 这类知识推理基准明显下降（视觉特征被任务数据拉偏、通用理解受损），Falcon-UI 在其任务上解冻也无稳定收益。
  3. 关键证据或数字：Qwen2.5-VL-7B 只训 ViT：平均 +1.31，MME 感知 +10，计数 +5.00，粗粒度感知 +1.31，MMVP +4.00；联合微调在此之上再 +1.34 平均、MME 再 +7.04，为三组里最好。
  4. 结论/判断：按任务决策——偏感知（计数、细粒度识别、GUI、图表、分辨率变化大）就解冻 ViT 并配更小学习率（约为 LLM 的 1/10，可分层 LR）；偏知识推理（MMMU 类）或数据量小时冻结更稳。实操顺序：先冻结跑基线，再解冻对比，全程监控 MMMU 类通用基准防退化。

5可迁移

  • 面试被问 VLM 微调策略时，先拆三段结构再按任务类型给决策规则，并主动提「解冻要配约 1/10 的 ViT 学习率、projector 通常全程可训、解冻后显存与训练时长都会涨」这些工程细节。
  • 通用方法论：任何「冻不冻某一模块」的争论，先冻结跑基线、再单变量解冻对比，并用一个通用基准守退化线——这套消融纪律适用于任何多模块系统。
