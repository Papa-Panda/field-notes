2一句话总结

自回归逐 token 生成、前文不可改的范式，同时带来了错误连锁放大、只能局部贪心、训练与推理分布不一致三大结构性局限，现实解法是长思维链 + 工具调用在框架内绕行。

3核心

  1. 问题/背景：主流大模型只做一件事——从左到右预测下一个 token，前文一旦生成便固定。幻觉、复读、数学算错等毛病大多可追溯到这一范式本身。
  2. 机制/方法：三个局限分别是：①滚雪球错误——某一步出错后，后续生成只能基于错误前文继续，错上加错；②无法全局规划——每步只选当前概率最高的 token，是局部贪心，对需要先定整体结构（如长代码架构）的任务天然吃亏；③曝光偏差（exposure bias）——训练用 teacher forcing 喂正确前文，推理喂模型自己的输出，分布不一致，长链生成越走越偏。
  3. 关键证据或数字：挑战者扩散语言模型可并行解码多个 token 并反复迭代修正，更像「从模糊到清晰」，但当前质量与稳定性仍明显不如自回归，尚未取代成功。
  4. 结论/判断：工程上的现实解法不改范式本质：长思维链分步推理 + 自我验算（在自回归内模拟回溯修正），以及把精确计算外包给工具调用，绕过短板。

4可迁移

  • 面试被问「幻觉从哪来」时，可把曝光偏差列为结构性来源之一：训练/推理分布不匹配，而非单纯数据问题。
  • 做 Agent / 长链推理系统时，默认前文错误会连锁放大，应在关键步插入校验与回滚点，而不是指望模型自我纠正。

5疑问 / 下一步

  • 扩散语言模型若在质量上追平，自回归的推理 infra（KV cache、连续批处理）有多少能直接复用？
