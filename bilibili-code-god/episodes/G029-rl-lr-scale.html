2一句话总结

RL 全参学习率普遍比 SFT 小一个数量级（ $10^{-6}$ – $5\times10^{-6}$ 对 $10^{-5}$ – $2\times10^{-5}$ ），因为 on-policy 数据会把大步子的误差正反馈放大、崩溃是断崖式的；学习率本质上是在给采样分布上保险，而 LoRA 因为只更新一小块参数，等效步长小，反而可以用回 $10^{-5}$ 。

3核心

  1. 问题/背景：SFT 学习率大家熟（ $10^{-5}$ – $2\times10^{-5}$ ），RL 开源配方却几乎都写 $10^{-6}$ 量级，没人讲为什么。本期把三档数放在一条对数轴上对比：SFT 全参、RL 全参、RL+LoRA。
  2. 机制/方法：解释分三层。其一，数据来源不同：SFT 数据固定，步子迈偏了下一步还是同一批数据把你拉回来；RL 是 on-policy，每步训练数据由当前策略自己采，步子迈偏，下一批数据就来自偏了的分布，误差正反馈放大。其二，策略梯度是优势加权的采样估计，一组 8 条回答算出的优势噪声很大，大步长等于把噪声一并放大。其三，KL 与 clip 只是局部约束，管单步比值；学习率管的是全局步长、整体跑多远。视频也坦承这套解释是直觉而非定理，但能预测「崩溃是断崖式而非渐变」这一现象。
  3. 关键证据或数字：VideoThinker 在 Qwen2.5-VL-7B 上跑 GRPO 2500 步扫四档： $10^{-6}$ 各基准 39–80， $3\times10^{-6}$ 略低， $5\times10^{-6}$ 整体最好（43–81）， $10^{-5}$ 严重退化、最差基准掉到 1.14% 近乎没训——可用区间不到一个数量级，再上一档就崩。反面证据是 JustRL 的「最笨配方」：恒定 $10^{-6}$ 、batch 256、每题 8 条 rollout、clip 上界 1.28、温度 1.0，无调度、无参考模型重置、无长度惩罚、无课程；两个 1.5B 模型同一套超参零调参分别训 4380 步与 3440 步，熵在 1.0–1.6 自然震荡不漂移、奖励单调上升、回答长度从约 8000 自然压缩到 4000–5900，基准平均 54.87 与 64.32，算力只有对手的 1/2 到 1/5（作者注明博客未做学习率消融， $10^{-6}$ 是常规取值而非证明最优）。LoRA 例外来自 PEFT-RLVR：在 DAPO 上 LoRA 的 $10^{-5}$ / $5\times10^{-6}$ / $10^{-6}$ 得分 42.5 / 42.3 / 42.3，一个数量级内几乎不敏感；同篇算法间差距（42.5 / 42.0 / 40.5）比学习率差距还小，作者判断学习率量级是 RLVR 稳定性的决定因素。
  4. 结论/判断：LoRA 能用大学习率，是因为只更新低秩的一小块参数、等效步长本来就小，与「LoRA 学习率是全参十倍」的既有结论一致。实操三条：全参 RL 从 $10^{-6}$ 起步、最多到 $5\times10^{-6}$ ， $10^{-5}$ 别碰；LoRA 做 RL 直接用 $10^{-5}$ ，不用像全参那样保守；先用恒定学习率跑长，盯熵与奖励两条线——熵不漂移、奖励单调涨就别动，只有明显失败再加调度与惩罚。

4关键数字

场景 常用学习率
SFT 全参 $10^{-5}$ – $2\times10^{-5}$
RL 全参（GRPO 类） $10^{-6}$ – $5\times10^{-6}$
RL + LoRA 可回到 $10^{-5}$（比全参大一个量级）
VideoThinker 消融中 $10^{-5}$ 的最差基准 1.14%（断崖崩溃）
JustRL 恒定 $10^{-6}$ 训 3440–4380 步，熵 1.0–1.6 不漂移

5可迁移

  • 自己跑 GRPO 时把学习率当稳定性预算而非效率旋钮：先恒定小学习率跑长程基线，监控熵漂移与奖励单调性，再决定是否加调度。
  • 面试问 RL 超参，先答 $10^{-6}$ 量级及其 on-policy 正反馈理由，再答 LoRA 的十倍例外，层次立刻分明。

6疑问 / 下一步

  • 纯文本模型的崩溃阈值与多模态 7B 是否同形（视频只给了形状类比），值得在自己的 pilot run 里用小扫参验证一次。
