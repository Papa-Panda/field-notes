## 一句话总结

标准注意力的输出本质是对 V 的线性加权平均，表达力有上限且伴随 attention sink；在注意力输出后逐头乘一个 sigmoid 门，就能同时引入非线性、产生输入相关的稀疏、并消除 sink。

## 核心

1. **问题/背景**：标准注意力用 softmax 权重对 value 向量做加权平均，这一步是纯线性组合，深网络也改变不了这一层的表达力天花板；另一个毛病是 attention sink——与内容无关的情况下，大量注意力被序列开头几个 token 吸走。
2. **机制/方法**：Gated Attention 的改动极小：在注意力输出之后，逐元素乘以一个由输入算出的 sigmoid 门，且每个注意力头有自己独立的门。门值落在 0 到 1 之间，对原输出做逐元素调制。
3. **关键证据或数字**：实测门值平均仅约 0.116，说明多数输出被压低、只保留真正重要的部分；加门后 attention sink 强度从很高降到接近零；在 5 亿到 140 亿参数的多种规模模型上都有一致提升。
4. **结论/判断**：一个门同时办成三件事——在 V 投影与输出投影之间插入非线性、带来输入相关的稀疏、顺带消灭 sink；改动约一行代码却跨规模稳定有效，这是它拿下最佳论文的核心说服力。

## 可迁移

- 面试/讨论架构改进时可用这条逻辑链：先指认标准组件的数学本质缺陷（线性聚合），再给最小改动（逐头门控），最后用跨规模一致性收尾——这是顶会级「小改动大叙事」的范式。
- 做长上下文或 KV cache 相关工作时，attention sink 是绕不开的现象；门控给出了一条从结构上消除 sink 的路线，可与 StreamingLLM 的保留 sink token 路线对照理解。
