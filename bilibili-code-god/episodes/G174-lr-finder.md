## 一句话总结

LR Finder 用一次短跑把学习率从极小值一路指数放大、记录 loss 画成曲线，最优学习率取曲线最陡下降点再除以十，免去逐个猜学习率。

## 核心

1. 问题/背景：学习率是最重要的超参，太大发散、太小不学，靠猜要反复试错很多轮。
2. 机制/方法：从约 $10^{-7}$ 的极小学习率开始，每 batch 逐步放大到约 $10^{-1}$ ，同时记录 loss，跑约 100–200 个 batch 画出 loss 对学习率的曲线。曲线分三段：左端平稳微降（学习率太小）、中段急剧下降（刚好）、右端反弹（太大发散）。
3. 关键证据或数字：最优学习率取急降段中最陡点的学习率除以十（约在最低点左侧一个量级处），例如陡降发生在 $10^{-3}$ 量级附近时，取 $3\times10^{-4}$ 一类数值作起点。大模型经验区间：预训练 $10^{-4}$–$5\times10^{-4}$ 、SFT $10^{-5}$–$5\times10^{-5}$ 、RL $10^{-6}$–$10^{-5}$ 。
4. 结论/判断：注意事项四条——曲线嘈杂需移动平均平滑；batch size 变了要重跑；Finder 本身不加 warmup 跑；它只定初始学习率，衰减策略另选。实际训练时 Finder 给出的峰值偏大，须配合 warmup（占总步数 $1\%$–$2\%$ ，从零线性升到峰值）再接 cosine decay。

## 关键数字

| 项目 | 数值 |
|---|---|
| Finder 扫描范围 | 约 $10^{-7}$ → $10^{-1}$ |
| 扫描步数 | 约 100–200 个 batch |
| 取值规则 | 最陡下降点学习率 ÷ 10 |
| warmup 占比 | 总步数 $1\%$–$2\%$ |

## 可迁移

- 小规模试跑定学习率是后训练调参的标准动作：新基座、新数据配比或 batch size 变化后，先花一两百步扫曲线再正式开训，比拍脑袋省卡。
- 面试答学习率怎么定：先讲 range test 原理与读图方法，再给各阶段经验区间，最后提 warmup + cosine 的配套，完整度明显高于只报经验值。

## 疑问 / 下一步
