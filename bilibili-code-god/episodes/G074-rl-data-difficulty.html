2一句话总结

RL 数据的难度是相对于待训模型的量：标准做法是让模型对每道题采样 8 次用通过率定难度，删掉全对题、做成难题为主的镜像 J 形分布并在训练中动态重估；理论上 50% 通过率处信号最强，还可用前缀回放在训练中把漂移的通过率拉回 50%。

  1. 问题/背景：与 SFT 看数据本身质量不同，RL 中一道题有没有用取决于当前模型能否做对一部分：全对或全错的题在组内优势上都是零信号，只有有对有错的题才产生梯度——同一道题对 7B 是难题、对 32B 可能是送分题，所以难度只能用要训的那个模型来测。
  2. 机制/方法：Polaris 的配方：基座对每道题采样 8 次得通过率，八次全对的题全部删除（只会产生零优势、白烧算力），保留难题为主、简单题为辅的题目构成镜像 J 形分布（通过率直方图难端高、易端低），训练中周期性重估难度、动态过滤保持分布不漂移；Skywork-OR1 路线类似，另加人工与 LLM 裁判做质量把关，一线常用阈值是保留 pass@8 在 12.5%–50% 之间的题。更进一步的理论结果（2026 年 5 月论文）：二值奖励下通过率 50% 时四个信号指标同时最大——奖励熵最高、动态采样过滤后存活的组最多、RLOO 优势能量最大、成功–失败配对数最多；偏向 0 或 1 信号都衰减。为对抗训练中通过率随模型变强而上漂，该工作提出前缀采样回放：对老师做不出的题接一段曾经成功的前缀，对全对的题接一段失败的前缀，制造组内正负样本；回放 token 在 loss 里 mask 掉，只优化新生成的续写。
  3. 关键证据或数字：Polaris 4B 模型在 AIME24 上达到 81.2%（视频称 7B 用 5.3 万题、4B 只用 3 万题；另一处给出 4B 的 AIME24 数值 79.4%，口径待核）；前缀回放在 SWE-bench Verified 上让 34B、32B 模型端到端提速 2.01 倍与 1.55 倍，14B 峰值从 0.274 涨到 0.295，AIME25 在 4B、8B 上同样成立。实操流程五步：采样定难度 → 分桶删全对、全错按任务少量保留或走课程/提示 → 整成镜像 J 形 → 训练中定期重估动态过滤 → 通过率漂向 1 时用前缀回放或补难题拉回 50%。
  4. 结论/判断：数据准备是「零梯度组」问题的上游治理：前端把通过率分布做对，后端动态采样要丢弃的组就少得多；目标不只是删全对全错，而是把整体通过率持续维持在信息量最大的 50% 附近。

5可迁移

  • 自建 RLVR 数据管线时直接套用：待训模型采样定难度 + 镜像 J 形 + 周期重估，这是可迁移的数据工程 SOP，比用固定难度标签（如题目来源年级）可靠得多。
  • 面试讲出两点即是满分骨架：「难度相对于模型」与「50% 通过率信号最大」；还能顺带点出它与 DAPO 动态采样是同一问题的上下游两种解法。
