2一句话总结

LLaVA 证明了给大模型装眼睛不必重造多模态巨无霸：CLIP ViT + 一个极简投影层 + 现成语言模型，再配两阶段训练（先冻两头只训投影层对齐，再放开语言模型做指令微调）就够了。

3核心

  1. 问题/背景：让语言模型看图，卡点不是它不认识图片，而是视觉与语言是两个不同的世界：视觉编码器输出的特征向量与语言模型的词嵌入向量维度、含义都对不上，直接喂等于让模型听方言。
  2. 机制/方法：
  3. 架构只有三段：视觉编码器用 CLIP 的 ViT，把图片看成一串视觉特征；中间是投影层；第三段是现成已训好的语言模型，负责理解与回答。
  4. 投影层是全片主角：就是一个线性层或两层 MLP，只干一件事——把视觉特征投影到语言模型的词嵌入空间，变成所谓的视觉 token，相当于学一本把「视觉方言」翻成「语言普通话」的词典；翻译完，视觉 token 与文本 token 并排拼成一条序列一起喂入，模型不区分谁是图谁是字。
  5. 两阶段训练：第一阶段特征对齐预训练，冻住视觉编码器和语言模型、只训投影层，用海量图文配对数据逼它学会对齐；第二阶段指令微调，放开语言模型与投影层一起训，用看图对话、看图问答等指令数据教模型不光看懂、还能好好回答。
  6. 与复杂路线对照：另一派在视觉与语言之间塞结构复杂的桥接模块、还要额外学一大堆查询向量；LLaVA 反其道把桥砍到最简，结果不仅能行、效果还出奇地好。
  7. 关键证据或数字：实际喂入时，一张图经 ViT 与投影层变成 500 多个视觉 token，拼在文字问题前面组成整条输入序列；整套方法只新增一个小投影层，不重训巨无霸模型。
  8. 结论/判断：接入多模态未必要靠复杂结构，一个对齐得当的投影层往往就够打——简单、省钱、又稳又省是这条路线的核心价值。

4可迁移

  • Post-training：两阶段思路可直接迁移——先冻结主体只训新接口做对齐，再解冻做指令微调，是给现成 LLM 嫁接新模态/新工具时的低风险默认配方。
  • 面试：讲 LLaVA 按「三段架构 → 投影层做翻译 → 两阶段训练」答，并与 Q-Former 式复杂桥接做对比，点出「极简反而效果好」的反直觉结论。
