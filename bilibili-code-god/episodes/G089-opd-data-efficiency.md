## 一句话总结

OPD 极度数据高效：一道难题就能把六个数学基准平均分做到全量 1.7 万条的九成以上，按师生平均通过率挑出的 8 道最难题直接追平全集；真正驱动收益的是思维链长度，而不是流行的高熵 token 说法。

## 核心

1. **问题/背景**：OPD 中学生自己采样回答，老师对每个 token 给概率，学生逐 token 用反向 KL 向老师靠拢——数据是学生自生成的（无分布偏移）、每个 token 都有信号。问题是：信号这么密，到底需要多少道题？
2. **机制/方法**：单题实验显示一道题足够稳定涨分，因为被学的不是这道题的答案，而是老师对成百上千条不同采样轨迹的逐 token 分布。驱动因素实验做了长度控制：把两道题的 rollout 长度限制成一样后，高熵题与低熵题的差距缩到 0.5% 与 −0.9%，几乎消失——真正的驱动是更长的思维链，它让学生在长程推理上持续对齐老师，学到反思、回头检查这类短回答里没有的模式。选题规则：学生与老师各采样 16 次，通过率取平均 ， $A$ ，只挑 ， $A < 0.1$ ，的最难题。
3. **关键证据或数字**：最好的一道题（编号 973）六基准平均 51.7%，全量 1.7 万条 53.7%；只挑 8 道最难题得 53.6%，与全集持平。更反直觉的是师生训练准确率都为零的无解题照样提升验证分，说明学的是轨迹结构而非正确答案。结论在 1.5B–7B 数学域上验证，其他域需重跑。
4. **结论/判断**：蒸馏的数据是难比多重要；选题零额外参数、零复杂优化——用师生各 16 次采样的平均通过率排序，从最难的开始挑；别用熵当筛子，看思维链长度与难度。

## 关键数字

| 设置 | 六基准平均分 |
|---|---|
| 单道难题 OPD | 51.7% |
| 8 道最难题（ ， $A < 0.1$ ，）OPD | 53.6% |
| 全量 1.7 万条 OPD | 53.7% |
| 长度控制后高熵 vs 低熵题差距 | 0.5% / −0.9%（基本消失） |

## 可迁移

- post-training 数据工程：OPD/蒸馏的选题预算应花在难度标定（师生双采样通过率）上，而不是堆题量；无解题不必剔除。
- 面试准备：能解释 OPD 为何单题成立——学生轨迹的多样性 × 老师逐 token 分布构成密集监督，题目只是采样入口。

## 疑问 / 下一步

- 思维链长度是收益的因还是果：强行让简单题生成长链（如加反思提示）能否复现难题的收益，视频未验证。
