2一句话总结

GRPO 的两个偏差都藏在分母里：长度归一让长错误回答罚得更轻（越训越长），除以组内标准差放大了太易与太难题的权重；Dr. GRPO 删掉这两个分母，DAPO 再放宽 clip 上界治熵坍塌、加动态采样保梯度。

3核心

  1. 问题/背景：上期看似完美的 GRPO 公式，被两篇后续工作各挑出一个分母的问题：偏差不在思想、在归一化的实现细节。
  2. 机制/方法：第一个偏差是回答长度：优势为负时再除以长度，越长的错误回答单位惩罚越轻，于是模型越训越长；第二个偏差是标准差：除以组内标准差会放大太易和太难的题的相对权重。Dr. GRPO 的修法干脆利落——把这两个分母都删掉。DAPO 改的是别处：把 clip 上界从 0.2 放宽到 0.28（clip-higher），因为概率只有 0.01 的 token 原来最多涨到 0.012、根本动不了，这正是熵坍塌的成因；再加动态采样（组内全对或全错就没有梯度，直接换题）、损失按 token 平均而非按条平均（长回答不再被稀释），并把 KL 整个去掉。
  3. 关键证据或数字：DAPO 配置在 Qwen2.5-32B 上 AIME 拿到 50 分，比 R1-Zero 的 47 分高，且训练步数只用一半。
  4. 结论/判断：记忆锚点就是「两个分母、两个偏差」：归一化不是无害的工程细节，它直接改变优化偏好；clip 放宽治熵坍塌、动态采样保梯度，是配套的三件套。
