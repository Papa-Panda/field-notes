REINFORCE（Williams, 1992）；策略梯度定理

2一句话总结

策略网络的输出是概率分布、动作靠随机采样得到，采样这一步不可导；log-derivative 恒等式把「对采样结果求导」改写成「对对数概率求导」，于是策略梯度变成对数概率梯度乘以动作价值，REINFORCE 再用整条轨迹的真实回报做这个价值的无偏估计。

3核心

  1. 问题/背景：价值派（如 DQN）先学价值表再贪心选动作；策略派换思路，用神经网络直接吃状态、输出每个动作的概率，目标是最大化期望回报，从而需要目标对参数的梯度。但链路中间有一步硬伤：动作是从分布里随机抽出来的，掷骰子式的采样不可微，梯度流到这里就断了。
  2. 机制/方法：关键恒等式是 $\nabla_\theta p = p \nabla_\theta \log p$ ，即对数概率的梯度等于概率梯度除以概率本身。把求期望回报梯度的问题改写后，采样动作不再需要被求导，需要求导的只是策略网络自己输出的对数概率——完全可导。由此得到策略梯度定理的核心形式：

$$\nabla_\theta J(\theta) = \mathbb{E}\left[\nabla_\theta \log \pi_\theta(a|s) \cdot Q(s, a)\right]$$

前半段负责「让这个动作更容易被选到」，后半段的动作价值是权重，决定往该方向推多远。回报为正就抬高该动作概率，为负就压低。 3. 关键证据或数字：公式中唯一的未知量是动作价值。REINFORCE 的朴素解法是让智能体把一整局跑完，用该步之后真实拿到的回报直接当价值估计——单个样本噪声大，但期望上无偏，长期平均方向正确，于是「能采样、能算回报」就能训练。 4. 结论/判断：策略梯度的全部魔法在一处替换：不可导的采样被留在期望里，只对可导的对数概率求梯度并用回报加权。这也是 PPO、GRPO 等现代 LLM 后训练算法共同的数学地基。

4可迁移

  • GRPO 的 loss 本质就是这条公式去掉 critic、换上组内相对优势；看懂 log-derivative 技巧，就能解释为什么 RL 训练里到处是 $\log \pi$ 的差与比值（importance ratio 也是同源）。
  • 面试答法：先点出「采样不可导」这个坎，再写恒等式接通梯度，最后落到 REINFORCE 的无偏但高方差——顺带引出 baseline 与 Actor-Critic 的降方差动机。

5疑问 / 下一步

  • REINFORCE 的高方差具体大到什么程度、减 baseline 后方差如何随动作数变化，值得做一次小实验量化，而不是只停留在「无偏但方差大」的定性说法。
