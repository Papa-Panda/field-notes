## 一句话总结

GRPO 的奖励曲线可以写成一个受随机力驱动的阻尼振子方程：动量对应质量、off-policy 陈旧度吃掉阻尼、group size 只出现在噪声项里——由此能提前算出稳定阈值，并用四组读数把四种训练故障分开诊断。

## 核心

1. **问题/背景**：调 GRPO 时动量、rollout 刷新间隔、group size 基本靠经验试。视频介绍的工作主张：这三者其实是同一根「弹簧」的三个参数，奖励曲线服从二阶动力学而非指数饱和。
2. **机制/方法**：把奖励与上限的偏差记为 ，$E = P - P^*$ ，其演化类比弹簧上的小球。质量来自优化器动量，刷新滞后（数据陈旧）也会加到质量里；阻尼基底是 ，$1 - \mu$ ，但陈旧度会侵蚀它，侵蚀量正比于 ，$K \eta \tau$ ，其中 ，$K$ ，是奖励函数在固定点附近的曲率（可由训练早期斜率测出）、 ，$\eta$ ，是学习率、 ，$\tau$ ，是刷新间隔；随机力的强度正比于优势方差除以 group size，即 ，$\sigma_A^2 / G$ ，$G$ ，只出现在噪声项，是「温度」，不改变弹簧本身。
3. **关键证据或数字**：在三个模型（4B、7B Chat、R1 蒸馏 1.5B）上用二值奖励在 GSM8K 训练，曲线拟合的 ，$R^2$ ，全部不低于 0.91，最高 0.97； ，$G$ ，从 4 增到 16 时拟合出的平台值与曲线形状不变，稳态涨落按 ，$1/G$ ，缩小，验证了「G 只调噪声」的预言。
4. **结论/判断**：由阻尼比 ，$\zeta = C / (2\sqrt{KM})$ ，可分出三种曲线形态：远大于 1 是过阻尼（单指数直接爬升），约等于 1 是临界阻尼（慢启动—加速—平台的三段式，即最常见的形状），小于 1 是欠阻尼（在平台附近来回震荡）。稳定性要求阻尼为正，即满足下面阈值，否则线性不稳定、训练发散：

$$K \eta \tau < 1 - \mu$$

## 关键数字

| 量 | 基线/条件 | 结果 |
|---|---|---|
| 曲线拟合优度 ，$R^2$ | 三个模型、GSM8K 二值奖励 | ≥ 0.91，最高 0.97 |
| Group size | ，$G$ ，：4 → 16 | 平均曲线不变，稳态涨落按 ，$1/G$ ，缩小 |

## 可迁移

- 排障时不要只看奖励一条线：视频给出四组读数分离四种病——作弊看训练/评测归一化进度的对角线偏离（耦合比趋零 = 评测停涨而训练还在涨）；优势退化看 ，$\sigma_{adv} / \sqrt{G}$ ，在不同 ，$G$ ，下是否重合、以及全组同奖励的 prompt 占比是否爬向 1；策略集中看熵降与 KL 升；数值不稳定看梯度范数震荡与最大重要性比。这套面板可直接借鉴到自己的 RL 训练可观测设计里。
- 稳定阈值里的 ，$K$ ，可以从训练最初几步的斜率估出，意味着「会不会发散」能在烧大算力之前先算一遍；想稳平均曲线时调 ，$G$ ，只降抖动、不改走向。

## 疑问 / 下一步

- 该振子模型是在 GSM8K 二值奖励、单任务短程训练上验证的；换到长链多轮 Agent RL（奖励更稀疏、陈旧度结构不同）时，质量/阻尼的分解是否还成立，值得留意后续工作。
