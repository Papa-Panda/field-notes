## 一句话总结

OPD 的师生距离是个倒 U：太像没新东西、太远则逐 token KL 变噪声。Distilled RL 干脆换掉老师的角色——学生仍按奖励做策略梯度，老师只给每个 token 定权重，重新分配学生自己的梯度。

## 核心

1. 问题/背景：OPD 让学生自采样、老师逐 token 给概率、学生用反向 KL 贴近老师，监督密集、起步快；但老师太像时蒸馏原地踏步，跨家族时分词与习惯都不同，学生踩不到老师喜欢的 token，KL 指导变噪声。纯 RL 则只有结果奖励，一条几千 token 的回答只有一个 0/1，信用分配粗、也学不到新知识。
2. 机制/方法：保留 RL 骨架：学生采样、按奖励算优势、走策略梯度；老师只决定 token 级权重 ， $w_t$ ，目标是优势乘 $w_t$ 再乘学生 log 概率。三个关键设计：一是反向重要性采样，$w_t$ 取老师概率与学生概率之比并 clip 极端值，老师更喜欢的 token 权重大；二是负样本重置，只对优势为正的成功轨迹用老师重加权，失败轨迹权重统一为 1——否则失败轨迹上老师喜欢的 token 会被更重地惩罚，等于把学生往老师的反方向推；三是序列几何归一化，学生采出的 token 在老师那里概率天然偏低，直接用比率会系统性压低所有成功轨迹，故把每条序列 clip 后的比率除以其几何均值，只保留 token 间的相对偏好。
3. 关键证据或数字：老师为 8B 量级，学生含同家族 4B 与跨家族蒸馏模型，数据为 DAPO 17K，指标平均 pass@1：同家族 Distilled RL 58.96，高于 OPD 55.97 与纯 RL 57.40；跨家族 40.00 对 35.27 与 36.86，差距反而更大——因为不再要求 token 级模仿，家族差异的噪声被几何归一化与负样本重置压住了。
4. 结论/判断：老师的开销与 OPD 一样（只需一次前向给学生轨迹算 token 概率）；clip 与几何归一化必须同时开，只开一个会系统性偏置；选老师不用再纠结家族，能力强就行。与前几集对照：OPD 是模仿，PowerOPD/DOPD 改 KL 的形式，Distilled RL 改的是老师的角色。

## 可迁移

- OPD 落地：遇到跨家族师生先怀疑逐 token KL 的有效性，可切换到「老师只做梯度重加权」的范式，保留 RL 的探索与 on-policy 性。
- 面试可讲：蒸馏与 RL 的统一视角——老师信号可以进入目标函数的三个位置（拟合目标、奖励、梯度权重），位置不同，对师生差距的鲁棒性完全不同。
