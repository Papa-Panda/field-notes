2一句话总结

Q 学习用「即时奖励 + 下一步最优价值」迭代修正 Q 表；状态空间爆炸后改用神经网络近似 Q 表（DQN），再靠经验回放和目标网络两招把训练稳住，直接从像素学会玩游戏。

3核心

  1. 问题/背景：强化学习要在试错中最大化累计奖励，需要为每个「状态-动作」估一个价值分（Q 值），分高者优先选；但初始 Q 表全是瞎填，必须有办法把它练准。
  2. 机制/方法：TD 更新——用当前步奖励加上下一状态的最大 Q 值构造更可靠的目标，回头修正当前格；状态多到表装不下时，用神经网络输入画面、输出各动作 Q 值来近似 Q 表。
  3. 关键证据或数字：直接训网络会剧烈震荡，两招补丁解决：经验回放把经历存池、随机抽样打破时序相关；目标网络用更新更慢的旧网络算目标，避免「追自己的尾巴」。同一套 DQN 代码不改，仅喂像素与分数，就在几十款 Atari 游戏上从乱按练到反超人类，且从未被告知规则。
  4. 结论/判断：DQN 的骨架是「函数近似 + 自举目标」，两大不稳定性来源（相关样本、移动目标）分别由回放池和目标网络对治，这套组合是后续深度 RL 的地基。

4可迁移

  • 面试讲 DRL 不稳定时，按「相关性 → 经验回放；目标漂移 → target network」一一对应，比罗列技巧更有说服力。
  • RL infra 视角：回放池本质是把在线采样转成可复用的离线数据集，容量、采样策略与吞吐直接决定训练效率，设计 rollout 存储时可借鉴。
