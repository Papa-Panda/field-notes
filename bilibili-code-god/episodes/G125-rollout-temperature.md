## 一句话总结

GRPO 类训练的信号来自组内对错混合，rollout 温度的目标就是把正确率调到中间地带：太低全对/全错无区分度，太高全错同样没信号，监控 advantage 方差是否为零是最直接的判据。

## 核心

1. **问题/背景**：每个 prompt 采样一组回答（如 group size 8），组内归一化后才有梯度信号；温度控制随机性，直接决定这组回答的质量分布。
2. **机制/方法**：理想状态是组内有对有错。温度太低，8 条回答几乎一样，要么全对要么全错；温度太高，质量参差、难题上可能全错。经验起点是数学/通用任务约 1.0、代码约 0.7，简单题可降到 0.5（容易做对、不需要太多探索），难题升到 1.0 增加探索。
3. **关键证据或数字**：诊断闭环是看 advantage 方差——趋近于零说明这组采样没有区分度；一组全对就降温、一组全错就升温。若调温后仍无信号，问题多半不在温度，而在题目难度配比。
4. **结论/判断**：固定温度对简单题太热、对难题太冷，进阶方案是 per-prompt 自适应温度——按模型对该类题的当前正确率动态调（正确率高降温省探索，低则升温加探索），视频称 veRL 等框架已支持。

## 关键数字

| 场景 | 温度起点 |
|---|---|
| 数学/通用任务 | 约 1.0 |
| 代码任务 | 约 0.7 |
| 简单题 | 约 0.5 |

## 可迁移

- RL 排障时把「组内全对/全错比例」与「advantage 方差」列为 rollout 健康度的一等指标，先于调学习率去查。
- 温度调参与难度筛题（G074）是同一问题的两面：温度是在采样侧救区分度，筛题是在数据侧保证区分度。
