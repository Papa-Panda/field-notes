## 一句话总结
标注质量靠的是一套能自我纠错的流程——双人独立标注 + Cohen's Kappa 把关 + 金标题暗检，而不是堆人力。

## 核心
1. **问题/背景**：标注者会犯错且有主观偏差，质量不控住，模型只会把错误学得更牢，数据量再大也救不回来。
2. **机制/方法**：五步流程——写清带正反例的标注规范、培训、少量试标校准、正式标注（每条至少两人独立标）、分歧仲裁。一致性用 Cohen's Kappa 度量（它扣除了随机命中的部分，比裸一致率可信）：大于 0.8 很好，0.6–0.8 可接受，低于 0.6 要重新培训或改规范。
3. **关键证据或数字**：五道质控闸门——预筛（测试题淘汰标注者）、金标题暗检（混入 5%–10% 已知答案的题，准确率低于 90% 淘汰）、定期抽检约 5%、每周反馈纠正、动态淘汰。放量门槛是抽 10%–20% 任务双标、Kappa 达到 0.6 以上。
4. **结论/判断**：质量大于数量——视频给出的判断是少量金标数据的价值可以压过大量杂数据；规范要随错误分布周复盘迭代升版。

## 关键数字
| 指标 | 阈值 |
|---|---|
| Cohen's Kappa 放量线 | ≥ 0.6（> 0.8 为优） |
| 金标题暗检准确率淘汰线 | < 90% |
| 定期抽检比例 | 约 5% |

## 可迁移
- SFT/偏好数据 curation 面试高频题：把 Kappa 门槛、金标题、仲裁三件套讲成完整质控闭环。
- 自己做数据时先写 bad case 手册再开标，边界情况全部举例，不让标注员猜。
