## 一句话总结

输入 embedding（ $V \times D$ 查表）与输出 LM head（ $D \times V$ 打分）形状互为转置、本质是同一套「词 ↔ 语义向量」对应，共享一块权重能省上亿参数并顺带正则化，解绑则换表达自由度。

## 核心

1. **问题/背景**：模型一头一尾各有一块大矩阵——开头把词编号变成向量，结尾把隐藏向量变回词表分数，看似两件事，却共用一个矩阵。
2. **机制/方法**：输入端是查表：按词编号取 embedding 矩阵的一行；输出端是打分：隐藏向量与输出矩阵每一列做点积得到 logits ，再过 softmax 。两矩阵形状互为转置，共享即输入端当表查、输出端转置后逐行点积打分。
3. **关键证据或数字**：以词表 32000 、维度 4096 计，一块矩阵约 1.3 亿参数，词表越大共享省得越多；GPT-2 等经典模型默认共享，输入输出同处一个向量空间、天然对齐。
4. **结论/判断**：这是权衡题——词表大、参数吃紧就共享（省参数 + 正则化）；想让输入输出各学各的、表达更自由就解绑，如 LLaMA 用两块独立矩阵，没有绝对对错。

## 可迁移

- 手算参数量（ $12Ld^2 + Vd$ 口径）时要先确认是否 tying：共享只算一份 $Vd$ ，漏判会差出上亿。
- 面试区分度题：能讲清「查表 = 取行、打分 = 转置点积」这层对称性，就答到了点子上。
