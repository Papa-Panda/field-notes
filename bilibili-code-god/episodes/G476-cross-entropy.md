## 一句话总结

交叉熵的全部直觉就是对模型给正确类别的概率取负对数：越自信且正确损失越小，又自信又错则惩罚趋向无穷；BCE 与多分类 CE 只是同一思想在二分类与多分类下的两种写法。

## 核心

1. **问题/背景**：交叉熵是分类任务的标准损失，衡量预测分布与真实答案的差距。要讲清它到底在惩罚什么，需要把二分类（配 Sigmoid、二元交叉熵）与多分类（配 Softmax、多分类交叉熵）统一起来看。
2. **机制/方法**：核心是负对数曲线：给正确类的概率越接近 1 ， $-\log p$ 越接近 0 ；概率越小惩罚急剧上升直至无穷，所以它对「自信地犯错」惩罚极重。二分类公式里标签只能取 0 或 1 ，两项每次只有一项存活，分别把正类概率往 1 或往 0 推。多分类时标签是 one-hot，求和中只有正确类那一项系数为 1 ，整个损失塌缩成正确类概率的负对数——BCE 就是多分类 CE 在两个类别时的特例。
3. **关键证据或数字**：手撕实现三步：先用 Sigmoid 或 Softmax 把原始输出转成概率；再用 clamp 把概率夹在远离 0 与 1 的区间内，防止 $\log 0$ 产生负无穷、导致梯度爆炸或 NaN ；最后套公式逐样本计算再取平均。
4. **结论/判断**：一句话，交叉熵罚的是「对正确答案不够自信」；写代码时数值稳定（clamp）是必备项，不是可选优化。

## 可迁移

- 面试手撕 CE 时主动提 clamp / log-sum-exp 稳定化处理，是明确的加分项。
- SFT 训练里 label 设 -100 的 ignore 机制本质就是在 CE 求和时跳过这些位置，与本期的「只有正确类一项存活」是同一套掩码思路。
