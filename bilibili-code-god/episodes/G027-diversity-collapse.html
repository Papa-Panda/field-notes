2一句话总结

RLVR 的多样性坍塌几乎全发生在序列开头几个 token：入口段的熵位移是下游段的 11–16 倍，能力本身没丢、只是入口被锁住，所以只需对第 20–28 层做 checkpoint 差值插值就能找回三成多覆盖；而且这种两极化会顺着训练管线传到下一阶段，把可训练信号抽干。

3核心

  1. 问题/背景：RL 训完后 pass@1 涨、pass@k 掉是常识，但多样性具体死在哪一步不清楚。在能穷举全部解法的 Countdown 任务上（150 道测试题、379 个可行「入口家族」、平均每题 2.53 个），可以精确度量模型采样能碰到多少种解法入口。多样性之所以重要：它决定 pass@k 的上限，也决定下一阶段训练里还有没有「有对有错」的混合信号。
  2. 机制/方法：把每个有效解按第一个算术运算符切成「入口段」和「下游段」，逐 token 比较训练前后的熵位移；再用「给一个最小入口前缀、让模型续写」的访问—执行实验，区分「不会做」和「不从这个门进」。修复则用层级差值：只对晚期 checkpoint 与早期 checkpoint 在第 20–28 层的参数差做插值覆盖，其余层不动。
  3. 关键证据或数字：PPO 训后 pass@1 涨 50 倍以上，解覆盖率却从 0.337 掉到 0.111（-67%），入口家族覆盖 0.932→0.571，入口熵 1.585→0.760 nats；GRPO 公开 checkpoint 准确率翻三倍、覆盖掉 43%。熵位移方面，PPO 入口段每 token 约 4.50 nats、下游仅 0.28（差 16 倍），GRPO 为 8.08 对 0.71（差 11 倍）。给定入口前缀后，指定家族完成率从 0.018 跳到 0.212（翻十倍多），下游执行能力甚至比训练前更强——证明能力还在、入口被锁。层差值修复后覆盖率 0.111→0.152（相对 +37%），pass@1 还从 0.278 涨到 0.305；调温度、换提示词均无效，只有动权重才行。跨 Qwen2.5 7B/14B 的六个数学基准上入口段散度都大于下游，SimpleRL 训后首 token 熵降 30%–41%，采样预算加 50 倍 pass@64 纹丝不动。
  4. 结论/判断：坍塌是入口的锁死而非能力的消失，代价还会跨阶段传染：另一篇工作里 Qwen3-8B base 做数学 RLVR 后，指令遵循 pass@1 涨 6.5、best@32 却掉 9.8，原因是提示被两极化成全对或全错；先训指令遵循 RL 再训数学 RL 时，第 20 步混合支持的提示从 33.6% 掉到 1.6%，梯度随之消失。反例 OLMo 3 走 SFT→DPO→RLVR 阶梯保住了入口熵，多解 SFT 的覆盖是晚期 GRPO 的 2.6 倍。实操四条：盯首 token 的熵而非全局熵、SFT 阶段喂多解数据、想清楚阶段顺序、晚期崩了先用层差值救别急着重训。

5可迁移

  • 做 RLVR 监控时把 first-token 熵和组内「全对/全错」比例列为一级指标：混合组比例塌掉，等于后续 step 没有梯度信号，这比看 reward 曲线更早预警。
  • 面试谈 pass@k 下降不要只说「熵坍塌」：给出入口/下游分解、访问—执行实验和层插值修复，才算把「能力还在、分布变窄」讲到机制层。
