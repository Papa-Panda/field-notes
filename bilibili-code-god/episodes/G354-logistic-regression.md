## 一句话总结

逻辑回归 = 线性打分过 sigmoid 压成概率 + 交叉熵训练；名字里有「回归」，干的却是分类，且决策边界本质上是线性的。

## 核心

1. **问题/背景**：线性回归的输出遍布整个实数轴，没法直接当概率用（负数、超过 1 都无意义），而且远离群体的样本会把拟合直线拽歪。分类需要一个把任意实数温和压回 $ (0, 1) $ 区间的「压缩器」。
2. **机制/方法**：这个压缩器就是 sigmoid 函数 $ \sigma(z) = \frac{1}{1+e^{-z}} $ 。它有三个关键性质： $ z = 0 $ 时恰为 0.5，是分类的中线；两端渐近 0 和 1、永不越界；导数形式极简， $ \sigma'(z) = \sigma(z)(1-\sigma(z)) $ ，让反向传播非常干净。模型流程是先算线性打分 $ z = w \cdot x + b $ ，再过 sigmoid 得到正类概率。取 0.5 为阈值时，判正判负等价于 $ z $ 的正负，所以决策边界就是 $ w \cdot x + b = 0 $ 这条直线/超平面——想要弯曲边界，得靠特征变换或神经网络。多分类有两条路：一对多（OvR，每类训一个二分类器）与 softmax 回归（sigmoid 的多类推广，现代网络输出层的标配）。
3. **关键证据或数字**：损失为什么不用均方误差而用交叉熵，视频给了两个理由：其一，sigmoid 套上均方误差后损失面非凸、局部最优多，梯度下降容易卡住；交叉熵与 sigmoid 组合后是凸的，有唯一全局最优。其二，交叉熵来自最大似然估计（样本独立同分布下最大化标签似然，化简即得），且对「自信地答错」惩罚极重——真实标签为 1 而预测趋近 0 时损失趋于无穷。
4. **结论/判断**：记住三件事——本质是分类而非回归；边界是线性的；损失用交叉熵而非均方误差，且这源于凸性与最大似然两方面的必然。

## 可迁移

- 面试被问「逻辑回归为什么是分类算法 / 为什么用交叉熵」时，按「压缩器三性质 + 边界等价于线性方程 + 凸性与最大似然」三段答，比只背定义完整得多。
- 对 post-training 的视角：softmax + 交叉熵正是 LLM 训练与偏好建模的地基（RM 的 Bradley-Terry 损失本质也是二分类交叉熵），这条经典脉络值得保持熟悉。
