## 一句话总结

同一套 GRPO 配方下 Qwen 稳步涨分、Llama 却长度冲顶复读不涨分，差别不在 RL 而在 base 模型的推理语料存量；用约 220B token 的中段训练（mid-training）补课后，Llama-3.2-3B 走完同样 RL 能与 Qwen2.5-3B 基本持平——RL 能不能 scale，在 RL 开始之前就决定了。

## 核心

1. **问题/背景**：复现 R1-Zero 式训练的人常撞同一堵墙：Llama-3.2-3B 做 RL 时 response 长度几步冲到 4096 上限，开头写个 boxed 答案后无限复读，分数原地甚至倒退（GSM8K 倒退约 2 分），而 Qwen2.5-3B 同配方多基准显著提升。
2. **机制/方法**：在预训练与后训练之间插入 mid-training 阶段：用数百 B 级 token 的高质量专项语料继续训练 base 模型，目标不是学新知识，而是把 base 改造成适合下一阶段的形态。受控实验用同样 20B token 预算换不同语料给 Llama 中段训练再跑同一套 RL：高质量数学网页语料收益显著；另一份语料收益边际且诱发长度失控；只加问答数据里的短思维链没用、长思维链收益大但 RL 不稳，再补 0.8B token 指令数据后短思维链的潜力才被解锁。
3. **关键证据或数字**：最反直觉的现象是中段训练 20B/70B/100B 三个检查点上 base 模型评测分几乎不变，RL 之后的分数却一路上涨——base 评测看不出来的东西，RL 看得见。最终两段配方（stable 段 200B token 恒定学习率，数学网页语料占 72.5%、通用网页 10%、其余代码与问答；decay 段 20B token 余弦衰减，分长思维链/短思维链/混合问答三分支，问答占 30% 是甜点、40% 起递减）之后，Llama-3.2-3B 的 GSM8K 从 30.5 经 stable 段到 56、RL 后到 64.4，MATH500 从 7.4 到 22.4 再到 30.8，与 Qwen2.5-3B 走完同样 RL 的分数基本持平。
4. **结论/判断**：Llama 不是不行，是预训练里推理语料太少；中段训练补上，RL 的引擎就点着了。另有两个稳定 RL 的小技巧：提示模板明确要求思考过程与 boxed 答案；最大长度渐进放开（前 200 步 2048，再 4096，再 8192），别一上来就给满。

## 关键数字

| 指标 | 原始 Llama-3.2-3B | 中段训练后 | 再经 RL 后 |
|---|---|---|---|
| GSM8K | 30.5 | 56 | 64.4 |
| MATH500 | 7.4 | 22.4 | 30.8 |

## 可迁移

- 选 base 模型别只看榜单分：先跑约 200 步 RL 探针，看 response 长度是否平稳上升、pass@k 是否还有余量——长度一失控先停查 base，别急着调 RL 超参。
- 面试被问 mid-training：答「预训练和后训练之间、为 RL 做准备的中段训练」，要点是它的收益在 base 评测上不可见、只在 RL 后兑现，所以评估它必须用 RL 探针而不是静态基准。

## 疑问 / 下一步

- 220B token 的中段训练对 3B 模型性价比成立，但对已经过充分推理语料预训练的新一代 base（如 Qwen3 系）边际收益还剩多少，视频未展开，值得留意消融。
