2一句话总结

OPD 里老师给的 token 级信号有三到五成是反的、且学生根本不靠它学习；真正起作用的是压低学生自己最没把握的低概率 token，于是 OPSA 干脆去掉老师，只对学生最低的 20% 概率 token 施加与熵正相关的负优势，AIME24 反而比标准 OPD 高约 17 分。

3核心

  1. 问题/背景：在线蒸馏（OPD）让学生自己采样、老师逐 token 用对数概率差打分（正/负优势），好处是数据在学生自己的分布上。但默认前提是「老师越大、分越准」。
  2. 机制/方法：作者先量化老师噪声——用有标准答案的题检查老师打分方向，正确答案 token 拿到负优势、错误答案拿到正优势都算噪声。结果噪声率随老师变大而升高；再把训练轨迹按含噪/干净分组，三组最终成绩几乎一样，说明学生并不依赖老师信号的质量。看优势分布发现：近三成 token 优势恰为零、另有约一成优势小到几乎无梯度，且这些都集中在学生本来就有把握的高概率 token 上；只训高概率 token 时，无论用真优势还是随机优势都不涨分。结论是 OPD 的有效信号本质在低概率 token。OPSA 的规则只有三步：学生自采样 → 每条回答按 log 概率排序取最低 20% 的 token → 赋负优势，幅度与该位置的熵正相关（熵越高、压得越重，幅度范围约 $-0.5$ 到 $-1$ ）；不需要老师、不需要标准答案、核心代码不到十行。
  3. 关键证据或数字：噪声率：4B 老师 30.6%、30B 老师 34.7%、235B 老师 50.6%。Qwen3-1.7B 在 AIME24 上 avg@32 从 13.4 涨到 48.9（+35.4，相对 +263%），pass@32 从 40% 到 80%，比标准 OPD 高 16.8 分；4B 从 23.3 到 62.1；9B 从 76.4 到 87.8。每步耗时因省掉老师前向从 61.2 秒降到 46.3 秒。
  4. 结论/判断：蒸馏的增益很可能主要来自「自我锐化」而非老师知识；屏蔽反思分叉位置后增益消失，说明学的正是这些分叉点。适用边界：只在 9B 以内验证，已经锐化得很厉害的后训练模型收益可能有限。

5可迁移

  • 做 on-policy distillation 前先花小成本量一遍老师的 token 级噪声率和优势分布，再决定要不要为大老师付前向成本；信号在学生低概率 token 上这件事，对设计蒸馏/拒绝采样类目标都适用。
  • 面试谈 OPD 时能说清：OPD 的优势 = 老师与学生的对数概率差；其增益可能来自锐化低概率分叉点而非知识迁移——这是比「老师教学生」更深一层的答法。
