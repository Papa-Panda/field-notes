## 一句话总结

Quiet-STaR 把 STaR「答题前先想一段」从题目级下放到 token 级：模型在每个 token 之前都并行生成一小段不输出的内部思考，用「这段思考有没有让下一个真实 token 预测更准」作强化学习信号，在普通网页文本上自学出通用的推理习惯。

## 核心

1. **问题/背景**：前身 STaR 是让模型对有标准答案的题先写推理再作答，答对就留下推理微调自己，越练越会推理；天花板在于必须有标准答案判对错，海量无答案文本学不动。而人读书写字时，每个词背后其实都藏着推理——凭什么只在做题时才想？
2. **机制/方法**：三个设计——① token 级默想：每个 token 冒出之前先生成一小段内部思考，被特殊标记框成「草稿纸」，只在内部盘算、绝不输出（quiet 的由来）；所有位置并行各想一段，一次算完，不必逐个排队。② 门控混合：同一位置同时算「想过」与「没想」两套预测，用一个可学习的小门控按比例混合，模型还不会想时思考少掺、学会后多听思考，从不会到会平滑过渡不翻车。③ 强化学习信号：一段思考若让紧接着的真实 token 预测更准就奖励强化，没帮忙甚至帮倒忙就压制；连比同位置其他想法还差的也一律淘汰。
3. **关键证据或数字**：整个训练只读普通网页文本、从未针对题目刷题，零样本考下来：小学数学应用题（GSM8K 类）与常识推理的正确率明显上升，视频称数学一项从个位数翻到两位数。学到的不是某道题的解法，而是通用的「开口前先想一想」的习惯。
4. **结论/判断**：Quiet-STaR 证明了推理能力可以从无标注文本中靠自监督式 RL 信号长出来，把 STaR 的自举从「题目级 + 需答案」推广到「token 级 + 无需答案」，是从测试时思考回溯到训练时内化思考的一条代表路线。

## 关键数字

| 维度 | STaR → Quiet-STaR |
|---|---|
| 思考粒度 | 整道题想一次 → 每个 token 前想一小段 |
| 监督需求 | 需要标准答案判对错 → 只用普通文本的下一 token 预测增益 |
| 思考是否输出 | 写出推理链 → 内部默想、不输出 |
| 零样本效果 | — → 数学、常识推理明显提升（视频称数学由个位数到两位数） |

## 可迁移

- 概念迁移：把「思考」当作可训练的隐变量、用下游预测增益做奖励，是理解后来一系列 test-time compute 与内化推理（implicit CoT）工作的起点，面试讲 STaR 家族演进时是关键一环。
- Infra 视角：每个位置并行生成短思考、再用门控混合，本质是训练时用额外算力换推理习惯，与推理期拉长 CoT 是同一笔「算力换准确率」账的两种付法。

## 疑问 / 下一步

- 默想长度与门控的学法对算力开销影响很大：原论文中思考 token 的长度上限、淘汰机制细节，以及这套方法在更大模型上是否仍有增益，值得查原文核对。
