## 一句话总结

垂域模型的默认流程「领域数据留给微调」其实是最贵的用法：把领域数据按百分之几混进预训练、重复几十遍，微调后领域表现更好、通用遗忘更少，还能用更小的模型打平大模型——是否划算取决于部署期的推理总量。

## 核心

1. **问题/背景**：传统路径是预训练只看通用网页，领域适应全靠微调。但微调只能在已有表示上打补丁，领域与网页差异越大补丁越难打，还会挤掉通用能力（灾难性遗忘）。
2. **机制/方法**：SPT 从预训练第一天起就把小领域集按比例混入（实验为 3 亿 token 的化学、音乐、数学证明领域集，按 1%–5% 混入 2000 亿 token 预训练，相当于重复 10–50 遍），之后照常微调。领域知识直接长进表示里，微调阶段不需要大改参数，于是遗忘也更少。
3. **关键证据或数字**：SPT 后再微调，领域测试 loss 相对下降 0.8%–2% ；达到同等领域表现最多省 1.75 倍预训练 token；在与网页差异最大的领域上，1B 的 SPT 模型超过未混数据的 3B 模型；下游数学最多涨 6 分、音乐理论基准涨 4 分。重复是否过拟合取决于领域集大小：3 亿 token 的集重复几十遍持续受益，但 300 万–3000 万 token 的小集会过拟合，混合比到 10% 或训练超 700 亿 token 也会重复过头；领域本身在网页中占比已超 5% 时收益趋平。
4. **结论/判断**：成本账要把推理算进去——微调派需要更大的模型追平领域表现，推理单价高约 3 倍，两条成本线在约 1 万亿推理 token 处交叉，之后 SPT 路线更便宜；推理量小则老老实实微调。前提是你得有能改预训练数据配比的基础设施，拿开源模型的人只能退而求其次做专用继续预训练。

## 关键数字

| 项 | 数值 |
|---|---|
| 领域 loss 相对下降 | 0.8%–2% |
| 同等表现的预训练 token 节省 | 最高 1.75 倍 |
| 混合比例配方 | 短训练 5%–10%，中训练 2%–5%，长训练 1%–2% |
| 成本交叉点 | 约 $10^{12}$ 推理 token |

## 可迁移

- 面试/方案题「垂域模型怎么训」多一个选项：不只有 CPT 和 SFT，配比前置到预训练阶段的 SPT 在高推理量场景下是更优解。
- 数据工程要点：先估领域语料与预训练语料的分布距离（可用微调后 loss 差近似），距离越大 SPT 越值；小领域集改为后期引入而非全程混入。

## 疑问 / 下一步

- 实验只覆盖 3 个领域、最大 3B 模型，且假设微调阶段有足够验证数据做早停；到 30B+ 规模、代码/法律等领域是否同规律，尚无实证。
