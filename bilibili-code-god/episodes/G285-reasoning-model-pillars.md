## 一句话总结

推理型大模型的通用配方是四根支柱环环相扣：推理时计算负责「多想」，过程监督（PRM）负责「逐步打分」，搜索负责「在推理树里探路剪枝」，自我进化负责「把搜出的好推理筛出来再训练」，转一圈强一圈。

## 核心

1. **问题/背景**：过去让模型变强靠堆参数、堆数据、堆预训练算力，越走越贵、边际收益越小。新思路是参数不变、让模型在回答时想得更深——视频开场称同一模型仅靠多想，数学成绩能从 50 多分涨到 90 分。四根支柱就是围绕「想得更深」长出的完整系统。
2. **机制/方法**：① 推理时计算——两条路：想得更久（拉长思维链）与想得更多（并行采样多遍、择优或多数投票），思考量与准确率形成新的增长曲线；② 过程监督 PRM——老办法只看最终答案对错，信号又细又晚且不知错在哪一步，PRM 给每一步打分，能揪出跑偏环节、信号密集；③ 搜索——把解题看成一棵树，模型在岔路里探路、走不通就回退，由 PRM 分数决定剪掉哪些分支、算力集中到最有希望的路；④ 自我进化——搜索产出的高质量推理别浪费，筛出答对的反过来训练模型，变强后回到搜索再转一圈，即 STaR 一脉的自举。
3. **关键证据或数字**：完整闭环是：预训练基座 → 推理时计算 + 搜索 + PRM 评估生成大量高质量推理 → 筛选后做偏好训练/SFT 得到更强模型 → 回到第二步循环。视频以 o1 类模型为典型例证，未给出逐项 benchmark 表格。
4. **结论/判断**：四根支柱缺一不可且互相供血——没有 PRM，搜索没有指南针；没有搜索，推理时计算只是线性延长；没有自我进化，每次推理的昂贵搜索成果无法沉淀回权重。这是理解 o1、R1 及各类 reasoning 工作的总框架图。

## 关键数字

| 支柱 | 作用 | 信号/产物 |
|---|---|---|
| 推理时计算 | 拉长或并行扩增思考 | 更长 CoT / 多路采样 |
| 过程监督 PRM | 每一步打分 | 密集的步级奖励信号 |
| 搜索 | 树上探路、剪枝、回退 | 最优推理路径 |
| 自我进化 | 好推理回训模型 | 更强的下一代基座 |

## 可迁移

- 这是 post-training 面试的框架级答案：「推理模型怎么训」可直接按四支柱展开，并落到自己熟悉的环节（如 PRM 对应 reward 建模、自我进化对应拒绝采样/RFT 与迭代式 RL）。
- 做 agentic RL infra 时同构映射：rollout 生成 = 推理时计算 + 搜索，verifier/PRM = 过程监督，筛选回训 = 自我进化，系统瓶颈（rollout 吞吐、打分延迟）也在这张图上。
