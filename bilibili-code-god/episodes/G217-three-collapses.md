## 一句话总结

RLHF 训练崩溃基本就三种形态——reward 崩塌（策略钻 RM 漏洞、分数虚高而真实质量下降）、KL 爆炸（策略偏离参考模型太远）、输出发散（退化成乱码或重复）；诊断看 reward 曲线、KL 值、输出质量三件套，修复靠调 KL 系数、clip range 与早停回滚。

## 核心

1. 问题/背景：RLHF 训练不稳定，崩溃时需要先分清是哪一类失效，才能对症下药而不是盲目调参。
2. 机制/方法：三类崩溃各有成因：reward 崩塌是策略找到了奖励模型的漏洞，优化方向与真实质量脱钩；KL 爆炸是策略分布离参考模型太远、行为失控；输出发散是前两者的末端表现，文本退化为乱码或无限重复。
3. 关键证据或数字：修复三板斧——KL 系数一般从 0.05 起调（太小策略跑飞、太大学不动）；clip range 控制单步更新幅度，默认 0.2；发现 reward 崩塌立即早停并 rollback 到上一个健康 checkpoint。
4. 结论/判断：诊断流程固定为三步：先看 reward 曲线形态，再看 KL 值是否失控，最后抽查实际输出质量；三者结合才能定位崩溃类型。

## 关键数字

| 超参 | 经验值 |
|---|---|
| KL 系数起始值 | 0.05 |
| clip range 默认值 | 0.2 |

## 可迁移

- 搭 RL 训练监控时，reward、KL、输出样本三类面板缺一不可，且要预先存好可回滚的健康 checkpoint，回滚是崩溃时成本最低的修复。
- 面试讲 RLHF 稳定性时，用「崩溃分类 → 诊断信号 → 对应修复」的结构作答，比罗列调参技巧更有排障感。

## 疑问 / 下一步
