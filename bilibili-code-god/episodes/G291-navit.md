## 一句话总结

NaViT 不再把图片强行缩放成固定方块，而是按原始长宽比切 patch、再把多张图的 patch 序列打包进同一个训练样本，用注意力掩码隔离跨图信息，省算力还能按需调分辨率。

## 核心

1. 问题/背景：标准 ViT 要求固定输入分辨率（如 224×224），原图无论横竖高矮都被硬塞进方框：长宽比被拉歪、高清图细节被压没、小图被放大白占算力。
2. 机制/方法：两招组合。第一，按原生分辨率切 patch——宽图 patch 多而扁、竖图呈长条排布，每张图该有多少 patch 就是多少，长宽比和细节原样保留。第二，Patch n' Pack 借 NLP 的序列打包思路：把多张不同尺寸图片的 patch 序列首尾相接塞进同一条定长序列；再用块对角注意力掩码保证每个 patch 只能看到同图 patch，跨图一律屏蔽，拼而不串。
3. 关键证据或数字：训练上只用约 1/4 的算力就追平顶配固定分辨率模型的效果；同一预算可喂数倍图片。打包还让算力按图分配成为可能：复杂图多给 patch、简单图少给甚至随机丢一部分。
4. 结论/判断：推理期同一模型可按需滑动分辨率——想快少给 patch、想准多给 patch，在算力与质量之间平滑取舍，这是固定分辨率范式做不到的。

## 可迁移

- 「变长输入打包 + 掩码隔离」是跨模态通用招式：和文本侧的 sequence packing 同源，做多模态数据管线时应把 packing 率当作吞吐指标盯。
- 面试答法：先讲固定分辨率的三个代价（变形、丢细节、算力错配），再讲原生切分 + 打包 + 掩码三件套，链条完整。
