## 一句话总结

注意力有平方复杂度、KV cache 膨胀、串行解码三个硬伤，但凭训练并行性、工程生态与全局聚合三道护城河短期内不会被取代，混合架构是过渡期的主流答案。

## 核心

1. **问题/背景**：挑战者攻击的三个致命伤是：注意力计算量随序列长度平方增长；长上下文下 KV cache 持续膨胀吃显存；自回归解码只能逐 token 串行生成，无法并行。
2. **机制/方法**：三派路线——取代派（Mamba/SSM）用线性递归状态方程把复杂度降到线性、推理时间为常数，但训练并行性和全局信息聚合弱于注意力；改良派保留注意力框架、只换 softmax 内核（稀疏注意力的 Longformer/BigBird、线性注意力的 Performer、低秩近似的 Linformer），代价是要重新训练；共存派走混合架构，多数层用线性层处理长序列、隔几层插一层完整注意力做全局聚合，FFN 换 MoE 稀疏激活。
3. **关键证据或数字**：视频给出的 2026 年格局估计是纯 Transformer 约占七成、混合架构约两成五且在长文本场景快速崛起、纯 SSM 约 5% 仍停留在小众研究。
4. **结论/判断**：新架构要在工程与生态上补课，靠单个 benchmark 翻不了盘；Transformer 不是终点，但混合架构才是当前最现实的演进路径。

## 可迁移

- 面试被问「Transformer 会被什么取代」时，按致命伤 → 三派路线 → 护城河 → 格局占比的框架答，比只喊 Mamba 名字完整得多。
- 做长上下文 RL rollout 的 infra 选型时，混合架构（线性层打底 + 稀疏注意力层）是显存与全局聚合之间的现实折中。
