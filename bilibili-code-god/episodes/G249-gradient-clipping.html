2一句话总结

梯度裁剪是大模型训练必开的稳定器：静态全局范数裁剪阈值固定、偏粗暴；AdaGC 按梯度统计动态调阈值，尖峰频率可降约 30%，训练更稳。

3核心

1. 问题/背景

训练中梯度尖峰会一步打坏参数。裁剪是标准防线，但固定阈值一刀切：设大了挡不住尖峰，设小了正常梯度也被削。

2. 机制/方法

两条路线：一是静态全局范数裁剪，对全体梯度的总范数设固定阈值，超了就等比缩放；二是 AdaGC 自适应裁剪，根据梯度统计量动态调整阈值，不用人手调。另外还有 per-tensor（逐张量）与 global（全局）两种裁剪范围的选择，视频建议从 global 起步。

3. 关键证据或数字

静态阈值一般取 $1.0$ ，需按模型规模调整，模型越大阈值可越小（如 $0.5$ ）；AdaGC 动态阈值使尖峰频率下降约 30%。

4. 结论/判断

先用静态全局裁剪 $1.0$ 保底；尖峰仍频繁时，换自适应阈值比反复手调固定值更划算。

4关键数字

项 静态全局范数裁剪 AdaGC 自适应裁剪
阈值 固定，常取 $1.0$（大模型可 $0.5$ ） 按梯度统计动态调整
调参 需按规模手调 基本免手调
尖峰频率 基线 约降低 30%

5可迁移

  • 训练排障清单里把「裁剪阈值是否与模型规模匹配」列为 loss 尖峰的第一批排查项，先于怀疑数据和学习率。
  • 面试讲稳定性工具箱时，裁剪可以和 warmup、梯度范数监控并列成一条线讲。
