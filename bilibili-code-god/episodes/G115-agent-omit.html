2一句话总结

8B
Agent

把「这一轮不思考、这条历史观察直接删掉」定义成策略可学的省略动作，先合成数据冷启动再用省略感知 RL 微调，8B 模型在五个 Agent 基准上追平前沿模型，同时上下文更短、效率-效果曲线占优。

3核心

  1. 问题/背景：多轮 Agent 每轮的上下文 = 此前所有轮的思考链 + 工具返回，长度随轮数线性甚至更快增长：prefill 越来越贵、撞上限后截断、且早期工具日志（如第 3 轮的搜索结果）会变成噪声把第 12 轮的决策带偏。
  2. 机制/方法：两种省略动作——思考省略（本轮直接出动作、不写思考）和观察省略（把某条历史观察从后续上下文中删除）。省略不是推理时的固定截断规则，而是策略的一部分：先用覆盖单轮/多轮省略场景的合成数据 SFT 冷启动教会模型使用这两个动作，再用省略感知 RL：同一任务采一条有省略的轨迹和一条无省略的对照，双采样比较；奖励同时看任务成功与省略量，并用 KL 约束保证学省略不把任务能力学没。
  3. 关键证据或数字：8B 模型在 5 个 Agent 基准上与 7 个前沿 LLM Agent 表现相当；效率-效果权衡曲线优于 7 种高效方法（同样的准确率上下文更短，或同样的上下文准确率更高）。视频未给具体分数与省略比例。
  4. 结论/判断：省略该不该发生因轮次而异（有的轮只是简单确认、有的观察用完即弃），只有让模型自己在训练中学，才能把「删什么」变成能力的一部分；只奖励省略量会学成什么都不看，奖励必须与任务成功平衡。

4可迁移

  • 多轮 Agent 的上下文管理可以从「推理时启发式截断」升级为「训练时可学动作」：动作空间里显式加跳过思考/丢弃观察，并用带 KL 约束的对照采样 RL 教它。
  • 注意与训练侧的 observation-token loss mask 区分：那是算 loss 时不计观察 token，这里是推理时真的把观察从上下文里删掉，省的是 prefill 与注意力噪声。
