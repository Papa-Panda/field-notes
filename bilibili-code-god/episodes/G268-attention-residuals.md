## 一句话总结
把残差连接重新理解为「深度方向的线性注意力」，再用带可学习 query 的 softmax 注意力替换写死的等权加号，深层网络的幅度膨胀与信号稀释一并缓解，推理只贵约 2%。

## 核心
1. **问题/背景**：残差流是前面所有层输出的等权总和——每层权重恒为 1、不看内容、无归一化。浅层无碍，但网络变深后两个毛病暴露：残差幅度随层数越堆越大、数值不稳；早期层在总和中的占比被摊薄到接近零，「越深越不稳，也越记不住」。
2. **机制/方法**：AttnRes 给每层配一个可学习 query，前层输出经 RMSNorm 作 key，点积 + softmax 得到权重 ， $\alpha$ ，再加权聚合。query 零初始化，训练初期所有权重相等、恰好退化回标准残差，不破坏预训练权重，再慢慢学出差异化。
3. **关键证据或数字**：直接做深度注意力需存每层表示，显存 ， $L \times d$ ，太贵；Block AttnRes 把网络分成约 8 个块，块内仍普通残差相加，只在块边界存表示做块间注意力，显存降到 ， $N \times d$ 。实验模型 48B 总参 / 3.1B 激活、4T token 训练，下游基准全面打平或优于标准残差。
4. **结论/判断**：序列方向早已用 softmax 注意力，深度方向却停在 11 年前的等权加法；给深度方向补上「会选择的注意力」，代价极小、收益稳定。
