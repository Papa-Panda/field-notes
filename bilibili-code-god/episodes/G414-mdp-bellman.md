## 一句话总结

强化学习的全部地基就是 MDP 五要素加贝尔曼方程：价值不是盯着眼前奖励，而是折扣回报的期望，且它能递归自洽地拆成「即时奖励 + 折扣后的未来价值」。

## 核心

1. **问题/背景**：智能体在环境里「看状态 → 选动作 → 得奖励 → 到新状态」循环往复；若每步只盯即时奖励就会短视，不肯吃一时之亏换长远收益。核心问题是：如何让只会走一步的智能体学会深谋远虑。
2. **机制/方法**：
- 舞台是马尔可夫决策过程（MDP），五要素为状态、动作、奖励、状态转移、策略。
- 衡量好坏不用单步奖励，而用回报（未来奖励之和）；每往后一步乘一个小于 1 的折扣系数 $\gamma$ ，既让近处奖励更重要，也让无穷求和收敛。
- 回报要等整局结束才知道且随机性大，于是取期望得到价值函数：状态价值是从某状态按当前策略走下去的期望回报，动作价值是先钦定第一步动作再按策略走的期望回报。
- 贝尔曼方程把价值递归拆开：当前价值 = 即时奖励 + 折扣后的下一状态价值，一层套一层、自洽成立。
- 把「按策略平均」换成「永远挑最优动作」（求和变取 max），得到最优贝尔曼方程；反复套用它刷新每个状态的价值，价值会像水波一样从终点奖励向前倒灌收敛，这就是价值迭代。
3. **关键证据或数字**：视频以走格子机器人为例直观演示：越靠近大奖的格子价值越高；价值迭代只需几轮迭代即可从终点向前收敛，无需真正解方程。
4. **结论/判断**：Q 学习、策略梯度等后续全部算法都从这块地基长出来——先有 MDP 的问题定义，再有贝尔曼方程的递归结构，最后才有各种求解算法。

## 可迁移

- 面试/理论：被问 RL 基础时按「MDP 五要素 → 折扣回报 → 价值期望 → 贝尔曼递归 → max 版与价值迭代」的链条答，比孤立背公式完整得多。
- Post-training 视角：LLM 的 RLHF/GRPO 本质是把 token 序列建模成 MDP（状态 = 已生成前缀，动作 = 下一个 token），贝尔曼式的「即时信号 + 未来价值」拆分正是 critic/优势估计的思想源头。
