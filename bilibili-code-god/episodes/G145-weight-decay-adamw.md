## 一句话总结
Weight decay 本质是 L2 正则，AdamW 的关键改动是把衰减从梯度里摘出来直接作用于权重，大模型经验区间 0.01–0.1。

## 核心
1. **问题/背景**：权重过大易过拟合，需要在损失里加权重平方和惩罚项约束权重幅度；但把 L2 混进 Adam 的梯度后，衰减效果会被二阶矩自适应缩放，实际强度失真。
2. **机制/方法**：AdamW 将 weight decay 解耦——不经过自适应学习率，直接按系数对权重做衰减，语义清晰、效果大幅优于原始 Adam 的 L2，因此成为大模型训练标配。
3. **关键证据或数字**：经验值 0.01–0.1，0.01 最常用；与学习率有交互——学习率大时衰减效果被放大、应适当减小系数。分阶段取值：预训练 0.1（数据量大、需强正则），SFT 0.01（数据量小、不能太强），DPO 0.01–0.001，RLHF 基本不关键（KL 约束已提供正则）。
4. **结论/判断**：从 0.01 起步，过拟合加大到 0.1、欠拟合减小到 0.001；调 decay 必须同步考虑学习率，并监控权重范数——范数持续增大说明衰减不够。

## 可迁移
- 面试讲 AdamW 时抓住「解耦」一词：L2-in-gradient 与 decoupled decay 在自适应优化器下不等价，这是必考点。
- 训练排障清单：权重范数曲线应与 loss、grad norm 一起看，范数单调膨胀是正则不足的早期信号。
