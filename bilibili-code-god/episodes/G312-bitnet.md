## 一句话总结

从零训练一个权重只取 -1/0/+1 的模型：每权重约 1.58 bit、矩阵乘法退化成加减法，3B 规模起即可追平同尺寸全精度模型。

## 核心

1. **问题/背景**：常规模型权重是 16 位浮点，几十亿参数光存储就几个 GB；而矩阵乘里的浮点乘法是芯片上最慢、最耗电的运算。想省电，突破口在权重表示本身。
2. **机制/方法**：三值量化的信息量是 $\log_2 3 \approx 1.58$ bit（名字由来）；权重为 +1 时激活原样通过、为 0 时丢弃、为 -1 时取负——乘法器不再需要，全退化为加减。关键不是训后暴力压缩，而是从一开始就带三值约束训练：取整不可导，用直通估计（STE）让梯度在反向时假装该步平滑、直接穿过。相比早期 1-bit（只有 ±1），多出的 0 让连接可以「关断」，天然带稀疏、更好训。
3. **关键证据或数字**：3B 参数以上，困惑度与下游任务可追平同尺寸全精度模型；推理速度快 2 倍多、显存省 3 倍多，矩阵乘部分能耗在 7nm 工艺下约降至 1/70。
4. **结论/判断**：低比特的上限不只由量化误差决定，还由「是否原生训练」决定；极端低比特可能反过来催生专用加法型芯片。

## 可迁移

- 成本/能耗估算：做推理 infra 的量级账时，权重比特数同时决定显存、带宽和 matmul 能耗，是第一阶变量。
- 面试：讲清 STE 为什么能训三值网络、以及「0」带来的稀疏价值，是低比特话题最容易被追问的两点。
