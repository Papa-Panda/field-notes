2一句话总结

4B
平均

样本是不均匀的——全对、全错、半对半错、自信地错，一个算法覆盖不了；Self-Routing 用 rollout 准确率与 token 级熵置信度两个信号，把每条样本按概率分到 GRPO、自蒸馏、KL 正则、跳过四条路，Qwen3-4B 平均 73.7，胜过纯 GRPO 的 66.8 与纯自蒸馏的 70.4。

3核心

  1. 问题/背景：后训练两条主流路各有盲区：GRPO 靠组内对错差异算优势，全对或全错的组都没有梯度；在线自蒸馏（OPSD）让模型在提示里看到标准答案生成回答、当老师逐 token 蒸馏给不看答案的自己，全错的题也能学。但全对且稳定的题再训只会漂移，自信全错的题说明模型根本不懂、硬学容易学歪。
  2. 机制/方法：用两个信号交叉分类。信号一是 rollout 准确率（0–1），用三个高斯核映射成低/不确定/高三个软隶属度，中心分别在 0、0.5、1， $\sigma$ 固定为 0.18 / 0.16 / 0.18、不按数据集调；信号二是置信度，由 token 级预测熵算出、batch 内归一化，用来区分「不会但知道自己不会」与「不会却很自信」。四条路的路由分数：GRPO 分 = 不确定 + 高准确且置信不变 + 低准确但不自信（主要吃有对有错的题）；自蒸馏分 = 低准确 × 不自信（真不会但没瞎自信的题）；正则分 = 高准确 × 置信上升（稳定全对，只做 KL 正则防漂移）；跳过分 = 低准确 × 自信（自信全错，这轮不更新）。分数归一化成概率后，每条样本每轮采样一条路。
  3. 关键证据或数字：在 Qwen3 0.6B / 1.7B / 4B 与 Qwen3.5-0.8B / 2B / 4B 上，训练集 DAPO-Math-17K，评测 4 个域内 + 2 个域外：Qwen3-4B 上 Self-Routing 73.7，基座 61.0，纯 GRPO 66.8，纯自蒸馏 70.4；Qwen3.5-4B 上 86.6，对 GRPO 76.8、自蒸馏 79.8、的 83.0（字幕中该对照名转写不清，应为固定比例混合类基线）；同时打赢固定比例混合与只看准确率的路由。路由分布随训练漂移：前期自蒸馏占一半以上，中期 GRPO 达峰，后期正则主导，跳过始终很少。
  4. 结论/判断：配方应该跟着样本走；路由分布曲线本身就是收敛诊断——自蒸馏占比降、正则占比升，说明模型在收敛。实操要点：自蒸馏的老师不需要外部模型（同一基座 + 标准答案离线生成一次、训练中复用）；$\sigma$ 固定别调；用概率采样而非硬分配，避免震荡。

5可迁移

  • RL 训练里「全对/全错组零梯度」不只是采样效率问题，还可以升级成样本级路由问题：给不同状态的样本配不同目标（学、防漂移、跳过），比统一算法更省算力。
  • 面试谈后训练数据/样本调度时，Self-Routing 的「准确率 × 置信度」二维分型是一个很好的框架，且路由分布可当训练健康度面板——与可观测性思路相通。
