2一句话总结

SFT 与 RL 优化的是同一件事——让模型分布 $Q$ 靠近人类分布 $P$ ——区别只在 KL 的方向：SFT 是正向 KL（撒网覆盖），RL 是反向 KL（择优收缩）。

3核心

  1. 问题/背景：SFT 像「抄答案」、RL 像「打分试错」，表面天差地别；换成概率语言后，两者都是在调模型分布 $Q$ 去逼近人类真实分布 $P$ ，远近用 KL 散度量。而 KL 不对称， $D_{KL}(P\|Q)$ 与 $D_{KL}(Q\|P)$ 是两种完全不同的训练目标。
  2. 机制/方法：正向 KL 站在 $P$ 的地盘抽样查 $Q$ ——人类会说而 $Q$ 给零概率的地方惩罚无穷大；反向 KL 站在 $Q$ 的地盘抽样查 $P$ —— $Q$ 说出的每句话都必须被 $P$ 认可，说错重罚。SFT 的交叉熵损失减去与模型无关的常数（ $P$ 自身的熵）后，恰好就是正向 KL；PPO 在最大熵强化学习的近似下整理可得，其目标等价于反向 KL。
  3. 关键证据或数字：面对双峰的人类分布，正向 KL 把 $Q$ 拉宽成一张大网，连两峰之间人类根本不会说的区域也分到概率——这是幻觉的一个数学来源；反向 KL 则让 $Q$ 死抱最有把握的那个峰、直接放弃另一个峰，更精准但丢多样性。RLHF 后模型爱说「作为一个 AI，我不能……」式的保守回答，正是反向 KL 的数学天性，业内称对齐税。
  4. 结论/判断：判别口诀是看样本从谁那里来——样本来自人类数据、批算交叉熵，就是正向 KL；样本来自模型自身采样、再拿去打分，就是反向 KL。这也解释了标准流水线为什么先 SFT 后 RL：先撒网学会全部人类语言，再收缩到高质量模式。

4可迁移

  • 面试被问 SFT 与 RL 的本质区别时，用「数据来源决定 KL 方向」一句话答完，再展开模式覆盖（mode-covering）vs 模式寻找（mode-seeking）的行为差异，比背定义有力得多。
  • 理解 OPD/蒸馏为什么选反向 KL：与 RL 同属收缩型目标，学生只学自己会走到的区域，避免被教师分布里的大网摊薄。

5疑问 / 下一步
