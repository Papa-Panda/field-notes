## 一句话总结

合成数据的瓶颈不在生成而在质检：用 Self-Instruct 种子扩展、Evol-Instruct 进化加难、强模型打分造偏好对，再过四步质检，才能把成本优势兑现成可用数据。

## 核心

1. **问题/背景**：真实数据收集成本极高，人工标注一条要数分钟，强模型生成一条只要几秒；对资源有限的团队，合成数据往往是唯一可行的数据来源，但质量失控就会反噬训练。
2. **机制/方法**：三段生成法。Self-Instruct：备一小批种子指令，让强模型生成新指令并作答，再过滤、循环扩展——Alpaca 用 175 条种子撬出约 5.2 万条。Evol-Instruct：沿两个方向进化已有指令，深度方向加约束、增难度，广度方向换领域扩覆盖，WizardLM 用此产出约 25 万条指令。偏好数据：同一 prompt 让强模型生成多个回答并自打分，最高分作 chosen、最低分作 rejected，UltraFeedback 由此得到约 6.4 万条偏好对。
3. **关键证据或数字**：质量控制四步——规则过滤（去重、去过短等）、embedding 相似度去近重复、强模型打分只留高分、人工抽检 5%–10%。
4. **结论/判断**：合成数据不缺量，缺的是质检这一环；四步质检做完，合成数据的质量可以逼近人工标注。

## 关键数字

| 事项 | 基线 | 结果 |
|---|---|---|
| 指令扩展（Alpaca） | 175 条种子 | 约 5.2 万条指令 |
| 指令进化（WizardLM） | 种子指令集 | 约 25 万条指令 |
| 偏好合成（UltraFeedback） | 同 prompt 多采样 | 约 6.4 万条偏好对 |
| 人工抽检比例 | — | 5%–10% |

## 可迁移

- 数据管线设计：生成便宜、验证昂贵时，把预算压在质检环节（规则+相似度+模型打分+抽检的分层过滤），这正是数据 curation 主线的标准打法。
- 造偏好数据时「同 prompt 多采样 + 模型打分排序」是 DPO/RLHF 数据的低成本来源，但打分模型本身的偏差会写进数据，需留人工抽检兜底。
