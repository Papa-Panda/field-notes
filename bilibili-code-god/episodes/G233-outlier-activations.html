2一句话总结

极少数固定维度的激活值比其他维度大 10 万倍，主导了注意力分布、撑起整个模型；把其余 99% 小激活清零模型几乎无损，动这几个大值立刻崩盘，它们也是统一尺度量化精度断崖的根源。

3核心

  1. 问题/背景：从激活热力图看，绝大多数维度数值很小，只有几个格子异常大，且这些大值几乎不随输入变化、稳定出现在固定维度上，形成离群激活。
  2. 机制/方法：这几个尖峰经 softmax 后把注意力吸到特定 token 上，形成 attention sink，等于少数维度撑住了整个注意力分布。反直觉实验：把 99% 的小激活清零，模型性能几乎不掉；把那几个大激活置零，模型直接崩——真正扛事的是极少数维度。
  3. 关键证据或数字：离群值与普通激活相差约 10 万倍。量化时若用统一尺度，尖峰把整条数轴撑爆，小值全被压成零，INT8/FP8 精度断崖下跌，这是大模型量化难的根子。定位方法很简单：统计每个维度激活绝对值的均值排序，top 几个就是离群维度——注意是少数维度，不是少数 token。
  4. 结论/判断：两条解法路线——细粒度量化（per-channel / per-token，每个维度用自己的尺度互不干扰）；或先用旋转变换把离群值摊平再量化（SpinQuant 一类思路）。

4可迁移

  • 做量化/推理优化时，先统计激活分布找离群维度再选量化粒度，能解释大部分「权重 INT8 没事、激活 INT8 就崩」的现象。
  • attention sink 与本系列 StreamingLLM 一篇是同一机制的两面：sink token 不能丢，正是这些离群维度在 token 侧的对应物。

5疑问 / 下一步

  • 离群维度在 RL 训练的训推不一致里是否也扮演角色（如 logprob 尖峰），值得在自己的训练日志里查一下激活统计。
