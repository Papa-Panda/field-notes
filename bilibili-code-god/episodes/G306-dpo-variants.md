## 一句话总结
IPO、KTO、ORPO、SimPO 四个 DPO 变体各盯着 DPO 的一个包袱开刀——过拟合、成对数据、独立 SFT 阶段、参考模型——选型就是看自己缺什么。

## 核心
1. **问题/背景**：DPO 免训奖励模型、直接用成对偏好优化，是当红对齐方法，但背着两个包袱：训练时要挂一个冻结的参考模型当锚；数据必须是好坏成对的。此外它还有把好坏差距无限拉大、过拟合训练数据的倾向。
2. **机制/方法**：四个变体各改一处——IPO 给优化装刹车，把好坏差距的目标设为有上限的固定值，防止无限拉大差距导致过拟合；KTO 免成对，每条回答只需好/坏二元标签，并借前景理论的损失厌恶对坏样本施加更重惩罚；ORPO 把 SFT 与偏好对齐并成一步，在普通微调损失上加一个基于几率比的惩罚项压低差回答，既省掉单独的微调阶段也不要参考模型；SimPO 整个扔掉参考模型省显存，奖励改用长度归一化的平均对数概率（长短句公平比较、不偏爱啰嗦答案），再加一道间隔要求好回答至少高出坏回答一截。
3. **关键证据或数字**：视频给出的对照维度是三项——是否需要参考模型（DPO/IPO/KTO 要，ORPO/SimPO 不要）、是否需要成对数据（只有 KTO 不要）、是否合并微调阶段（只有 ORPO）。
4. **结论/判断**：变体不是互相取代而是一套工具箱：只有二元标签选 KTO，想少训一个阶段选 ORPO，想省显存又想更强选 SimPO，怕过拟合选 IPO。

## 关键数字
| 方法 | 参考模型 | 成对数据 | 合并 SFT | 绝招 |
|---|---|---|---|---|
| DPO | 要 | 要 | 否 | 基线 |
| IPO | 要 | 要 | 否 | 差距设上限，防过拟合 |
| KTO | 要 | 不要（二元标签） | 否 | 损失厌恶，坏样本罚更重 |
| ORPO | 不要 | 要 | 是 | 几率比惩罚，一步到位 |
| SimPO | 不要 | 要 | 否 | 长度归一化奖励 + 间隔 |

## 可迁移
- 面试高频题「DPO 有哪些变体、各改了什么」：按「砍参考模型 / 砍成对数据 / 砍 SFT 阶段 / 给目标加刹车」四条减负路线组织答案，比逐个背定义更稳。
- 自有对齐实验选型：先盘点手里的数据形态（成对还是单条标签）和显存预算，再对号入座，而不是默认上 DPO。
