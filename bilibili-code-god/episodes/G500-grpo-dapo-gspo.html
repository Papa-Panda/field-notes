2一句话总结

三代算法是一条「先砍模型、再打补丁、最后换记账粒度」的链：GRPO 用组内相对优势砍掉价值模型，DAPO 用四个工程补丁修 GRPO 的三个坑，GSPO 把重要性比值从 token 级换成序列级，根治 MoE 训练崩溃。

3核心

  1. 问题/背景：PPO 训练要策略、参考、奖励、价值四个模型同跑，其中价值模型要在答案写完前「半路猜分」，本身难训准还全程占显存，太重。
  2. 机制/方法：
  3. GRPO：同一道题采样一组回答，直接用组内奖励做标准化， $优势 = (奖励 - 组均值) / 组标准差$ ，答对的往上推、答错的往下压，价值模型直接省掉。代价是三个坑——熵坍塌（概率锁死、不再探索）、全对/全错时优势全零导致梯度消失、逐答案内平均再跨答案平均造成长度稀释。
  4. DAPO 四个补丁：Clip-Higher（裁剪上限从 0.2 放宽到 0.28、下限不动，鼓励低概率潜力 token 上涨）、动态采样（全对/全错的组直接丢弃重采）、token 级损失（全批次所有 token 统一平均）、超长回答软惩罚（截断答案不再粗暴打零分，并可屏蔽其损失）。
  5. GSPO：GRPO 的重要性比值是逐 token 算的，奖励却是整段打一次分，粒度不对齐；在 MoE 里一步更新后约一成 token 的专家路由就变了，比值比较的根本不是同一套参数。GSPO 改用整段回答按长度归一化的序列级比值（几何平均），与奖励粒度对齐，连路由重放补丁都不再需要。
  6. 关键证据或数字：DAPO 在 DeepSeek-R1-Zero-Qwen-32B 同款设置下，把 AIME24 成绩从 30 分提到 50 分。
  7. 结论/判断：GRPO 把价值模型的债转成了训练稳定性的债，DAPO 用四个补丁分期还债，GSPO 换了记账粒度、直接不欠。

4关键数字

事项 基线 结果
DAPO 四补丁（AIME24，32B 同款设置） 30 分 50 分
MoE 一步更新后路由改变的 token 占比 — 约 10%
DAPO Clip-Higher 上限 0.2 0.28

5可迁移

  • 面试被问 GRPO 缺点时，按「熵坍塌 / 零梯度组 / 长度稀释」三坑 + DAPO 对应补丁成对作答，比只背公式完整得多。
  • 做 RL infra 时记住粒度原则：重要性比值的粒度必须和奖励粒度对齐，MoE 场景优先考虑序列级比值。
