2一句话总结

大模型抛弃的是神经元级 Dropout，不是整层跳过：Cerebras 用 2400 多次实验证明，层级 Dropout（随机深度）只要把缩放因子写对——训练时保留层输出乘 $1/\rho$ 、评测不缩放——再配「深层多丢、后期少丢」的调度，8.2B 模型能少用 25% 训练算力达到与稠密基线一模一样的验证损失，还附赠推理弹性。

3核心

  1. 问题/背景：经典 Dropout 在一层内随机把部分神经元输出置零，防的是小数据多轮训练的过拟合；大模型单轮训练、海量数据，过拟合基本不发生，激活 Dropout 经验上反而掉点，且这种稀疏省不下墙钟时间。层级 Dropout 不同：以一定概率把整个 Transformer 块跳过、输入沿残差直传，这一层的前向反向算力是真省了——但早期尝试它的人也失败了。
  2. 机制/方法：失败根源是一个被写错的细节：缩放因子。某层以概率 $\rho$ 保留，保留时输出应乘 $1/\rho$ 补偿期望、评测时不缩放；最早的随机深度论文是训练不缩放、评测乘 $\rho$ ，PyTorch/TensorFlow 标准实现是训练乘 $1/\rho$ ，而近期不少复现用了「训练不缩放」的版本，于是退化。Cerebras 采用 $1/(1-p)$ 的密度缩放并遵循 μP 的最大残差流更新准则，效果是学习率、batch size、权重衰减的最优值在不同丢弃率下不用重调，「超参彩票」消失。空间分布三种（全层同率、从第一层 0 线性递增到最后一层 $p_{max}$ 的递增式 ILD、只丢奇数层的交替式 ALD），时间调度三种（常数、线性递增、线性递减），外加整层优于子层、每条序列独立 mask 优于整 batch 共用 mask。
  3. 关键证据或数字：2400 次实验的结论一致：固定算力预算下，从最大率衰减到零的递减时间调度在所有规模上最好，空间上递增式最好，一句话「深层多丢，后期少丢」。3.9B 在算力最优的 20 tokens/parameter 下，稠密验证损失 1.732，$p_{max} = 0.8$ 的层级 Dropout 是 1.745、几乎持平而训练 FLOPs 少 28.2%；8.2B 把 $p_{max}$ 拉到 0.99，验证损失 1.663 对 1.663 一模一样、算力少 25%；503M 在省 5% 算力的配置下损失从 2.1096 降到 1.9514，用更少算力打败稠密基线。趋势与直觉相反：模型越大越耐丢（271M 省 10% 算力时损失涨 1.6%，8.2B 完全持平）。推理红利：早退在一半深度输出，Dropout 训出的模型损失比稠密模型低 2%–4%；跳层推理时交替式模型的损失 2.129，稠密基线一跳就炸到 6.446；自投机解码 3.9B 用浅层当草稿、全模型验证，稠密基线只有 1.02 倍， $p_{max} = 0.4$ 的模型达 1.43 倍、接受率 97%。
  4. 结论/判断：配方卡——空间 ILD、时间递减调度、训练缩放 $1/\rho$ 、每序列整层丢弃； $p_{max}$ 按规模定：1.8B 用 0.6、3.9B 用 0.8、8.2B 用 0.99；想要跳层弹性就用交替式 ALD，牺牲一点基础精度。

5可迁移

  • 这是「旧技术失败先查实现细节」的样本：缩放因子写错就能让一个有效方法看起来无效，排障时优先核对这类一行级约定，再怀疑方法本身。
  • 层级 Dropout 的推理弹性（早退、跳层、自投机解码）对推理 infra 有直接价值：训练阶段一个开关，换部署阶段的动态深度能力。
