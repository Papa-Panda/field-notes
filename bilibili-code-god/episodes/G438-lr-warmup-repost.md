## 一句话总结

Warmup 是在训练开头把学习率从零线性升到目标值再接衰减，用几乎零成本躲开开局最脆弱的阶段：随机初始化的损失面陡峭难行，Adam 的二阶矩估计在样本太少时又极不准。

## 核心

1. **问题/背景**：同样的模型和数据，两次训练一个平稳收敛、一个开局 loss 剧烈震荡直接发散，差别只在最初几百步的学习率处理。
2. **机制/方法**：Warmup 让学习率先从零线性爬坡到目标值、之后再按原计划衰减，曲线呈先升后降的小山。两个理由：一是开局参数随机初始化、站在又陡又乱的损失曲面上，大步容易一步迈过头发散，先小步探路挪到平缓处再加速；二是 Adam 靠历史梯度平方估计每参数步长，开局样本太少、估计忽大忽小，算出的步长不可靠，干脆先把学习率压小，等二阶矩估准了再放开。
3. **关键证据或数字**：不加 warmup 时开局学习率顶格，loss 立刻剧烈抖动、运气差直接飙升拉不回来；加了之后平稳下探。结构依赖上，Post-LN 早期靠近输出的梯度特别大、极易炸，对 warmup 依赖极重；Pre-LN 把归一化前置后早期梯度温和得多，对 warmup 没那么敏感——warmup、小初始化、Pre-LN 做的是同一件事：稳住最脆弱的开局。
4. **结论/判断**：工程上就是几行配置：选 warmup 步数（如前 2000 步线性升温），后面接余弦衰减或平方根反比衰减；框架都有现成调度器，近乎零成本，是训练默认应开的开局稳定器。

## 可迁移

- 训练排障时 loss 开局震荡/发散，先查 warmup 是否开启、步数是否够，再怀疑数据与模型；Post-LN 结构尤其要把 warmup 当必需项。
- 面试答 warmup：一条链讲全——定义（线性升再衰减）、双理由（损失面陡 + Adam 二阶矩未估准）、不加的后果、与 Post-LN/Pre-LN 的关系。
