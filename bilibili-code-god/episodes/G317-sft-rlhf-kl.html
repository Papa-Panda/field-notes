2一句话总结

SFT 等价于最小化正向 KL（模型去覆盖专家分布，mode covering），RLHF 等价于最小化反向 KL（模型去贴近奖励诱导分布，mode seeking）——一个撒大网、一个挑高峰，是同一枚硬币的两面。

3核心

  1. 问题/背景：流程上人人都背得出「先 SFT 再 RLHF」，但两者在数学上是什么关系？视频从概率分布视角把两个目标函数改写成 KL 散度，一层关系就透了，理解后 DPO、KTO、SimPO 这一大家子对齐方法都有了抓手。
  2. 机制/方法：SFT 对专家数据的每一对 （问题， 回答） 最大化模型给出该回答的对数概率，即最大似然估计；数学上等价于最小化以专家分布在前、模型分布在后的 KL ，即正向 KL ——专家在哪里有概率质量，模型就必须在哪里分配质量。RLHF 的目标是最大化奖励减去与参考模型的 KL 正则项；等价改写后是最小化以模型在前、奖励诱导分布在后的 KL ，即反向 KL ，其中奖励诱导分布正比于参考模型概率乘以奖励的指数项——直觉是让模型主动贴近高分区域，同时被参考模型拽住不许跑远。
  3. 关键证据或数字：几何特性完全相反。正向 KL 是 mode covering：专家分布有多个峰（好回答有很多种写法），模型被迫把每个峰都罩住，分布又宽又扁——覆盖全、不偏科，代价是每个模式学得不够尖锐，这就是 SFT 容易学到「平均水准」的数学根源。反向 KL 是 mode seeking：模型若在低分区域分配概率会被重罚，于是收敛到一个最尖的高分峰、丢掉其他模式——单个模式学到极致，代价是模式坍缩、多样性下降，这解释了 RLHF 后回答风格单一、过度自信。
  4. 结论/判断：工程含义随之清晰：SFT 是 RLHF 的起点（提供参考分布与合理出发点），RLHF 是 SFT 的精细收敛（在起点附近挑出最高分模式）；DPO 等方法更进一步，跳过显式奖励模型与 PPO，但概率视角没变，还是在拉分布。

4可迁移

  • 面试答「SFT 与 RLHF 的区别」时，用正向 KL 撒大网 vs 反向 KL 挑高峰这一组对偶，比背流程高一个层次；还能顺势解释 SFT 学平均、RLHF 丢多样性两个常见现象。
  • 做对齐调参时的直觉校准：想要覆盖与多样性就别把反向 KL 那侧压得太狠（ $\beta$ 、KL 正则强度直接决定 mode seeking 的尖锐程度），想要极致单点质量则反之。

5疑问 / 下一步

  • 视频把 RLHF 目标严格等价于反向 KL 最小化，实际 PPO 训练里还有采样分布、截断与近似带来的偏差，这层等价在工程实现中打几折，值得结合 DPO 的推导再对照一遍。
