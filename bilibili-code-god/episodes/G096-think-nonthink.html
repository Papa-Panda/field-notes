2一句话总结

Qwen3 在四阶段后训练的第三阶段做「思考模式融合」：非思考样本保留空 think 块、用消息末尾的 /think 与 /no_think 标记切换模式，思考预算则是推理侧截断涌现出来的；而 2507 又把两种模式拆回两个模型，说明共存有质量代价。

3核心

  1. 问题/背景：能不能让一个模型既能像推理模型一样长思考、又能像普通对话模型一样秒回，还能按需设思考预算？Qwen3 的答案藏在它四阶段后训练的第三阶段。
  2. 机制/方法：四阶段依次是——长思维链冷启动 SFT（数学、代码、逻辑、STEM 数据教思考格式）；推理 RL（规则奖励、大规模 RL 推理能力）；思考模式融合（把非思考能力融进思考模型）；通用 RL（二十多个通用任务修行为、强指令遵循与 Agent 能力）。融合阶段的数据有两类：思考数据用第二阶段的 RL 模型对第一阶段查询做拒绝采样生成、带完整 think 块；非思考数据覆盖代码、数学、指令遵循、多语言、创意写作、问答、角色扮演等，用自动生成的 checklist 评估质量。关键格式设计：非思考回复也保留一个空的 think 块，保证两种模式格式一致；模板在用户消息末尾加 /think 或 /no_think 标记切换，不加标记默认思考。
  3. 关键证据或数字：思考预算不是训出来的，是涌现的——推理时监控思考长度，达到用户设定阈值就插入一条停止思考的指令，强制模型基于已有推理 token 收尾作答；因为融合阶段见过完整思考与空思考两种极端，中间任意长度截断它都能接上。效果上，32B 融合后思考跟随指标（Thinking Follower）为 88.7 ，第四阶段通用 RL 后升到 98.9 ，Arena-Hard 再涨 4.4 分。
  4. 结论/判断：随后 Qwen3-2507 把 thinking 与 instruct 拆成两个模型，Instruct-2507 只有非思考模式，其 AIME25 从 24.7 跳到 70.3 、Arena-Hard v2 从 52 涨到 79.2 ；模型卡没解释拆分原因，但数字说明两种模式共存有代价。实操四条：做混合模式时非思考样本一定要保留空 think 块；模式标记放在用户消息里并想清楚默认模式；思考预算靠推理时插入停止指令实现、不用改训练；先想清楚要不要混合——融合是产品选择，拆分是质量选择。

5可迁移

  • 后训练配方设计：模式融合的关键不在数据量而在格式契约——空 think 块让两种模式共享同一输出骨架，切换标记放在用户消息末尾，训推必须逐 token 对齐。
  • 面试要点：思考预算（thinking budget）可以纯靠推理侧实现：在生成中监控长度、达阈值注入停止指令截断，前提是训练时模型见过「被截断后收尾」的分布。

6疑问 / 下一步

  • 融合模型在中间长度截断时的质量衰减曲线如何，官方没有给出；若自己的产品要设思考预算，值得在目标任务上实测不同截断点的准确率。
