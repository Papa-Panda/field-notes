## 一句话总结

SimPO 砍掉 DPO 的参考模型，直接用策略模型自身的平均对数概率当隐式奖励，再加一个目标间隔——显存近乎减半、训练更快，且消除了 DPO 的长度偏好。

## 核心

1. **问题/背景**：DPO 训练时要常驻一个冻结的参考模型（SFT 模型的副本）来算隐式奖励，显存里永远躺着两份权重，还要为参考模型多跑一遍前向；同时 DPO 用对数概率求和打分，长回答天然占便宜，训久了模型越来越啰嗦。
2. **机制/方法**：SimPO 三处改动——（1）扔掉参考模型，奖励直接取策略模型对回答的对数概率；（2）除以回答长度，用平均每 token 对数概率打分，长短回答同一起跑线；（3）加目标间隔 $\gamma$ ，要求好回答的奖励必须显著高过坏回答，而非只高一点点。
3. **关键证据或数字**：去掉参考模型后只剩一份策略权重，显存占用近乎减半，同卡可容纳更大模型或更长序列；实现上删掉整块参考模型加载逻辑，配置只剩奖励缩放 $\beta$ 与间隔 $\gamma$ 两个旋钮。
4. **结论/判断**：更简单、更省、更快，效果常常还优于 DPO——尤其在偏好数据质量过硬时；代价是没有参考模型锚点，稳定性更依赖 $\beta$ 与 $\gamma$ 的调参。

## 关键数字

| 项 | DPO | SimPO |
|---|---|---|
| 常驻模型 | 策略 + 参考，两份权重 | 仅策略，一份权重 |
| 隐式奖励 | 相对参考模型的对数概率比（求和） | 策略模型平均对数概率 |
| 长度偏好 | 有（求和偏爱长回答） | 无（长度归一化） |
| 关键超参 | $\beta$ 等 | $\beta$ （缩放）+ $\gamma$ （目标间隔） |

## 可迁移

- 显存吃紧做偏好对齐时，reference-free 路线（SimPO 一类）是首选答法：省一份权重和一遍前向，迭代速度直接受益；但要主动说明失去 KL 锚点后的漂移风险与应对（调 $\beta$ 、控学习率、盯生成长度）。
- 面试讲 DPO 缺点时可成套输出：参考模型开销、求和式奖励的长度偏置、隐式奖励与生成指标不对齐——SimPO 的三刀正好逐一对应。
