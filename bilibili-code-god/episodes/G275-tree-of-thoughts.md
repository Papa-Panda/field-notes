## 一句话总结
思维树把线性思维链扩展成一棵可搜索的推理树——每步生成多个候选想法、用模型自评打分剪枝、再用 BFS/DFS 探索并允许回溯，在 24 点游戏上把同一模型的正确率从 4% 拉到 74%。

## 核心
1. 问题/背景：思维链（CoT）是一条直线，一步错、步步错，既不会停下来检查，也不会尝试其他路径，对需要试错的任务天然脆弱。
2. 机制/方法：四环节——① 思想分解：把大题拆成若干推理小步，一步一个节点；② 生成：每步不只写一个答案，而是一次生成多个候选想法形成分支；③ 评估：让模型给每个候选当裁判打分，明显死路直接剪掉；④ 搜索：用广度优先逐层保留最优几个，或深度优先先扎到底，走进死胡同就回溯到上一个岔路口换分支。CoT 只是这棵树中的一条链。
3. 关键证据或数字：24 点游戏（四数加减乘除凑 24）需要不断试错回头，普通 CoT 正确率仅 4%，ToT 达 74%，相差近 20 倍；走迷宫、解谜等探索型任务上同样大幅领先。
4. 结论/判断：ToT 的增益来自"回溯"这一 CoT 结构上做不到的能力；代价是每步多候选生成 + 自评 + 搜索带来的数倍推理开销，适合难题而非日常问答。

## 可迁移
- Agent / 推理系统设计：ToT 是 test-time compute 中"搜索 + 验证"一招的经典形态（参见 G277），做 agentic RL 的轨迹生成时，树搜索 + 过程打分可作为高质量 rollout 的采样策略。
- 面试要点：能说清四环节（分解、生成、评估、搜索）与回溯机制，即可完整复述 ToT。
