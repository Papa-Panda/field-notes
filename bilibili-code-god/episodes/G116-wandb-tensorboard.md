## 一句话总结

训练监控的最小完备集是六大指标（训练 loss、验证 loss、梯度范数、学习率、吞吐量、显存），工具上个人用 TensorBoard、团队用 WandB，两者可同时开；关键动作是开训第一件事就初始化日志并把全量 config 入库、给实验名带上关键超参。

## 核心

1. **问题/背景**：大模型训练动辄几天几周，只盯 loss 等于盲开长跑：梯度爆炸、过拟合、IO 瓶颈、OOM 风险都可能很久之后才从 loss 上显形。监控体系是仪表盘，要在问题出现的第一时间报警。
2. **机制/方法**：六大必记指标各有判读法——训练 loss 看整体下降趋势、突升报警；验证 loss 与训练 loss 对照，训练降验证升即过拟合；梯度范数在稳定区间波动正常、突升是梯度爆炸；学习率实际值确认 warmup 与 decay 按预期执行；吞吐量（tokens/s）突降提示 IO 瓶颈；显存接近上限预警 OOM。WandB 用法五步：安装、init（project + run 名）、训练循环里 log、界面看实时曲线、设 alert 阈值通知。
3. **关键证据或数字**：告警阈值的经验法：梯度范数超过均值 3 倍标准差就报警。
4. **结论/判断**：选型按协作形态分：TensorBoard 本地轻量、无需网络，个人够用；WandB 云端、支持团队协作、多实验自动对比与告警。两者可并行（TensorBoard 看实时、WandB 做记录）；且不必全程盯盘，前几百步密切看、稳定后每隔几小时扫一眼趋势即可。

## 可迁移

- 开训 checklist：init 日志 + config 全量入库 + 实验命名带关键超参 + 六大指标全记录 + 告警阈值 + 定期保存生成样本做人工质检 + 实验结束用自动对比找最优配置——这套顺序可直接搬进自己的 RL/SFT 训练脚本模板。
