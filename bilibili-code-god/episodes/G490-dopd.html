2一句话总结

给老师喂参考答案做蒸馏会产生「特权错觉」——学生拟合的是自己永远拿不到的信息捷径；DOPD 用特权学生前向消掉信息鸿沟、只按真实能力差距分四象限因材施教。

3核心

  1. 问题/背景：为造更强的老师，常给老师独享特权信息（参考答案、标准推理提示、结构化标注）。但老师的答题优势里混着两样东西：真正的思考能力差距（学生能学），与信息鸿沟（老师有答案册、学生没有，学生再模仿也永远拿不到）。普通蒸馏不加区分地全让学生学，学生于是练成「假装看过答案册」的姿势——这就是特权错觉。
  2. 机制/方法：DOPD 的核心一步是让学生也看一眼答案册：对每个 token，除了普通学生，再让一个拿到同样特权信息的「特权学生」做一次前向；条件对等后，老师与特权学生的 log 概率之差（特权优势差距 A）便消掉了信息鸿沟这一干扰项，只剩真实能力差距。再把 A 与学生自身把握（该 token 概率高低）交叉成四象限，分别施策：差距小把握大，权重 0.6 用反向 KL 轻点；差距小把握小，属噪声，权重 0.3 自蒸馏并停梯度；差距大且老师笃定，是关键能力，全力 JS 散度硬转移；差距大但学生更笃定，自蒸馏软保留这份探索。
  3. 关键证据或数字：特权错觉的典型伤痕是训练曲线先升后降、同时策略熵一路坍塌（学生把精力耗在不可复现的捷径上，越学越死板）。修复效果：8 个基准平均分普通 OPD 为 43.9 ，DOPD 达 51.4 ，净涨 7.5 分，填平师生差距近九成；AIME 数学竞赛上学生 23.3 反超教师 20.2 ；学生越小收益越大——0.6B 学生普通蒸馏只提 3.5 分，DOPD 提 14.1 分。消融显示删掉高差距关键词，两成性能直接腰斩，反证成败取决于一小撮最该硬学的 token。
  4. 结论/判断：蒸馏前先问一句：老师的本事里有多少是学生根本拿不到的信息。DOPD 的代价是每步多一次带特权的前向（算力高于普通蒸馏），且四象限切分用的是启发式阈值而非原理最优解。
