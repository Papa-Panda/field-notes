## 一句话总结
DiT 把扩散模型的去噪骨干从 U-Net 卷积网络整体换成标准 Transformer：图像切块成 token 序列、条件靠零初始化的自适应归一化注入，换来的核心收益是干净的 scaling 性质。

## 核心
1. 问题：扩散模型的骨干是一个逐步去噪的网络，长期清一色用 U 形的 U-Net（逐层下采样再上采样、全靠卷积）；但卷积骨干堆到大规模容易撞瓶颈，且去噪网络本身并不必然需要 U 形结构。
2. 机制：三步。先 patchify——把二维特征图切成规整小方块、每块拉直成向量并标位置，整图变成 token 序列，图像被「翻译」成 Transformer 读得懂的语言；再过一摞标准 Transformer 模块逐层加工（每块都能看全局），末端接线性层为每个块预测应擦除的噪声（并预测方差），拼回原位即完成一步去噪；条件注入靠 adaLN——时间步与类别条件先过一个小网络，算出缩放与偏移量去调制每层的归一化参数，相当于给每层实时拧旋钮。
3. 关键证据或数字：视频强调的关键设计是旋钮零初始化——调制参数初始全为零，训练从恒等映射稳稳起步再慢慢学发力，这是训练稳定的秘诀；定性结论是换骨干后「模型越大、算力越足、生成质量越稳步提升，几乎看不到尽头」。
4. 结论：DiT 的变革不在某个技巧，而在把 Transformer 的可扩展性搬进扩散模型——这正是它成为 Sora 一类视频/图像大模型共同骨干的原因。

## 可迁移
- 「切块成 token + 标准骨干 + 条件调制」是跨模态通用配方：理解 DiT 就理解了 ViT 式处理一切网格数据的思路。
- 零初始化调制（adaLN-Zero）是可迁移的稳定训练小技巧：任何「新加一条条件通路」的场景，先让它初始不起作用再学，能显著降低训练翻车率。
