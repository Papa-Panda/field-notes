## 一句话总结
语音大模型的前提是把连续声波离散化成 token：VQ-VAE 用码本把编码向量换成最近码字的编号，RVQ 再用多层小码本逐级量化残差，用组合拼出高保真。

## 核心
1. 问题/背景：大模型的范式是「预测下一个 token」，文字天生离散，但音频是连续模拟信号，没有天然的切分点，必须先人为离散化。
2. 机制/方法：VQ-VAE 三步——编码器把一小段音频压成连续向量；在预置码本里找距离最近的码字，用其编号代替向量（量化）；解码器凭编号取回码字向量重建波形。这样音频就变成和文字同构的整数 token 序列。
3. 关键证据或数字：单层量化有结构性两难——码本小则量化误差大、还原发闷失真；码本做到几百万个又训练困难、存储计算爆炸。RVQ 的解法是分层接力：第一层粗量化后，把残差（原向量与码字之差）交给第二层小码本再量化，逐层削减误差，各层码字相加即近似原向量；层数叠够后重建波形几乎与原声重合，而每层只需一个小码本。
4. 结论/判断：RVQ 用「多个小码本的组合」换掉了「一个大码本」，同时拿到保真和效率，是现代语音大模型离散表示的地基。

## 可迁移
- 面试被问「语音怎么进 LLM 框架」时，答题主线是：连续信号 → 编码 → 最近邻量化 → 离散编号序列，之后与文本 token 完全同构。
- 「粗量化 + 残差逐级逼近」的思想和数值计算里的迭代 refinement、乘积量化（PQ）相通，聊向量检索/压缩时可互相印证。
