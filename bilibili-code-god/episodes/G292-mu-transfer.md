## 一句话总结

普通参数化下最优超参会随模型宽度漂移；μP 按宽度精确缩放初始化与各层学习率，把不同规模模型的 loss 谷底钉在同一位置，于是小模型调好的超参可零样本搬到大模型。

## 核心

1. 问题/背景：大模型试一次学习率就要上千张卡跑数天，调参几乎是巨头专属奢侈品；自然的想法是「小模型先调、大模型照搬」，但常规参数化下模型一变宽，最优学习率就挪窝，搬过去不灵。
2. 机制/方法：μP 从参数化规则下手：宽度变大时，按精确的数学规则同步缩放参数初始化幅度与各层学习率，使每层的更新强度不随规模漂移。这样画 loss–学习率曲线时，大小模型的谷底几乎对齐在同一位置——最优点被钉住，迁移才成立。
3. 关键证据或数字：硬核验证：只用 4000 万参数小模型调参，搬到 67 亿参数模型后成绩超过业界公开的同规模数字，调参花费仅占预训练总算力的 7% ；另一例用 1300 万参数代理模型调好了 3.5 亿参数模型。
4. 结论/判断：标准流程变成三步：按 μP 搭好目标大模型 → 捏一个又窄又小的代理模型尽情试超参 → 最优值零样本照搬、直接开训。调参成本被压成零头。

## 可迁移

- 自己跑 post-training 实验时同样适用：先在小模型上把学习率、warmup、权重衰减扫干净，再放大规模，别在大 run 上试错。
- 面试答法：关键不是「小模型调参」这个流程，而是先解释为什么普通参数化搬不动（最优点随宽度漂移），再讲 μP 的缩放规则如何对齐谷底。
