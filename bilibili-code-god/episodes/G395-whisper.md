## 一句话总结
Whisper 用 68 万小时弱标注网络音频以规模换鲁棒性，再靠 encoder-decoder 结构和特殊指令 token，把转录、翻译、语种识别、时间戳等一整条语音流水线统一进单个模型。

## 核心
1. 问题/背景：自动语音识别几十年来难在真实环境噪声杂、口音多，而传统训练靠人工逐句标注，又慢又贵、数据量上不去。
2. 机制/方法：数据侧直接抓取网络音频及其配套字幕作弱标注，用规模换质量；音频先按 30 秒切段并转成对数梅尔频谱图（时间 × 频率 × 能量的二维图），送入编码器压成浓缩特征，解码器再自回归地逐字生成文本；任务切换不靠换模型，而靠在序列开头放入不同的特殊指令 token（转录、翻译、语种、时间戳等），同一模型据此决定这次干什么。
3. 关键证据或数字：训练量达 68 万小时弱监督音频；过去需要「语音活动检测 → 语种判断 → 识别 → 翻译」多模型串联的流水线，被压缩成一个模型加几个 token 的切换。
4. 结论/判断：Whisper 的强项不在结构创新，而在「弱监督大数据 + 多任务统一接口」这套配方，见过足够多样的声音后对口音和噪声自然不慌。

## 可迁移
- 「特殊 token 当任务开关」是通用的多任务统一手法，与文本侧用指令/控制 token 区分任务同构，设计多任务模型时可直接借鉴。
- 弱监督规模化的思路对 post-training 数据同样成立：当精标成本过高时，先用海量弱标注打底换取分布覆盖与鲁棒性，再用精标数据收尾。
