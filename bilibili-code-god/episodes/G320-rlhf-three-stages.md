## 一句话总结

RLHF 不是端到端一次训成的，而是 SFT 学对话格式、RM 学打分、PPO 在打分下做强化学习的三棒接力，SFT 模型同时充当后两棒的初始化与参照。

## 核心

1. **问题/背景**：人类偏好信号噪声大，直接对 base model 做端到端强化学习极不稳定，模型容易钻评分器的漏洞、输出看似高分实则垃圾的文本。InstructGPT 的解法是把对齐拆成三个任务单一、可独立评估的阶段。
2. **机制/方法**：
   - **SFT**：数据是 prompt + 人工写的理想回答，目标就是对理想回答做最大似然，让模型先学会基本对话格式；但它只知道模仿，不知道哪个回答更受欢迎。
   - **RM**：数据换成偏好对——同一 prompt 下采样多个回答、标注员只做排序。用 Bradley-Terry 模型训练，损失是负 log-sigmoid 分数差；结构上从 SFT 模型初始化，把词表投影头换成标量头，输出一个代表人类偏好的分数。相对排序比写标准答案便宜且标注更稳定。
   - **PPO**：数据只剩 prompt，无人工标注。actor 生成回答，冻结的 RM 打分作为 reward，再用 PPO 更新；同时维护一个冻结的 reference（同样从 SFT 初始化），目标里加 KL 惩罚防止 actor 偏离太远去骗分。
3. **关键证据或数字**：耦合关系是理解全篇的钥匙——SFT 模型在流水线里出现三次：RM 的初始化、PPO actor 的初始化、PPO reference 的初始化，可谓一个起点、三个用途；RM 在 PPO 阶段必须冻结，只打分不更新，否则 actor 会通过改变裁判本身来作弊。
4. **结论/判断**：分阶段的价值是工程可解释性：SFT 看模仿像不像、RM 看排序准不准、PPO 看 reward 涨不涨，出问题定位快。DPO 后来把 RM 与 PPO 合成一个损失、省掉显式 RM，但偏好对齐的思想没变。

## 可迁移

- 面试讲 RLHF 时按「三种数据、三个目标、一个起点」组织答案，比背流程图更能体现理解深度。
- RL infra 视角：PPO 阶段同时驻留 actor / reference / RM 三个模型，显存与调度设计要从这张耦合图出发。
