## 一句话总结

重要性采样用新旧策略概率比复用旧数据，但序列的真实偏差是各 token 权重的乘积，逐 token 矫正会系统性低估偏差并放大方差，这正是 GSPO 把重要性采样抬到序列级的动机。

## 核心

1. **问题/背景**：目标分布难以直接采样时，可从易采样的行为分布取数据，再乘重要性权重（目标概率 ÷ 行为概率）矫正偏差。RL 里新策略是目标、生成数据的旧策略是行为，PPO/GRPO 靠概率比把旧数据换算成等效的在线样本，省去每步重新采样的成本。
2. **机制/方法**：以生成「猫喜欢鱼」为例，新策略给三个 token 的概率为 0.8、0.7、0.9，旧策略为 0.5、0.2、0.3；序列权重 = 整句联合概率之比 = 16.8，而逐 token 权重只有 1.6、3.5、3.0。
3. **关键证据或数字**：每个 token 权重都远小于 16.8——序列偏差是各 token 权重共同相乘的结果，逐 token 矫正必然不到位；同时逐 token 计算把每个位置的波动原样带进梯度，模型会过度纠结权重偏大的单个 token，忽略整句合理性，方差被放大、训练难收敛。
4. **结论/判断**：重要性采样的粒度应与优化对象对齐：要优化整条序列，就在序列级算权重并裁剪（GSPO 路线），而不是在 token 级逐个矫正。

## 关键数字

| 量 | 值 |
| --- | --- |
| 序列级重要性权重（整句概率比） | 16.8 |
| 逐 token 权重 | 1.6 / 3.5 / 3.0 |

## 可迁移

- 面试讲 PPO/GRPO 的 clip 时可顺带指出：clip 的对象是 token 级 ratio，这正是 GSPO 质疑并改为序列级 ratio 的切入点。
- RL infra 排障：若训练 loss 抖动大、个别 token 梯度异常，先查重要性权重的粒度与方差，而不是先怀疑学习率。

## 疑问 / 下一步

- 序列级权重解决了低估问题，但长序列上方差会随乘积放大，GSPO 的裁剪阈值如何与序列长度配合，值得对照原论文再看。
