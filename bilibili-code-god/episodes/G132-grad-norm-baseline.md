## 一句话总结

梯度范数没有绝对正常值，看的是趋势：先用前 1000 步建立自家基线，预警线设在均值加三倍标准差，超过 100 才通常意味着真不稳定。

## 核心

1. 问题/背景：梯度范数是所有参数梯度向量的长度，反映单步更新幅度，是仅次于 loss 的第二重要监控指标；像车速一样太快危险、太慢没效率。训练初期冲到 20 并不异常，因为参数还接近随机。
2. 机制/方法：判断标准是相对自家基线的偏离，而非绝对值。三种预警阈值设法：统计法（前 1000 步均值 + 3 倍标准差）、倍数法（当前步超过前 100 步均值的 10 倍立即报警）、趋势法（连续多步递增，即使绝对值不大也可能是发散前兆）。
3. 关键证据或数字：经验参考区间——大模型预训练的梯度范数通常在 ， $0.1$ – $10$ ，之间波动，初期可冲到 20 后回落；超过 100 通常意味着不稳定；低于 0.001 可能是梯度消失。梯度裁剪阈值默认 1.0 够用，若频繁触发裁剪，说明学习率可能太大。embedding 层梯度通常比其他层大，可单独放宽或用 gradient shrink 处理。
4. 结论/判断：warmup 段（约前 1% 步数）本来就抖，只记录不设硬报警；进入稳定期再上线报警。真触发报警时，先降学习率，再排查脏数据和标签问题。

## 关键数字

| 情形 | 参考值 | 判断 |
|---|---|---|
| 稳定期波动 | 0.1–10 | 正常区间（经验值） |
| 训练初期 | 可冲到 ~20 | 正常，随后应回落 |
| 绝对值 | > 100 | 通常意味着训练不稳定 |
| 绝对值 | < 0.001 | 可能梯度消失 |
| 预警线 | 均值 + 3σ（前 1000 步） | 统计法阈值 |
| 裁剪阈值 | 1.0（默认） | 频繁触发先怀疑学习率 |

## 可迁移

- 自己跑训练时第一件事是把 grad norm 曲线打进 WandB/TensorBoard 并建基线，这是排障时区分「正常抖动」和「真要崩」的唯一依据。
- 面试答「loss spike 怎么排查」时可串起本条链路：看 grad norm 是否同步飙升 → 降学习率 → 查脏数据。

## 疑问 / 下一步

- RL 训练中 grad norm 的基线分布与 SFT 差异很大（奖励稀疏、序列更长），阈值是否要分开建，值得实测。
