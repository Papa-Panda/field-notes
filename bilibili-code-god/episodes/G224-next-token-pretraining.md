## 一句话总结

预训练靠"错位标签"把无标注文本变成自监督数据：每个词的下一个词就是标签，模型在万亿 token 上最大化下一词对数似然，知识被压进权重；但训练时喂真值上文、推理时喂自生成上文，由此产生曝光偏差，需 SFT / RLHF 后续矫正。

## 核心

1. **问题/背景**：人工标注成本高到不可能覆盖万亿 token 量级，预训练必须找到一种不需要人写标签的学习信号，否则数据天花板永远掀不开。
2. **机制/方法**：错位（shift）构造标签——输入序列右移一位，每个位置的下一个词自动成为该位置的标准答案，一句话免费变出与词数等量的训练样本。模型对每个位置输出下一词的概率分布，用交叉熵惩罚错误预测，把所有位置的对数似然加起来最大化，反向传播更新参数。这就是自监督学习。
3. **关键证据或数字**：LLaMA 3 用了 15 万亿 token、DeepSeek-V3 用了 14.8 万亿 token 预训练，语料覆盖网页、书籍、代码与论文；正是在这种规模的"猜下一个词"里，语法、常识乃至推理与写代码的能力以涌现形式出现，而非被显式教会。
4. **结论/判断**：预训练留下一个结构性缺陷——曝光偏差：训练时上文永远是真实文本，生成时上文是模型自己的输出，一旦写错一步便可能错上加错；这道训练/推理鸿沟是后面必须有 SFT 与 RLHF 的根本原因之一。

## 可迁移

- 面试被问"下一词预测为什么能学到知识"：要点是标签免费（错位自监督）→ 数据规模无上限 → 压缩即学习，预测目标逼模型把世界规律压进权重。
- 曝光偏差是解释 scheduled sampling、以及 RLHF 用模型自生成数据训练（on-policy）的经典动机，答题时可串成一条线。
