2一句话总结

静态题库会信号衰减——训久了题不是全对就是全错、梯度归零；RLVE 用 400 个程序化生成、算法可验证、难度自适应的环境替代题库，让 1.5B 模型以不到三分之一算力拿到约七倍收益，并提出「环境数量本身是可扩展维度」。

3核心

  1. 问题/背景：RLVR 需要有信号的题（模型有对有错）。静态题库训一段时间后，简单题全对（优势为零、白烧算力）、难题全错（同样零信号），有信号的题越训越少，这就是信号衰减；再加上好题容易与评测重叠泄漏、人工补题出题与验证成本高。
  2. 机制/方法：环境三要素——程序化生成（一个环境是一个生成器，按参数随机造题，如给定位数生成算术题、给定节点数生成图最短路，理论上无限）；算法可验证（答案由程序算出，奖励是精确的 0/1，不用人标、不用裁判）；自适应难度（每个环境跟踪模型当前通过率，把难度分布往能力边界推，总是给出有对有错的题，按模型进展动态调而非固定课程）。RLVE-Gym 共 400 个生成器，覆盖数值、逻辑、算法、代码等——注意是 400 个生成器，不是 400 个数据集。
  3. 关键证据或数字：1.5B 模型在全部 400 个环境上连训，六个推理基准平均 +3.37；用超过三倍算力的静态题库基线只 +0.49——换数据机制，收益差约七倍、算力还更少。扩大环境集合时泛化推理能力持续提升：每个环境对应一类推理技能，环境越多技能越广，没见过的基准也涨。这与 Polaris 的通过率控制是同一个问题的不同答案——都在保证训练信号，只是 RLVE 把它做到了数据源头。
  4. 结论/判断：环境数量是与参数量、数据量、算力并列的可扩展维度。实操四条：能程序化的任务（数值计算、逻辑约束、代码单测）做成生成器 + 校验器；难度参数化（位数、节点数、步数当旋钮）；按通过率调难度、目标落在中间区间；与静态题库混用——环境补信号、题库补真实分布。

5可迁移

  • RL 环境/数据系统：把「题目」升级为「生成器 + 校验器 + 难度旋钮 + 通过率反馈」四件套，是环境侧最可复用的工程抽象，也和 difficulty filtering、pass-rate control 一脉相承。
  • 面试准备：信号衰减的成因（全对/全错都零优势）与三种解法（数据源头生成、训练中过滤、通过率控制）可以串成一个完整回答。
