## 一句话总结

多头注意力把嵌入维度切成 H 份，每头用自己的小 QKV 在子空间里独立做缩放点积注意力并行捕捉不同关系，最后拼回原维度过输出投影；实现的核心全是形状变换。

## 核心

1. **问题/背景**：单头注意力只有一套 QKV，只能学一种关注模式，但一句话里 token 间同时有语法、指代、位置远近等多种关系，指望一个头全学会太难。
2. **机制/方法**：把维度切分：例如 512 维切成 8 个头、每头 64 维，各配一套小 QKV 并行工作、互不干扰。实现上先过 QKV 三个线性层，再用 view 把最后的嵌入维拆成（头数 × 每头维度），用 transpose 把头数维换到序列维之前，使每个头能当作独立的注意力并行计算；每头内部就是自注意力那套：打分、除以根号缩放、掩码、Softmax、乘 V ；算完 transpose 换回、reshape 把头数与每头维度合并回嵌入维，横向拼成完整向量，最后过输出线性层融合，输入输出形状完全一致。
3. **关键证据或数字**：两个易错点：一是缩放因子除的是每头维度 $d_{head}$ 的根号而不是总维度，其中 $d_{head}$ 等于嵌入维除以头数，所以嵌入维必须能被头数整除（初始化时要断言）；二是拼接靠 transpose + reshape 而非直接 view，维度顺序错了结果会静默出错。
4. **结论/判断**：记住「切成多头、各看各的、再拼回来」这一句，加上形状变换的顺序，多头注意力的代码就能完整复现。

## 可迁移

- 手撕代码是面试高频题：按「线性层 → view 拆头 → transpose → 逐头注意力 → transpose + reshape 拼回 → 输出投影」五步写，形状标注清楚最加分。
