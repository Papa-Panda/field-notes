## 一句话总结
Titans 给 Transformer 加了一个神经网络形式的长期记忆模块：它在推理时按"惊讶度"（梯度大小）实时把重要信息写进自身权重，再用遗忘门衰减旧信息，并与负责短期精准注意的注意力分工配合。

## 核心
1. 问题/背景：注意力本质是短期记忆——窗口内两两比对很精准，但算力随长度暴涨、窗口开不大，话题滑出窗口后先前内容等于凭空消失，聊得越久越健忘。
2. 机制/方法：长期记忆不是查找表，而是一个小神经网络，把信息压缩进权重里（联想记忆：给键能还原出值，还原误差越小记得越准）。写入策略按惊讶度：新信息带来的梯度越大、越出乎意料，越值得用一次梯度更新狠狠写进权重；平淡信息梯度小、轻轻带过。再配遗忘门：每步让旧记忆按比例衰减腾地方，衰减率可调，另带一点惯性让一次强惊讶在随后几步持续影响记忆。
3. 关键证据或数字：视频未给出具体 benchmark 数字；定性结论是注意力管眼前、神经记忆管长远，两者边用边学、各司其职。
4. 结论/判断：Titans 最反直觉之处是模型在"考试"（推理）时仍在学习——记忆模块权重随输入实时改写，而非训练结束即冻结。融合有三种方案：记忆当上下文（取出相关记忆拼进输入再过注意力）、记忆当门控（短期与长期两条通路加权融合）、记忆当一层（串在注意力之前）。

## 可迁移
- 与 TTT 层（G274）对照记忆：两者都把记忆做成可训练的网络权重、测试时在线更新；差异在 Titans 是独立的长期记忆模块与注意力并存，TTT 是用内层模型替代序列混合层本身。
- 面试话术：被问"如何让模型拥有长期记忆"时，可按"神经记忆 + 惊讶度写入 + 遗忘门 + 三种融合方式"的链条作答。
