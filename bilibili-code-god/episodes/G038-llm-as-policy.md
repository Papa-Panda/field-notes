## 一句话总结

同一个 LLM 强化学习问题有两种等价的建模粒度：从提问层看是单步老虎机（一个问题、一段回答、Reward Model 打一个分），从生成层看是 token 级 MDP（状态是问题加已写前缀、动作是下一个 token、奖励只落在最后一个 token 上）——GRPO 公式里外层对回答、内层对 token 的两层求和正是后一种看法的直接写照。

## 核心

1. **问题/背景**：系列前面讲的环境都是游戏，大模型 RL 的「环境」是什么，需要先把建模说清，后面的 PPO/GRPO 公式才有落点。
2. **机制/方法**：单步视角把一整段回答当作一个动作，流程是一问一答一打分、一局结束；token 级视角则把每写一个字看作一步，状态随前缀增长，一段回答构成一条轨迹，策略梯度随之变成对每个 token 的对数概率梯度求和。
3. **关键证据或数字**：两种视角的衔接点在奖励的分配方式：Reward Model 看完整句才给分，奖励只出现在最后一个 token；折扣因子取 ，$\gamma = 1$ ，这一个分原样传回每个 token；而 KL 惩罚不同，是逐 token 各扣各的、从每步奖励里减。
4. **结论/判断**：理解 GRPO 目标里「外层几条回答、内层每条几个字」的两层求和结构，前提就是 token 级 MDP 这套建模；下一期再讲分数（奖励）本身从哪来。

## 可迁移

- 面试讲 LLM-RL 建模时，先给双层视角再落公式：为什么 credit assignment 难（奖励只在末端、却要分摊到每个 token）、为什么 KL 是逐 token 的而 reward 是序列级的，这两个高频追问都能从这套建模直接答出。
