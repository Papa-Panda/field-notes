## 一句话总结

判断训练好坏看的不是任何一条曲线，而是 train loss 与 val loss 两条曲线之间的距离与相对趋势：gap 稳定且双降是健康，val 掉头向上是过拟合，双双停在高位是欠拟合。

## 核心

1. **问题/背景**：train loss 衡量模型在训练数据上的表现，val loss 衡量在没见过的数据上的表现。只看 train loss 永远分不清模型是在泛化还是在死记硬背——同时看两条曲线是训练诊断的第一条铁律。
2. **机制/方法**：三种形态。**正常**：两条曲线都在下降、趋势一致、差距稳定，理想 gap 在 10%–30% 以内（如 train 0.5、val 0.65–0.8）。**过拟合**：train 持续下降而 val 停降或回升，gap 越拉越大；严重时 train 降到 0.1 而 val 回升到 1.0 以上，差距十倍。**欠拟合**：两条都高且不再下降、gap 很小，说明容量不够或学习率不对，连训练集都没学好，对策是加容量、调高学习率或查数据质量。
3. **关键证据或数字**：过拟合程度可用比值量化， $r = \text{train loss} / \text{val loss}$ （按视频给的区间口径）：1.0–1.3 正常，1.3–2.0 轻度过拟合可接受，2.0–3.0 中度需干预，3.0 以上严重必须处理；另一个确定性信号是 val loss 连续多个 checkpoint 单调上升。
4. **结论/判断**：过拟合处理手段按成本排序：早停（val 开始上升就停）和加正则化（weight decay、dropout、label smoothing）最快先试；加数据最有效但最慢；此外还有减小模型容量、数据增强、降低学习率。

## 关键数字

| train/val loss 比值区间 | 判断 |
| --- | --- |
| 1.0–1.3 | 正常 |
| 1.3–2.0 | 轻度过拟合，可接受 |
| 2.0–3.0 | 中度过拟合，需干预 |
| > 3.0 | 严重过拟合，必须处理 |

## 可迁移

- SFT/DPO 排障时先画双曲线看 gap 形态再决定动作，避免凭单条 loss 瞎调参。
- 面试被问「怎么判断过拟合」时，给出比值区间 + val 单调上升信号，比只说「验证集变差」具体得多。

## 疑问 / 下一步

- 大模型预训练阶段 val loss 长期单调下降、gap 判读与小模型不同，这套比值区间在预训练尺度是否成立需要另行核对。
