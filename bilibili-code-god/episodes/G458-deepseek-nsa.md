## 一句话总结

NSA 用三条腿模拟人读长文：压缩腿粗读全局、选择腿按块分数精读重点、滑窗腿盯紧邻近上下文，门控加权合并；64K 上下文解码快 11 倍多，且原生可训练、效果反超全注意力。

## 核心

### 1. 问题/背景

标准注意力每生成一个 token 都要与全部历史逐一算相关度，序列翻倍计算翻四倍，长文本必然越读越慢。但真实阅读中绝大多数历史对当前 token 并不重要——稀疏化就是只算真正相关的那一小部分。

### 2. 机制/方法

三条腿互补选材：

- **压缩（粗读全局）**：把历史按固定长度切块，每块经一个小线性变换压成一个代表向量；query 只与这些压缩向量算注意力，快而省，还顺带给每块打出相关度分数；
- **选择（精读重点）**：按压缩腿的分数挑出 top 少数块，取出块内原始未压缩的完整 KV 与 query 精算。无论历史多长，永远只精算被选中的块——序列越长，跳过的越多，省得越夸张；
- **滑动窗口（盯邻近）**：语言有强局部连贯性，单独取当前 token 前邻近一小段算注意力，保证最新最紧的信息不被粗读与抽样漏掉。

三路输出各自过一个小门控（线性变换 + sigmoid 得 0–1 权重），加权相加得最终结果。NSA 是原生可训练、硬件对齐的稀疏结构，从预训练第一步就参与学习（配合 GQA），训练推理表现一致，不像许多稀疏方法只能推理时硬套。

### 3. 关键证据或数字

64K 长文本训练：前向快 9 倍、反向快 6 倍、解码快 11 倍多；LongBench 上平均分反超标准全注意力；大海捞针测试 64K 内任意位置精准命中。

### 4. 结论/判断

NSA 的关键区别于早期稀疏方案有两点：选择依据来自可学习的压缩打分而非固定模式，且整套结构从预训练就在回路里——稀疏不是推理期的补丁，而是模型从一开始就学会的读法。
