## 一句话总结
Warmup 是给优化器适应梯度尺度的缓冲期，按总步数的 1%–2% 用比例设定，不要写死固定步数。

## 核心
1. **问题/背景**：训练初期参数随机、梯度方差大，Adam 的二阶矩估计还没稳定，一上来就用峰值学习率容易震荡甚至发散；warmup 让学习率从 0 线性爬升，避开这段最危险的窗口。
2. **机制/方法**：warmup 步数取总训练步数的 1%–2%（如 10 万步对应 1000–2000 步）。低于 0.1% 优化器没热身好、初期 loss 震荡；高于 5% 则前期学习率太小、白白浪费算力。最常见的错误是写死固定步数（如 2000 步）——总步数一变，占比完全不同，必须用比例。
3. **关键证据或数字**：分阶段经验——预训练 1%–2%（从头训、参数最不稳定），SFT 0.5%–1%（已有预训练参数、更稳定），RL 与 SFT 相近甚至可省。
4. **结论/判断**：监控方法是画出前几千步的学习率与 loss 曲线：warmup 期 loss 缓慢下降、结束后加速下降为正常；warmup 期剧烈震荡说明太短，warmup 后 loss 不降反升说明峰值学习率太大。

## 可迁移
- 写训练配置时把 warmup 写成 ratio 而非 steps，避免改总步数时悄悄失效——这是配置审查的固定检查项。
- 排障时先看前几百步 loss 曲线平不平滑，再谈其他超参，能快速区分 warmup 问题与峰值学习率问题。
