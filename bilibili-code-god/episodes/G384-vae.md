## 一句话总结
普通自编码器把每张图压成潜空间里一个孤立的点、点间全是空洞所以不能生成；VAE 改为把图编码成一个高斯分布、用重参数化让梯度穿过采样、再用 KL 项把潜空间铺满成连续的标准正态，于是任意采样都能解码出合理图像。

## 核心
1. 问题/背景：自编码器用编码器把图压成短向量、解码器还原，训练目标只是重构像不像。这样学出的潜空间是零散的点，点间大片区域解码器从没见过，随机踩点只会吐出乱码，所以它只能压缩、不能生成。
2. 机制/方法：VAE 三处改动——编码器对每张图输出均值和标准差、定义一个高斯分布，解码时从分布里采样；采样不可导，用重参数化把随机性外置：潜变量 = 均值 + 标准差 × 标准正态噪声，噪声走旁路，均值与标准差这条主干保持可导，梯度得以回传；训练目标是证据下界 ELBO，由重构项与 KL 正则项两部分拔河。
3. 关键证据或数字：KL 项逼每个编码分布贴近标准正态（均值 0、方差 1），把所有「云雾」往同一分布上聚拢铺满，潜空间从带空洞的稀疏点集变成连续致密区域；此后从标准正态随便采一个点，几乎必然落在有意义的区域并解码出全新但合理的图像。
4. 结论/判断：生成能力不来自更大的网络，而来自潜空间的结构——分布化编码 + 重参数化 + KL 铺满，三者缺一不可；这也是理解扩散模型潜空间工作的入口。

## 核心公式

$$\mathrm{ELBO} = \mathbb{E}[\log p(x|z)] - D_{\mathrm{KL}}(q(z|x) \| p(z))$$

第一项管重构质量，第二项管潜分布贴近先验，最大化下界就是在两者间找平衡。

## 可迁移
- 「不可导的随机节点」在 RL 里同样常见：重参数化（连续动作）与 score function / 基线（离散动作）是两条对应路线，能对照着理解。
- 潜空间连续性思想可迁移到表示学习：想做插值、检索、聚类，先检查表示空间有没有空洞与塌缩。
