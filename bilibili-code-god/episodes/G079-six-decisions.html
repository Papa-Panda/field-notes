2一句话总结

一份大规模受控实验给出的六个 SFT 决定：验证 loss 只在同家族同数据内可比且比真实效果早约 6 轮过拟合、早停要看任务指标；LoRA 学习率从 0.6B 到 235B 恒为 $1 \times 10^{-3}$ ，rank 64 / $\alpha$ 32 恢复全参 98% 提升；超过约 2 轮指令跟随退化，该加新数据而不是加 epoch；Muon 更保指令跟随。

3核心

  1. 问题/背景：SFT 调参里最常见的六个决定（何时停、学习率、LoRA rank 与 $\alpha$ 、训几轮、优化器、规模律）长期靠经验帖，这篇 2026 年 9 月的受控实验用两个模型家族（稠密 + MoE）、四个真实数据集把每个决定都量出了带不确定度的结论。
  2. 机制/方法：① 早停——固定模型与数据内，验证 loss 与质量的 Spearman 相关 0.38–0.88，能排序；但跨模型家族不可比（更低 loss 可以对应更差下游），且它过拟合比效果早得多：约 2 轮后验证 loss 回升，裁判打分的任务效果却一直涨到第 8 轮，按 loss 早停会白扔后面 6 轮。② LoRA 学习率——在 Qwen 与 Llama 两家族 0.6B–32B 全区间最优值平坦地等于 $1 \times 10^{-3}$ ，约为全参最优 $3 \times 10^{-5}$ 的 33 倍，且原封不动迁移到 80B、235B 的 MoE 上趋势不变；全局 batch 无单一最优，只是在 loss 与成本间权衡。所以 LoRA 的 lr 不用扫。③ rank 与 $\alpha$ ——默认 rank 64 / $\alpha$ 32 经验证：rank 32 参数减半、loss 只差 0.0009–0.0028，rank 128 增益只有 0.0004–0.0008 近乎白花；在 $1 \times 10^{-3}$ 学习率下 $\alpha = 32$ 每次比较都最好。LoRA 中位数恢复全参 98% 的提升，只训 3%–13% 参数。④ 轮数——超过约 2 轮后三件事同发：验证 loss 过拟合、裁判分数不再涨、指令跟随退化（IFEval 平均掉 0.15，12 个较大数据单元中 10 个从 1 轮到 4 轮持续下降）；同预算下新样本优于重复训练（租赁类数据集 3 倍新样本 loss 降 16%，安全类降 5.9%）。⑤ 优化器——Muon 在约 AdamW 三分之一的学习率下验证 loss 略低、极小值更平（视频称「设计低」1.2–2.8 倍，具体指标以原文为准），域内质量相当但通用指令跟随保持更好（IFEval 高 0.09）。⑥ 规模——loss 随规模是饱和幂律，全参指数 0.40–0.51，高于 LoRA 的 0.31–0.40；MoE 按活跃参数与总参数的几何平均进入曲线，而不是只按活跃参数。
  3. 关键证据或数字：见下方表格。
  4. 结论/判断：想涨分优先加新数据而不是加 epoch；早停看任务指标不看 loss；LoRA 直接 lr $1 \times 10^{-3}$ 、rank 64、$\alpha$ 32 起步；在意指令跟随保持时优先 Muon。

5可迁移

  • 自己的 SFT 实验直接套用：LoRA lr $1 \times 10^{-3}$ 不扫、rank 64 / $\alpha$ 32、2 轮后盯 IFEval 类指标、早停看任务指标——省掉整轮超参搜索的算力。
  • 面试谈 SFT 调参时把数字连同条件一起说（哪个家族、哪个区间验证的），比报经验值有说服力得多。
