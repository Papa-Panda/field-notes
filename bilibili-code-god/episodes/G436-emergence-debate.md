## 一句话总结

所谓「规模过临界点能力突然涌现」的断崖，很大程度上是精确匹配这类非线性严苛指标 + 测试分辨率太粗共同制造的假象；换成平滑的部分分指标，断崖往往化成连续上升的缓坡。

## 核心

1. **问题/背景**：涌现的原始观测是：小模型在某些任务上长期贴零，规模越过某门槛后分数突然拔地而起，且无法从小模型表现外推。斯坦福团队不否认模型在变强，而是追问：你是用哪把尺子量出来的？
2. **机制/方法**：精确匹配要求答案一字不差才得分，差一个字符直接零分、没有中间分。数学上，全对概率等于单字符正确率的连乘：答案长 $L$ 位、单字正确率 $p$ 时，全对率是 $p^L$ 。 $p$ 从 0.7 平滑涨到 0.9、0.98 时， $p^L$ 会在低段被死死压在零附近、到高段猛地窜起——断崖是指数函数算出来的形状，不是模型突然开窍。第二个帮凶是分辨率：测试题太少、尺子太粗，小模型细小的进步被直接抹平成零。
3. **关键证据或数字**：同一份模型输出只错一位（如答 6812 对 6912），精确匹配给 0 分，按字符相似度给 0.9 分；把指标换成按对字符数计分后，同一组模型同一任务的曲线从断崖变成从头到尾平缓连续的上升。
4. **结论/判断**：涌现作为观测是真实的，但「断崖式突现」的戏剧性观感被指标选择显著放大；能力本身随规模连续变强。两派至今未完全说服对方。听到「涌现」先问一句：用的哪把尺子？

## 关键数字

| 量 | 数值/关系 |
|---|---|
| 全对概率 | 单字正确率 $p$ 的 $L$ 次方（视频以 10 位为例） |
| 同一输出两种得分 | 精确匹配 0 分 → 字符相似度 0.9 分 |

## 可迁移

- 做 RL / 评测时对指标形状保持警惕：pass@1 这类 0/1 指标会把连续的能力爬升显示成台阶，汇报与调参决策应同时看平滑指标（如部分分、平均得分）。
- 面试答涌现：先承认观测，再给出 $p^L$ 的连乘解释和分辨率论点，最后落到「指标选择决定曲线形状」。

## 疑问 / 下一步
