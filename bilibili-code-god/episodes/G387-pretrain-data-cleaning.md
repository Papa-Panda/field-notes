## 一句话总结
预训练语料是把整个脏互联网经抽正文、质量过滤、去重、数据配比四步提纯成的「教科书」，数据质量而非结构或算力决定模型能力上限。

## 核心
1. 问题/背景：原始爬取网页里广告、导航、模板、乱码和复制垃圾页占绝大多数，真正可用的正文占比极低；同结构同算力下，数据洗得干净的一方效果占优。
2. 机制/方法：四步流水线逐步提纯——先从网页模板中手术式剥离正文；再用规则过滤（语言、长度、符号占比、常用词比例）加一个「像不像高质量文本」的分类器打分双重把关；然后做近似去重，把转载、镜像和高度相似副本合并成一份；最后按来源（网页、书籍、代码、论文）设权重做数据配比。
3. 关键证据或数字：每过一步体积都明显下降而质量上升；去重的动机是同一段话被模型反复见到数百遍既浪费算力又导致死记硬背式过拟合；配比相当于调音台，直接决定模型的「性格」与强项（如调高代码比例增强写码能力）。
4. 结论/判断：清洗不是打杂，而是决定成败的第一道关；各家的配比配方是秘而不宣的核心资产。

## 可迁移
- Post-training 数据 curation 可直接复用这套骨架：SFT/RL 数据同样需要「规则 + 分类器」双层过滤与近似去重，且配比（能力维度权重）往往比单条数据质量更影响最终能力分布。
- 面试被问数据 pipeline 时，按「抽取 → 过滤 → 去重 → 配比」的顺序答，并强调每步的体积/质量权衡，是结构化的得分点。
