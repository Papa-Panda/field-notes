2一句话总结

YaRN 的配方是「高频外推、低频内插、中间斜坡过渡」再加注意力温度校准：不压坏负责邻近细节的高频维度，只温和拉长低频维度，几乎零微调把上下文扩几十倍，已成各家事实标配。

3核心

1. 问题/背景

RoPE 给每个维度配一根旋转指针标记位置，位置越靠后转角越大；训练窗口内的角度组合模型都见过，一旦文本冲出窗口，位置差变大、指针转到没见过的角度，外推即失灵。

2. 机制/方法

撑大窗口有两条路：外推（步长不变、范围硬扩，后段角度全是没见过的）和内插（范围不动、把新位置挤进老区间，全部落在见过范围内，更稳）。朴素内插 PI 把所有位置等比缩小，代价是相邻位置的角度差被整体压小，转得最快的高频维度受伤最重——而高频恰恰负责区分紧挨着的 token，压糊了相对位置就乱套。

关键洞察是分频处理：

  • NTK-aware：高频管邻近细节须保持清晰 → 接近原样外推；低频管远距离大跨度 → 适合内插温和拉长。做法是调整 RoPE 频率基数而非均匀缩放位置；
  • NTK-by-parts：按每根指针的波长与序列长度之比分三档——高频外推、低频内插、中间用平滑斜坡（ramp）过渡；极低频维度波长长到训练序列都转不满一圈，对它外推反而有害；
  • YaRN：在此之上再补注意力温度——上下文变长后注意力分布易过尖或过平，用温度因子校准回训练时的健康状态。

3. 关键证据或数字

组合拳下来，只需极少量甚至零微调即可把窗口扩几十倍（如 4k → 128k 量级），长文本效果稳定；Qwen2.5、DeepSeek、Qwen3 等各家最终都升级到 YaRN 路线。

4. 结论/判断

长度外推的演进主线是「从一刀切到按频分治」：PI 均匀缩放 → NTK 分频 → by-parts 三档 → YaRN 再修注意力分布。每一步都在回答同一个问题：哪些位置信息可以动、动多少才不伤模型已学到的分辨力。

4关键数字

方法 处理方式 代价
