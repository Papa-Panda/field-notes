2一句话总结

L1 与 L2 的差别不在「强弱」而在「性格」：L2 平滑地把所有权重压小却谁都不删，L1 用恒定的力把不重要的权重直接推到零、真正做特征删除。

3核心

  1. 问题/背景：参数多、数据少时模型过拟合。正则化的朴素思路是在原损失后加一项权重范数惩罚，强度由超参数 $ \lambda $ 控制； $ \lambda $ 太大则欠拟合。惩罚项怎么写，分出了 L1 与 L2 两派（L2 即岭回归，L1 即 Lasso）。
  2. 机制/方法：视频从四个角度拆解差异。公式上，L2 罚权重平方和，L1 罚权重绝对值和。几何上，L2 的约束域是圆（高维是球），与损失等值线的切点一般不在坐标轴上，所以每个权重都被压小但不为零；L1 的约束域是菱形，顶点恰在坐标轴上，等值线扩张时最先撞上顶点，高维下顶点、棱、面都贴着坐标平面，于是大批权重同时归零。梯度上，L2 的回拉力正比于权重本身，越接近零越温柔，只能渐近趋零；L1 的推力恒定为 $ \lambda \cdot \mathrm{sign}(w) $ ，一路把权重推过零点并卡在零附近——一个像弹簧，一个像恒定摩擦力。贝叶斯上，L2 等价于给权重加高斯先验（零附近概率高但不强迫为零），L1 等价于拉普拉斯先验（零处有尖峰，默认权重就该是零，除非数据证据足够强）。
  3. 关键证据或数字：无实测数字，核心是四组对照结论：惩罚形式（平方和 vs 绝对值和）、约束形状（圆 vs 菱形）、梯度行为（正比衰减 vs 恒定推力）、先验（高斯 vs 拉普拉斯）。
  4. 结论/判断：要特征选择用 L1，要一般性的平滑正则用 L2，两者都想要就用 Elastic Net 把两项拼起来。

4可迁移

  • 面试高频题「为什么 L1 稀疏、L2 不稀疏」，只答几何一个角度不够；按几何→梯度→贝叶斯三层递进回答是明显的加分结构。
  • 对 post-training 的视角：权重衰减（weight decay）在大模型训练里就是 L2 家族的工程化身，理解它「压小不删除」的性格，有助于判断它与剪枝、稀疏化（如 MoE/稀疏注意力）是完全不同的工具。
