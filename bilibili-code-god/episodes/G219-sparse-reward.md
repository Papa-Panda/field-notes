## 一句话总结

推理 RL 只在最终答案处给 0/1 奖励，几十步推导中间没有任何信号，模型不知道错在哪一步、梯度传不回去；四种破解分别是人工设计中间奖励的塑形、先易后难的课程学习、给探索发内在奖励的好奇心驱动、以及用 PRM 对每一步打分把稀疏奖励变密集。

## 核心

1. 问题/背景：数学推理动辄几十个 token、几十步推导，奖励只在末尾出现且非对即错；答错时无法区分第一步就错还是最后一步粗心，信号太稀疏导致几乎学不到东西，这是推理 RL 的头号难题。
2. 机制/方法：四条路线——奖励塑形：人工拆中间奖励（如每写对一步给小分、用对公式加分、最终答对给大头），把 0/1 变成密集曲线，风险是设计不当会误导模型、需反复调试；课程学习：先用一步可解的简单题让模型频繁拿到奖励，再逐步加难度；好奇心驱动：给到达新状态/新推理路径的探索行为发内在奖励，与最终对错无关，避免模型反复走同一条错误老路；PRM：专门训练一个过程奖励模型对每一步打分，自动把终局奖励摊成逐步奖励。
3. 关键证据或数字：塑形的示例配比为单步推导 0.1、用对公式 0.2、最终答案 0.5；PRM 是当前最主流方向，OpenAI 与 DeepSeek 都在用。另有一个工程技巧：经验回放——把历史上答对的高质量轨迹存进 buffer 反复混训，因为成功轨迹在稀疏奖励下非常稀缺，不能只用一次就扔。
4. 结论/判断：四种解法可叠加，组合拳是塑形 + 课程 + PRM；核心目标一致——在终局奖励之外制造足够密的中间信号，同时不把模型引向错误的行为模式。

## 关键数字

| 塑形示例 | 奖励 |
|---|---|
| 每写对一步推导 | 0.1 |
| 用对公式 | 0.2 |
| 最终答案正确 | 0.5 |

## 可迁移

- 自建推理 RL 数据与奖励时，先按难度分层做课程、再考虑 PRM；人工塑形最便宜但最容易引入偏差，应放在最后微调而非当主信号。
- 样本效率层面，成功轨迹回放是低成本增益：任何 on-policy 推理 RL 都可以加一个高质量轨迹 buffer 混训。
