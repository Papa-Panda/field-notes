2一句话总结

扩散语言模型把生成从「逐 token 串行」换成「整句并行精化」：前向用掩码逐步涂黑句子，反向从全掩码一步步擦回，步数远小于 token 数，因此快一个量级且天然双向。

3核心

  1. 问题/背景：自回归生成 $N$ 个 token 要做 $N$ 次完整前向，严格串行，延迟等于 $N$ 乘单次前向时间；推理链越长延迟越高，质量与速度零和。
  2. 机制/方法：文本 token 是离散类别，不能像图像像素那样加高斯噪声，于是引入掩码 token 作为吸收态：前向过程按随时间变化的概率把词逐步替换成掩码（句子被逐渐涂黑，掩码一旦涂上不再变），生成时从全掩码出发并行预测、逐轮擦回。因为每一步同时修正很多位置，总步数 $T$ 远小于 $N$ ，延迟约为 $T$ 乘单次前向，且每步能看到双向上下文。
  3. 关键证据或数字：发展线：2021 年 D3PM 搭起离散扩散框架，2023 年首次大规模训练成功，2024 年 SEDD 的 score entropy 损失让困惑度首次追平自回归、MDLM 简化参数化，2025 年 Mercury 成为第一个商业级扩散语言模型；视频称其速度达 1000+ tokens/s、比自回归快约 5–20 倍，2026 年新版给到 128K 上下文。
  4. 结论/判断：扩散路线的核心优势是并行精化 + 双向上下文，代价是生成质量依赖精化步数与掩码调度；它是对自回归解码瓶颈的结构性回应，而不是简单的解码加速技巧。

5可迁移

  • 面试聊推理加速时把方案分层：解码技巧（投机解码等）仍在自回归框架内，扩散是换生成范式——两者解决的问题层级不同。
  • 掩码吸收态的思想与 BERT 式掩码建模、迭代精化相通，可迁移到一切离散序列的并行生成设想。
