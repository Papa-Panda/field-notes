## 一句话总结
o1 点亮了第二条 scaling 轴：参数不变、训练不变，仅在答题时多花算力"想"，准确率就随思考算力成倍投入近乎直线上升，其手法是拉长思维链、采样投票、搜索加验证、自我修正四招。

## 核心
1. 问题/背景：过去变强只有一条路——训练时堆算力（更大模型、更多数据），越走越贵越慢。同一个模型、同一道题，张口就答可能错得离谱，多想一分钟正确率却翻倍，说明推理侧还有一条未被利用的算力轴。
2. 机制/方法：四招——① 拉长思维链：一步步多推几步、不跳步；② 多次采样投票：同题独立答很多遍，多数意见定答案；③ 搜索加验证：铺开多条思路，用过程奖励模型（PRM）给每一步单独打分，低分分支当场剪掉、算力集中到最有希望的路上；④ 自我修正：答完自查，发现不对就返工重来。多想不是漫无目的地想，而是有裁判剪枝的聪明地想。
3. 关键证据或数字：思考算力成倍增加时，准确率几乎笔直上升且趋势稳定；题目越难越吃推理、收益越猛。总算力相同的前提下，小模型在推理时舍得多想，常能追平甚至反超大得多的模型——算力预算可以在训练与推理之间重新分配。
4. 结论/判断：变强有两条轴：训练时算力与测试时算力。但小模型底子不够时、碰上特别难的题，多想也会失灵；工程上要按题目难度动态分配思考预算。

## 可迁移
- RL infra 视角：测试时算力的四招直接对应 rollout 侧的成本结构——长 CoT、多次采样、树搜索都会放大生成开销，训练框架里"难度自适应采样 + PRM 打分"正是把这条轴用进 RL 的方式。
- 面试要点：被问 o1 为什么强，按"第二条 scaling 轴 + 四招 + 小模型多想反超大模型"这条链回答即可。

## 疑问 / 下一步
- 思考预算给多少才划算（准确率-算力曲线的拐点）视频未给量化方法；实践中常用按难度分档或置信度早停，值得结合自身推理服务再算一笔账。
