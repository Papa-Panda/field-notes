## 一句话总结

多臂老虎机是强化学习的最小模型：没有状态转移、只有动作与奖励，全部难点浓缩为一对矛盾——探索与利用的权衡，三种经典解法分别用随机、乐观和贝叶斯采样来化解它。

## 核心

1. **问题/背景**：面前有 $K$ 台老虎机，各自的真实中奖概率未知，总拉杆次数有限（视频举例 1000 次），目标是最大化累积奖励。因为选择不改变环境、没有状态转移，它成了 RL 最干净的入门模型；但拉了几把之后就出现两难：守着当前看起来最好的机器稳收（利用），可能错过其实更优的机器；一直试新机器（探索），又把次数耗在试错上。
2. **机制/方法**：三种经典策略。① ε-greedy：以 $1 - \varepsilon$ 的概率选当前样本均值最高的臂，以 $\varepsilon$ 的概率随机选一臂，用一点随机好奇心保证不放弃未摸透的臂。② UCB：给每臂算「样本均值 + 不确定性加成」，选置信上界最高者；拉得越少加成越大，自动鼓励先试冷门臂，拉多后加成衰减、靠真实均值竞争。③ Thompson 采样：为每臂维护一个后验分布表示对其中奖率的信念，选臂时从各分布各采一个样本、选采样值最大者；分布越宽越容易偶然采出大值，探索从采样随机性里自然涌现。
3. **关键证据或数字**：视频用「后悔值」（regret）作统一度量——上帝视角每把都拉最优臂的总奖励减去实际所得。后悔曲线显示：纯利用或纯探索的后悔近似随步数线性增长，而 UCB 与 Thompson 采样的后悔增速逐渐变缓、曲线趋平，因为估计收敛后几乎每把都选在最优臂上。
4. **结论/判断**：老虎机问题把 RL 的核心张力剥离到最简形式：信息价值与即时收益的交换。三种解法的差别只在如何给「不确定性」定价——固定随机比例、显式乐观加成、或后验采样。

## 可迁移

- Post-training 里 rollout 的采样温度、pass@k 的 $k$ 值、以及数据难度配比，本质都是探索/利用的定价问题；bandit 的 regret 视角可直接迁移去评估某种采样策略「为学到更优策略多付了多少」。
- 面试高频：ε-greedy 的盲目性（对所有臂一视同仁地随机）正是 UCB 按不确定性定向探索、Thompson 按后验概率匹配探索的改进动机，能讲清这条递进链就够答满。
