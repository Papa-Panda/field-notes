2一句话总结

「随机奖励也能涨分」这类反直觉 RL 结论大半是基准污染的产物：Qwen2.5-Math 在 MATH500 等常用基准上能凭半道题逐字背出后文，假奖励只是激活了第 18–20 层的记忆捷径；在真正干净的基准上只有正确奖励能稳定涨分，而结论是否成立由「模型—任务对齐度」决定。

3核心

  1. 问题/背景：此前有结论称给 Qwen 随机奖励数学分照样涨，动摇了「奖励必须准确」的前提。本期用三层证据拆解：先查污染、再在干净基准上重做、最后定位机理。
  2. 机制/方法：污染查法很朴素——把题干截断只给前 40%/60%/80%，让模型续写，看能否逐字补全剩余题面（补全率），以及只凭半道题能否答对。再构造一个模型发布之后随机生成的合成基准 RandomCalculation（0–100 整数、分数的平方立方与加减乘除、1–20 步算式、20 个子集各 1000 题、连续奖励按答案距离扣分），在此重跑正确/随机/反向三种奖励。机理上用 path patching 和门控抑制定位记忆通路。
  3. 关键证据或数字：60% 前缀下 Qwen2.5-Math-7B 对 MATH500 的补全率 54.6%、凭半题答对 53.6%；通用版 Qwen2.5-7B 为 21.2%/30.8%，Llama-3.1-8B 仅 3.8%/2.4%。逐基准看：MATH500 54.6%、AMC 42.2%、AIME2024 20%，而 AIME2025 与 LiveMathBench 为零——常用三基准对 Qwen 已污染、后两个干净。干净基准上三条曲线泾渭分明：正确奖励稳定上升、随机奖励忽上忽下、反向奖励迅速崩溃；随机奖励对 Llama 几乎没用甚至有害。机理上出现「困惑度悖论」：假奖励 RL 后答案 token 困惑度下降、整段文本困惑度反而上升，即模型绕过推理直接取记忆；第 18–20 层是记忆锚点（换回基座权重可恢复约 50% 效果，第 21 层往后是把记忆转成输出的结构适配器），第 18 层 MLP 放大 3 倍准确率 +4.4、压到 0.2 倍 -3.8；加门控抑制后 MATH500 从 100% 掉到 85.16%，AIME2025 的 30% 纹丝不动，且门只在 61.7% 的污染样本上触发、干净样本零触发。
  4. 结论/判断：统一解释是模型—任务对齐度：RL 前 pass@k 高的高对齐组合（如 Qwen 做数学）里，随机奖励 +16.7、单题 RL +24.4、只用负样本 +27.9、TTRL +21.3，全都「有效」；低对齐组合（Llama 做数学、Qwen 做三段论）里随机奖励 -5.7、单题 -2.2、TTRL 约为零，全部失效；但真实奖励在两边都是最好（Qwen MATH500 +30.2、Llama +6.1）。华盛顿大学的受控实验同样表明：RL 只在基座已给目标行为足够概率时才有效。实操四条：在干净基准上评测、跨模型系列验证、训练前跑一次补全测试、监控答案困惑度与提示困惑度的背离。

5可迁移

  • 任何「RL 技巧涨分」的结论先问模型、基准、污染三件事：自己做 RLVR 评测时优先用发布后生成或可程序化合成的干净题，并把补全率测试纳入训练前检查清单。
  • 面试被问「随机奖励为什么能涨分」时，按污染→记忆捷径→对齐度三层回答，并强调这不否定奖励设计：干净数据上只有正确奖励稳定有效。
