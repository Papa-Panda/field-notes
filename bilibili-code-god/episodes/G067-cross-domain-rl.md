## 一句话总结

多域混训 RL 的起点是均匀混合：Guru 六域实验表明，预训练里见得多的域（数学、代码、科学）能白拿跨域迁移收益，见得少的域（逻辑、模拟、表格）必须 in-domain 专训才涨；混训时先做域内奖励归一化，再监控各域曲线决定加权或专训。

## 核心

1. 问题/背景：真正上线的 RL 不只训数学——Qwen、GLM 的通用 RL 阶段都是几十个任务混着来。混训有两个实操问题：各域奖励尺度不一样怎么放进一个 batch，以及哪些域互相帮忙、哪些互相打架。
2. 机制/方法：Guru 的实验设计干净：六个域（数学、代码、科学、逻辑、模拟、表格）每个域单独设计可验证奖励（数学比答案、代码跑测试、逻辑题查约束），再去重过滤攒出 9.2 万道题；只用一个域训 RL、测所有六个域，得到迁移矩阵。从矩阵读规律：数学、代码、科学在预训练语料里见得多，只用别的域训他们也跟着涨；逻辑、模拟、表格在预训练里少见，别的域训完他们纹丝不动，必须 in-domain 训才涨——RL 在常见域更像把已有能力激活，在少见域才是真学新技能，这是预训练暴露程度决定的，不是域本身的属性。混训第一个坑是奖励尺度：数学是 0/1、代码是通过率、对话是裁判 1–10 分，直接放一个 batch，优势会被量纲绑架；解法是组内或域内归一化，均值方差归一后量纲消失。第二个坑是能力干扰：2026 年的 CARE-RL 发现数学、对话、指令跟随之间会互相拖后腿，用两个机制压冲突——协议感知的生成式奖励模型（先为每个任务生成评估协议再打分，让不同任务的分可比）和方向感知的能力子空间投影（与其它能力对齐的更新放大、冲突的压制、正交的保留）。更进一步是课程：TAC 用 GRPO 梯度算域与域之间的几何对齐（对齐高说明可迁移，开销不到 1%），再和域内可学性（组内优势大小）合成一个 bandit 式在线课程，决定每一步踩哪个域。
3. 关键证据或数字：六域均匀混合一起训，结果常常追平甚至超过单域专训——既保住各域的 in-domain 收益又拿到跨域迁移；Guru 7B 与 32B 在 17 个任务上比最好的基线分别高 7.9% 和 6.7%。CARE-RL 在 Qwen2.5-7B 与 Qwen3-4B 上总平均 47.9 和 50.7，优于多域基线；TAC 在六域套件上（Qwen3-17B、Llama-3.2-3B）都优于基线，比只看可学性的课程高 2.8 个点。
4. 结论/判断：实操顺序——各域单独设计并校验奖励 → 域内归一化 → 从均匀混合起步 → 监控每域曲线，对掉的域加权或专训 → 最后才考虑梯度对齐课程。追平单域是常见结果而非必然，监控不能省。

## 可迁移

- 多任务 RL 的数据配比决策有了判据：先按预训练暴露程度预判哪些域能蹭迁移、哪些必须留专训预算，再用迁移矩阵实测验证。
- 奖励尺度问题统一解法是域内归一化，这是把多域塞进一个 batch 之前的第一道工序，比调全局权重更优先。

## 疑问 / 下一步

- 「预训练暴露程度」目前只能定性判断；能否用基座在各域的初始通过率分布作可操作代理指标，值得在自己的混训实验里验证。
