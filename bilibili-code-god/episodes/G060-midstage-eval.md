## 一句话总结

评价一个训练中间阶段不能看它自己的分数，要看接上真实下游流水线后的终点：RL 前分数最低的 Mixed SFT（无 CoT 与长 CoT 数据混训）在统一 RL 后反超所有 next-chunk RL 方法且算力便宜约 60 倍，因为格式冲突只是压低了 RL 前的分数、知识并没有丢。

## 核心

1. 问题/背景：Next-chunk reasoning RL（NTR / NSR 一系）主张把 RL 提前到预训练阶段：预测下一段文本前先生成推理，预测得准就给奖励，不需要标注题目、任何文本都能当信号。这类论文报告了收益，但对照组只是"只用无 CoT 数据的普通 SFT"，从没比过一个更朴素的做法——把无 CoT 和长 CoT 数据混在一起做一次 SFT。
2. 机制/方法：实验设置很干净：基座 Qwen3-30B，两份数据同源（AOP）：长 CoT 约 15.2 万条（约 19.5B token，DeepSeek-V3.2 生成）、无 CoT 约 42.1 万条（约 5.3B token）。五种中间阶段：只用长 CoT 的 SFT、无 CoT 再长 CoT 的顺序 SFT、混合的 Mixed SFT、以及 NTR、NSR 两种 next-chunk RL。关键一步：所有方法后面接完全一样的 RLVR（decontaminated MATH 17K + GRPO），只比终点。NTR/NSR 需要在线 rollout、算奖励、更新策略，GPU 小时是 SFT 的 60 倍以上。
3. 关键证据或数字：终点成绩 Mixed SFT 全面胜出——域内六个数学基准平均 67.4（NTR 64.2、NSR 63.6、只用长 CoT 约 62.8）；域外 HLE 9.24 对 7.68/7.72，GPQA Diamond 60.98 对 57.70，MMLU-Pro 75.84 对 74.03。最反直觉的是 RL 前分数：Mixed SFT 只有 27.5 分、是所有方法里最低的，RL 后涨到 61.1（+33.7）；其他方法 RL 前 46–49 分，RL 后只涨 3–10 分。原因有二：混合格式互相打架压低了 RL 前答题格式的稳定性，但知识没丢，RLVR 一进来统一格式就把潜力放出来；而顺序 SFT 有隐藏代价——第二阶段的长 CoT 会覆盖第一阶段的无 CoT 知识，100 道无 CoT 题的保留探针上顺序 SFT + RL 只留 59.19%，混训是 68.63%。至于 NTR，它靠熵过滤挑要推理的 token，挑出来的约 48% 其实不推理也能预测，推理退化成模板式局部补全。
4. 结论/判断：实操三条：评价任何中间阶段，把它接到真实下游流水线看终点，pre-RL 准确率预测不了 post-RL 准确率；两种格式的数据别分阶段喂，混着喂，顺序训练会让后面的覆盖前面的；做长 CoT SFT 时用一个便宜指标——平均输出长度，训练早期先暴涨（学格式）、然后回落企稳（开始内化逻辑），长度还在明显缩短的 checkpoint 大概率没训完。论文边界：只在数学域验证，混合比例也只试了一种。

## 关键数字

| 方法 | RL 前分 | RL 后分 | 相对算力 |
|---|---|---|---|
| Mixed SFT（混训） | 27.5（最低） | 61.1（最高） | 1× |
| NTR / NSR（next-chunk RL） | 46–49 | 只涨 3–10 | 60× 以上 |

## 可迁移

- 这是评估中间 checkpoint 的方法论样本：选 checkpoint 看下游终点而不是当阶段分数，尤其 SFT 阶段选点应以"接 RL 后的表现"为准，和 G007"按 RL 上限选 SFT 点"是同一条线。
- 对 RL infra / 环境设计同样成立：中间组件（数据配比、格式模板）的 A/B 必须在完整流水线终点比较，只看局部指标会被格式冲突这类伪信号误导。

## 疑问 / 下一步

- 混训胜出的结论目前只在数学域、单一混合比例下验证；代码、Agent 等格式冲突更强的域里，最优混合比例和是否仍胜出，值得复现确认。
