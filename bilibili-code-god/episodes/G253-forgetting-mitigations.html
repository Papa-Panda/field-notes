2一句话总结

微调后模型在旧任务上变笨就是灾难性遗忘，五种缓解手段从轻到重：调小 LoRA rank、混入旧数据回放、EWC 正则保护重要参数、低学习率小步微调、任务向量加法合并多任务权重。

3核心

1. 问题/背景

在新任务上微调会覆盖旧任务依赖的参数分布，新能力涨、旧能力掉，即灾难性遗忘。五种方法的共同思路是限制「动多少、动哪里」，或事后把多任务能力合并回来。

2. 机制/方法

  • LoRA rank 选择：rank 越小，可动的参数子空间越小，遗忘越少——用容量换稳定。
  • 数据回放：新数据里混入旧任务（通用）数据，让模型在学新任务时持续复习旧分布。
  • EWC 正则化：给重要参数加保护项，惩罚它们偏离旧任务最优值，重要参数不被轻易覆盖。
  • 低学习率：小步微调减少参数总位移，从源头降低覆盖程度。
  • 任务向量加法：分别在任务 A、B 上训练并存下权重，与基座的差即任务向量；把多个任务向量相加叠回基座，可同时保留多任务能力且无需重训。

3. 关键证据或数字

视频为方法清单式讲解，未给对比实验数字；取舍逻辑是：能改训练配置优先 rank 与学习率，能改数据用回放，要保护特定旧能力用 EWC，多任务事后合并用任务向量。

4. 结论/判断

没有银弹：遗忘控制本质是「新任务拟合 vs 旧参数保持」的权衡，五种手段可组合，选型按你能动的层（参数子空间 / 数据 / 正则 / 步长 / 事后合并）来定。

5可迁移

  • 自己微调时默认组合拳：小 rank LoRA + 低学习率 + 混 10% 量级通用数据回放，是成本最低的防遗忘起步配置。
  • 面试讲持续学习 / 多任务合并时，任务向量加法是很好的收尾点：它把遗忘问题从训练期搬到了权重空间的事后合并。
