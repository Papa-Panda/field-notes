## 一句话总结

非可验证任务的 RL 卡在 LLM 裁判凭空打分不可靠；给裁判一份参考回答作校准尺，裁判就变成软验证器，自我改进效果追平专门微调的奖励模型。

## 核心

1. 问题/背景：数学比答案、代码跑测试，RLVR 的奖励干净；写作、对话、总结没有唯一答案，只能让 LLM 裁判打分。凭空打分的裁判标准漂移、偏爱长答案、偏爱靠前位置、偏爱自己风格，同回答两次打分还不一致——用这种 reward 做 RL，模型学的是讨好裁判。
2. 机制/方法：裁判 prompt 里带上一份参考回答，让它对照着判「比参考好在哪、差在哪」再打分；参考的角色是校准的尺子，不是让模型照抄。参考来源有二：前沿模型生成或人写。进而跑自我改进循环：策略模型对每条 prompt 采样多条回答，参考引导的裁判打分，用分数做偏好/RL 训练，迭代若干轮；全程不需要人标注偏好，也不需要专门训奖励模型，每条 prompt 只需 1 份参考。
3. 关键证据或数字：Llama-3-8B 在 AAAI Eval 达 73.1%、Arena-Hard 58.7%；Qwen2.5-7B 为 70.0% 与 74.1%。比 SFT 蒸馏高 20.2 / 17.1 分，比无参考的自我改进高 5.3 / 3.6 分，与专门微调的奖励模型相当。
4. 结论/判断：参考质量决定上限——参考错了裁判跟着错。有趣的分工：能力弱的裁判从前沿模型参考获益最大（自己判不准，参考给了锚）；能力强的裁判反而从人写高质量参考获益（前沿模型的参考它自己也能写）。

## 可迁移

- 实操四条：每条 prompt 备 1 份参考（弱裁判配前沿模型参考、强裁判配人写参考）；裁判 prompt 写明「对照参考评估、不是匹配参考」；配合长度/位置去偏（交换顺序打两次取平均）；迭代两三轮、每轮重新采样。
- 对自研 rubric/judge 管线：参考锚定是低成本替代 RM 训练的方案，适合没有偏好标注预算的域。

## 疑问 / 下一步

- 参考本身带风格偏置时，模型会不会收敛到「像参考」而非「答得好」，需要何种去偏验证，视频未展开。
