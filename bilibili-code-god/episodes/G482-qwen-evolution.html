2一句话总结

Qwen 两年六代的主线很清晰：2.5 之前卷结构（GQA、MoE、长上下文），2.5 之后随着推理竞赛白热化，转向卷后训练流程（DPO、GRPO、动态思考、蒸馏）与数据规模。

3核心

  1. 问题/背景：Qwen 版本迭代快、改进点散，单看每个版本的发布说明很难形成整体判断，需要一条时间线把结构与训练两条线分开看。
  2. 机制/方法：逐代拆解——Qwen1 打底（RoPE、前置 RMSNorm、SwiGLU、FlashAttention、BF16，上下文 2048 经 NTK 外推到 8192）；1.5 首次引入 GQA 压缩 KV Cache、首次上 MoE（共享专家加细粒度专家）；Qwen2 把 GQA 铺到全系列（KV 省约 40%），用 YaRN + DCA 处理长文本；2.5 数据暴涨并强化代码数学后训练，在线阶段用上 GRPO，上下文推到百万级；Qwen3 结构上加 QK-Norm 稳定注意力、MoE 取消共享专家改更细粒度切分，训练上做动态思考（单模型切换思考/非思考模式）；3-2507 干脆把思考与非思考拆成两个独立模型，上下文拉到 256K。
  3. 关键证据或数字：预训练数据从 Qwen2 的 7 万亿 token 涨到 2.5 的 18 万亿、再到 Qwen3 的 36 万亿；旗舰规格出现 235B 总参、激活 22B 的 MoE 版本；小模型用 KL 散度从大模型蒸馏对齐。
  4. 结论/判断：分水岭在 2.5：之前创新集中在模型结构，之后各家都在卷后训练流程与数据；但厂商大多只公开流程、不公开数据细节，外人能看到的只是骨架。

4关键数字

版本 结构关键点 数据/上下文
Qwen1 RoPE + RMSNorm + SwiGLU 2048（NTK 外推 8192）
Qwen1.5 首次 GQA、首次 MoE 32K
Qwen2 GQA 全系列，KV 省约 40% 7 万亿 token
Qwen2.5 YaRN + DCA，在线 GRPO 18 万亿 token，百万上下文
Qwen3 QK-Norm、细粒度 MoE、动态思考 36 万亿 token
Qwen3-2507 思考/非思考拆为两模型 256K

5可迁移

  • 面试聊开源模型选型或技术演进时，用「2.5 前卷结构、2.5 后卷后训练」这条主线组织回答，比逐版本背参数表有判断力得多。
  • 对自己的 post-training 学习：Qwen3 的四段后训练流程（思维链冷启动 → GRPO 强化推理 → 思考模式切换学习 → 场景 RL）是可直接对照的工业级 pipeline 模板。
