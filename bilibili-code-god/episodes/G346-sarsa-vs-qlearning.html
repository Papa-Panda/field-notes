2一句话总结

SARSA 与 Q-learning 的唯一分水岭是更新目标：前者用下一步实际执行的动作（同策略，把探索风险算进账），后者用下一步的最优动作（异策略，假设自己永不犯错）。

3核心

  1. 问题/背景：经典悬崖行走（4×12 网格，每步 -1、掉崖 -100 并回起点）里，最短路径紧贴悬崖，但探索时有约 10% 概率随机动作，贴边走随时可能踩空。学哪条路取决于价值估计的方式。
  2. 机制/方法：SARSA 的名字来自五元组（状态、动作、奖励、次状态、次动作），更新时用下一步真正要做的动作的 $ Q $ 值——评估的是包含探索的行为策略本身。Q-learning 更新时用次状态所有动作中最大的 $ Q $ 值——行为策略是带探索的 ε-greedy，目标策略却是纯贪心，两者分离。
  3. 关键证据或数字：学出的路径截然不同——SARSA 绕开悬崖走安全但稍长的路，Q-learning 贴悬崖走理论最短路；但长期在线累计回报 SARSA 反而更好，因为它在学习时就把「自己会犯错」计入了成本，Q-learning 执行时频繁掉崖。
  4. 结论/判断：探索代价真实且昂贵（机器人会摔、交易会亏钱）时用 SARSA 式同策略；只求理论最优、训练可在仿真里随便试、部署时关掉探索时用 Q-learning，收敛到真最优更快。

4关键数字

维度 SARSA Q-learning
更新目标 下一步实际动作的 $ Q $ 下一步 $\max_a Q $
策略类型 On-policy Off-policy
学到的路径 绕崖安全路 贴崖最短路
在线回报 更好（少掉崖） 理论最优但执行易踩坑

5可迁移

  • 这正是大模型 RL 的第一道分界：PPO 是 on-policy、DQN 家族是 off-policy，选型逻辑与悬崖例子同构——rollout 数据是否来自当前策略、探索代价谁承担。
  • 面试答「on/off-policy 本质区别」时用一句话即可：优化的是包含探索的行为策略，还是假设最优的目标策略。
